🟡 DESARROLLO 35 minutos

Actividad: "Compresión de archivos y comandos básicos en CMD"

Metodología: Explicación guiada y práctica.

🔹 Compresión de archivos

  • ¿Qué es? Reducir el tamaño de uno o varios archivos para ahorrar espacio y facilitar su envío o almacenamiento.
  • Formatos comunes: ZIP, RAR, 7z.
  • Herramientas en Windows: El explorador de archivos permite comprimir en ZIP sin necesidad de software adicional. También existen programas como WinRAR, 7-Zip o PeaZip.
✅ Comprimir en Windows (gráfico):
  1. Selecciona los archivos/carpetas.
  2. Clic derecho → "Enviar a" → "Carpeta comprimida (en ZIP)".
  3. Se crea un archivo ZIP con el mismo nombre.
📁 Descomprimir (extraer):
  1. Clic derecho sobre el archivo ZIP.
  2. Seleccionar "Extraer todo...".
  3. Elegir la ubicación y hacer clic en "Extraer".

🔹 Terminal CMD (Command Prompt)

  • ¿Qué es? Una interfaz de línea de comandos que permite ejecutar instrucciones al sistema operativo.
  • ¿Cómo abrirla? Escribir "cmd" en el menú inicio y presionar Enter.

💡 Comandos básicos de CMD:

  • dir → Lista los archivos y carpetas del directorio actual.
  • cd → Cambia de directorio. Ej: cd Documentos
  • cd .. → Sube un nivel en la jerarquía de carpetas.
  • mkdir → Crea una nueva carpeta. Ej: mkdir nueva_carpeta
  • del → Elimina un archivo. Ej: del archivo.txt
  • copy → Copia un archivo. Ej: copy origen.txt destino.txt
  • cls → Limpia la pantalla de la terminal.
# Ejemplos de comandos en CMD
dir (Muestra archivos y carpetas)
cd C:\Users\TuUsuario\Escritorio (Cambia al escritorio)
mkdir practica_cmd (Crea una carpeta)
cd practica_cmd (Entra a la carpeta)
copy NUL archivo.txt (Crea un archivo vacío)
del archivo.txt (Elimina el archivo)
cd .. (Vuelve al directorio anterior)
cls (Limpia la pantalla)

📝 Actividad práctica

Realiza los siguientes pasos en tu computadora:

  • Compresión gráfica: Crea una carpeta llamada "mis_archivos" en el escritorio y dentro coloca 3 archivos de texto. Comprime la carpeta en un archivo ZIP.
  • CMD: Abre la terminal (CMD).
  • Navega al escritorio usando cd.
  • Crea una carpeta llamada "practica_cmd" con mkdir.
  • Entra a la carpeta con cd.
  • Crea un archivo de texto con el comando copy NUL ejemplo.txt.
  • Lista los archivos con dir para verificar que el archivo se creó.
  • Elimina el archivo con del ejemplo.txt.
  • Sube un nivel con cd ...
  • Elimina la carpeta practica_cmd usando rmdir practica_cmd (solo si está vacía).
  • Limpia la pantalla con cls.

💡 Tips clave:

• Compresión: Usa ZIP en Windows, o programas como 7-Zip para más formatos y mejor compresión.

• CMD: Es más rápido que la interfaz gráfica para ciertas tareas.

• dir: Siempre útil para ver lo que hay en la carpeta actual.

• cd: Aprende a navegar entre carpetas rápidamente.

• mkdir y del: Crea y elimina archivos sin abrir el explorador.

• Precaución: El comando del elimina archivos permanentemente sin enviarlos a la papelera.
