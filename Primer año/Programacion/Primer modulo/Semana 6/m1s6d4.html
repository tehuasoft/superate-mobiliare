🟢 INICIO 15 minutos

Actividad: "¿Qué es Clipchamp y cómo accedemos?"

Metodología: Presentación y exploración.

Descripción: El docente presenta la herramienta y el proceso de acceso.

🔹 ¿Qué es Microsoft Clipchamp?

Clipchamp es un editor de vídeo online basado en la nube, diseñado para ofrecer una experiencia de edición sencilla y accesible sin necesidad de instalar software adicional. Desde su adquisición por Microsoft en 2021, se ha integrado plenamente en el ecosistema de Microsoft 365.

🔹 Versiones de Clipchamp

Existen dos versiones principales:

  • Versión personal: Acceso gratuito con funciones básicas, y opciones premium mediante suscripción. Se accede en app.clipchamp.com.
  • Versión profesional/educativa: Incluida en licencias de Microsoft 365 Empresa y Educación (A3, A5). Se accede desde el entorno de Microsoft 365.
📌 ¿Cómo saber en qué versión estoy?
Si ves una página de aterrizaje de Microsoft 365 con tus proyectos, estás en la versión de trabajo. Si ves app.clipchamp.com, estás en la personal.

🟡 DESARROLLO 35 minutos

Actividad: "Acceso a Clipchamp y exploración del entorno"

Metodología: Demostración guiada y práctica.

🔹 Paso 1: Acceder a Clipchamp

Hay varias formas de acceder a Clipchamp:

✅ Desde el navegador (versión personal)
  • Ir a app.clipchamp.com.
  • Iniciar sesión con una cuenta de Microsoft personal o familiar.
🔹 Desde Microsoft 365 (versión educativa)
  • Ir a m365.cloud.microsoft.
  • Iniciar sesión con credenciales institucionales.
  • Seleccionar Clipchamp desde el lanzador de aplicaciones.

🔹 Credenciales alternativas

Clipchamp permite iniciar sesión con diferentes cuentas. Es importante usar la cuenta correcta según la versión que se quiera utilizar.

  • Cuenta de Microsoft personal/familiar: Para la versión personal.
  • Cuenta institucional (Microsoft 365): Para la versión educativa o profesional.
  • Si se usan credenciales de terceros (Google, correo electrónico), se debe conectar una cuenta de Microsoft para acceder a las funciones premium.

⚠️ Importante: Si se usan credenciales diferentes, se pueden crear cuentas separadas y los proyectos no estarán visibles entre ellas. Para unificar, se debe usar siempre la misma cuenta de Microsoft.

🔹 Paso 2: Explorar la interfaz de Clipchamp

El entorno de Clipchamp se compone de varias áreas principales:

📥 Barra de herramientas

Ubicada a la izquierda. Permite importar contenido, grabar, acceder a la biblioteca de recursos y plantillas.

📺 Área de previsualización

Muestra el vídeo en tiempo real durante la edición. Incluye controles de reproducción y la barra de herramientas flotante.

⚙️ Panel de propiedades

Ubicado a la derecha. Contiene opciones para editar el elemento seleccionado (audio, filtros, velocidad, etc.).

⏳ Línea de tiempo

Área de trabajo principal. Organiza y edita los clips de vídeo, audio, texto y superposiciones.

🔹 Paso 3: Primer contacto con las herramientas

Una vez dentro, los estudiantes deben familiarizarse con las opciones básicas:

  • Iniciar un nuevo vídeo: Botón "Crear un nuevo vídeo".
  • Importar medios: Arrastrar archivos desde el explorador o usar el botón de importación.
  • Agregar a la línea de tiempo: Arrastrar elementos desde la biblioteca a la línea de tiempo.
  • Vista previa: Usar el botón de reproducción para previsualizar el vídeo.

📝 Actividad práctica

Realiza los siguientes pasos:

  • Accede a Clipchamp desde el navegador (app.clipchamp.com si usas cuenta personal, o desde Microsoft 365 si usas cuenta institucional).
  • Si no tienes cuenta de Microsoft, crea una de forma gratuita desde la página de inicio de sesión.
  • Explora la interfaz: identifica la barra de herramientas, el área de previsualización, el panel de propiedades y la línea de tiempo.
  • Haz clic en "Crear un nuevo vídeo" para abrir el editor.
  • Importa un archivo de vídeo o imagen de muestra usando "Importar medios".
  • Arrastra el archivo a la línea de tiempo y reproduzca la vista previa.
  • Explora las diferentes pestañas de la barra de herramientas: Tu contenido, Graba y crea, Biblioteca de contenido, Plantillas, Texto, Transiciones.
