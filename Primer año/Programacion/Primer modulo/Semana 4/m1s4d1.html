📘 PLANIFICACIÓN DE CLASE

Tema: Paint - Herramientas, dibujo básico, trucos y utilidades

🎯 Competencia General

Utiliza el programa Paint para crear dibujos básicos, aplicando correctamente sus herramientas y explorando trucos y utilidades para mejorar la presentación de imágenes.

📖 Conceptuales (Saber)

  • Identifica las herramientas del programa Paint.
  • Comprende la función de cada herramienta: lápiz, pincel, formas, colores, selección, texto, etc.
  • Reconoce los formatos de imagen que soporta Paint.
  • Entiende trucos básicos para mejorar dibujos (copiar, pegar, duplicar, escalar).

🛠️ Procedimentales (Saber hacer)

  • Abrir y navegar en Paint.
  • Usar herramientas de dibujo y edición.
  • Insertar texto en imágenes.
  • Seleccionar, copiar, pegar y redimensionar elementos.
  • Guardar imágenes en diferentes formatos.

❤️ Actitudinales (Saber ser)

  • Muestra creatividad al realizar dibujos básicos.
  • Valora las herramientas de edición de imágenes.
  • Participa activamente en los ejercicios prácticos.
  • Desarrolla habilidades de expresión visual.

🟡 DESARROLLO 35 minutos

Actividad: "Explorando Paint y creando dibujos básicos"

Metodología: Demostración guiada y práctica.

🔹 ¿Cómo abrir Paint?

En Windows: Menú Inicio → Escribir "Paint" → Abrir la aplicación.

🔹 Herramientas principales de Paint

✏️ Lápiz

Dibuja líneas a mano alzada con grosor de 1 píxel.

🖌️ Pincel

Dibuja con diferentes grosores y formas de trazo.

🟦 Relleno

Llena un área cerrada con un color.

📝 Texto

Inserta texto en la imagen.

🔲 Selección

Selecciona una parte de la imagen para mover, copiar o editar.

🎨 Colores

Elige el color de dibujo y el color de fondo.

⬜ Borrador

Elimina partes de la imagen.

🔷 Formas

Rectángulos, círculos, líneas, polígonos, etc.

🔹 Trucos y utilidades en Paint

  • Copiar y pegar: Selecciona una parte (Ctrl+C) y pégala (Ctrl+V) para duplicar.
  • Duplicar con teclas: Selecciona la imagen, mantén presionada la tecla Ctrl y arrastra para crear una copia.
  • Redimensionar: Usa la opción "Redimensionar" para cambiar el tamaño de la imagen o de una selección.
  • Rotar: Gira la imagen 90°, 180° o 270°, o la voltea horizontal/verticalmente.
  • Zoom: Usa la lupa para acercar o alejar y trabajar con detalles.
  • Fondo transparente: Al seleccionar, activa la opción "Selección transparente" para mover elementos sin fondo.
  • Atajo rápido: Ctrl+E abre las propiedades de la imagen (tamaño).

🔹 Guardar y formatos de imagen

  • PNG: Buena calidad, soporta transparencia.
  • JPG (JPEG): Tamaño más pequeño, útil para fotos.
  • GIF: Soporta animaciones y transparencia.
  • BMP: Formato sin compresión, archivos grandes.
📌 Recomendación:
Para guardar imágenes con calidad y transparencia, usa PNG. Para imágenes con muchos colores y tamaño reducido, usa JPG.

📝 Actividad práctica

Realiza los siguientes pasos en Paint:

  • Abre Paint y crea un dibujo sencillo: un sol (círculo amarillo con líneas alrededor).
  • Usa la herramienta Texto para escribir "¡Hola, mundo!" debajo del sol.
  • Añade una nube usando la herramienta de formas (elipses blancas).
  • Selecciona la nube, cópiala y pégala para crear otra nube.
  • Redimensiona el lienzo para que quede más grande (Ctrl+E).
  • Guarda tu dibujo como "mi_dibujo.png" en tu escritorio.

💡 Tips clave:

• Atajos útiles: Ctrl+C (copiar), Ctrl+V (pegar), Ctrl+E (propiedades).

• Selección transparente: Activa la opción para mover elementos sin fondo.

• Duplicar: Selecciona + Ctrl + arrastrar para crear copias rápidas.

• Formatos: Usa PNG para calidad/transparencia, JPG para tamaño reducido.

• Zoom: Acércate para trabajar en detalles, aléjate para ver el conjunto.

• Redimensionar: Mantén la proporción para que no se deforme la imagen.
