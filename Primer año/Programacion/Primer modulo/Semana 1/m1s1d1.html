📘 PLANIFICACIÓN DE CLASE

Tema: Conceptos básicos de Sistema Operativo, Hardware y Periféricos

🎯 Competencia General

Comprende los conceptos fundamentales de sistema operativo, hardware y periféricos, identificando sus funciones y su importancia en el funcionamiento de una computadora, y reconociendo la relación entre estos componentes para el correcto desempeño del sistema.

📖 Conceptuales (Saber)

  • Define qué es un sistema operativo y sus funciones principales.
  • Identifica los componentes del hardware básico de una computadora.
  • Clasifica los periféricos según su función (entrada, salida, entrada/salida).
  • Comprende la relación entre hardware, software y sistema operativo.

🛠️ Procedimentales (Saber hacer)

  • Diferenciar entre hardware y software.
  • Identificar los componentes internos de una computadora.
  • Clasificar periféricos según su tipo.
  • Explicar la función del sistema operativo como intermediario.

❤️ Actitudinales (Saber ser)

  • Muestra interés por conocer el funcionamiento interno de las computadoras.
  • Valora la importancia del sistema operativo para el uso cotidiano.
  • Participa activamente en la identificación de componentes.
  • Reconoce la evolución tecnológica de los periféricos.
🟢 INICIO 15 minutos

Actividad: "¿Qué hay dentro de una computadora?"

Metodología: Lluvia de ideas y cuestionamiento.

Descripción: El docente pregunta:

  • ¿Qué partes físicas tiene una computadora?
  • ¿Qué es lo que hace que funcione?
  • ¿Qué diferencia hay entre el monitor y el procesador?
  • ¿Cómo se comunica el usuario con la computadora?

Se introduce la división fundamental: Hardware (partes físicas) y Software (programas). El Sistema Operativo es el software principal que gestiona el hardware.

🧠 Analogía:
Hardware es como el cuerpo de la computadora.
Sistema Operativo es como el cerebro que coordina todo.
Software son las ideas o actividades que el cerebro ejecuta.

Actividad: "Sistema Operativo, Hardware y Periféricos"

🔹 Sistema Operativo (SO)

El Sistema Operativo es el software principal que:

  • Gestiona el hardware: Asigna recursos (CPU, memoria, discos) a los programas.
  • Provee una interfaz al usuario: Permite interactuar con la computadora (gráfica o por comandos).
  • Administra archivos y directorios: Organiza la información en el disco.
  • Controla la ejecución de programas: Inicia, ejecuta y termina aplicaciones.
  • Gestiona la seguridad: Controla el acceso a los recursos.
📌 Ejemplos de SO:
Windows (Microsoft), Linux (Fedora, Ubuntu, Debian), macOS (Apple), Android, iOS.

🔹 Hardware básico

El Hardware son los componentes físicos de la computadora. Se divide en:

🖥️ CPU (Procesador)
  • El "cerebro" de la computadora.
  • Ejecuta instrucciones y procesa datos.
  • Marca: Intel, AMD.
🧠 Memoria RAM
  • Memoria de trabajo (volátil).
  • Guarda datos e instrucciones temporales.
  • Se borra al apagar la computadora.
💾 Almacenamiento
  • Guarda datos de forma permanente.
  • Disco duro (HDD) o SSD (más rápido).
  • Aquí se instala el SO y los archivos.
📌 Otros componentes:
Placa madre (motherboard): Conecta todos los componentes.
Fuente de poder: Suministra energía.
Tarjeta gráfica (GPU): Procesa gráficos y video.

🔹 Periféricos

Los periféricos son dispositivos externos que se conectan a la computadora para ampliar sus funciones. Se clasifican en:

⌨️ Periféricos de entrada
  • Ingresan datos a la computadora.
  • Ejemplos: Teclado, mouse, micrófono, escáner, cámara web.
🖥️ Periféricos de salida
  • Muestran o entregan datos al usuario.
  • Ejemplos: Monitor, impresora, altavoces, auriculares.
🔄 Periféricos de entrada/salida
  • Ambas funciones: entran y salen datos.
  • Ejemplos: USB, disco duro externo, pantalla táctil.

💡 Tips clave:

• Hardware: Todo lo que puedes tocar (CPU, RAM, disco, periféricos).

• Sistema Operativo: El software que coordina todo el hardware y permite ejecutar programas.

• Periféricos: Dispositivos externos que permiten la comunicación con la computadora.

• Relación: El SO es el intermediario entre el usuario, el hardware y las aplicaciones.

• Sin SO, la computadora no podría funcionar (no habría manera de usar el hardware).
