Tema: Uso de IA para generación de citas en el texto y referencias APA (con Prompts)

🎯 Competencia General

Utiliza herramientas de inteligencia artificial de manera ética y responsable para generar citas en el texto (in-line citations) y referencias en formato APA a partir de URLs, libros u otras fuentes, aplicando prompts específicos y verificando la precisión de los resultados.

📖 Conceptuales (Saber)

  • Comprende el formato APA para citas en el texto y referencias.
  • Reconoce los elementos clave que debe contener un prompt para generar citas APA con IA.
  • Identifica la diferencia entre cita en el texto (autor-año) y referencia completa.
  • Comprende la importancia de verificar las citas generadas por IA.

🛠️ Procedimentales (Saber hacer)

  • Escribir prompts efectivos para que la IA genere citas en el texto y referencias APA.
  • Proporcionar a la IA el tipo de fuente (URL, libro, artículo) para que genere el formato correcto.
  • Verificar la precisión de las citas generadas por IA.
  • Utilizar la IA como asistente para la generación de citas y referencias.

❤️ Actitudinales (Saber ser)

  • Muestra compromiso con la honestidad académica al utilizar IA.
  • Valora la importancia de verificar la información generada por IA.
  • Participa activamente en la práctica de generación de citas con IA.
  • Reconoce la IA como una herramienta de apoyo, no como un sustituto del conocimiento propio.
🟢 INICIO 15 minutos

Actividad: "IA para generar citas APA: ¿Cómo funciona?"

Metodología: Cuestionamiento y demostración.

Descripción: El docente introduce el concepto de usar IA para generar citas APA.

🔹 ¿Por qué usar IA para citas APA?

  • La IA puede ahorrar tiempo al generar citas y referencias a partir de URLs o información proporcionada.
  • Es útil cuando se necesita un formato APA rápido y no se tiene acceso a una guía detallada .
  • Sin embargo, la IA puede cometer errores, por lo que es fundamental verificar la información generada .
📌 Principio clave:
La IA es una asistente, no una fuente definitiva. Siempre revisa las citas y referencias generadas antes de incluirlas en tu trabajo.

🔹 Prompts para generar citas APA

Un prompt es la instrucción que le damos a la IA para que realice una tarea específica. A continuación, se muestran ejemplos de prompts para generar citas APA.

# Prompt para generar cita en el texto (in-line citation) y referencia a partir de una URL
Prompt: "Por favor, genera una cita en el texto (in-line citation) y una referencia en formato APA 7ma edición para la siguiente URL: https://www.ejemplo.com/articulo"

# Prompt para generar cita en el texto y referencia a partir de un libro
Prompt: "Genera una cita en el texto y una referencia en formato APA 7ma edición para un libro con los siguientes datos: Autor: Juan Pérez, Año: 2021, Título: 'Fundamentos de Informática', Editorial: Editorial Técnica."

# Prompt para generar múltiples citas
Prompt: "Genera citas en el texto y referencias en formato APA 7ma edición para las siguientes fuentes: 1. URL: https://www.ejemplo.com/articulo2, 2. Libro: Autor: Ana García, Año: 2020, Título: 'Innovación Educativa', Editorial: Ediciones Académicas."

🔹 Ejemplo de respuesta de la IA

# Entrada del usuario
Prompt: "Genera una cita en el texto y una referencia en formato APA 7ma edición para la siguiente URL: https://www.ejemplo.com/articulo-informatica"

# Salida de la IA
Cita en el texto (in-line citation):
(Autor, 2023)

Referencia en formato APA:
Autor, A. A. (2023). Título del artículo. Nombre del sitio web. https://www.ejemplo.com/articulo-informatica

🔹 Cómo verificar la información generada

  • Revisar los datos: Verifica que el autor, año y título sean correctos.
  • Formato APA: Asegúrate de que el formato siga las reglas de APA (cursivas, sangría, etc.).
  • URL: Verifica que la URL sea accesible y que la fuente sea confiable.
  • Uso de herramientas: Puedes usar herramientas como APA Citation Generator o Grammarly para verificar los resultados .

🔹 Prompt para generar citas con diferentes tipos de fuentes

Prompt avanzado:
"Genera citas en el texto y referencias en formato APA 7ma edición para las siguientes fuentes. Para cada una, proporciona la cita en el texto (con paréntesis y narrativa) y la referencia completa:

1. URL: https://www.apa.org/education
2. Libro: Autor: Carlos Gómez, Año: 2018, Título: 'Métodos de Investigación', Editorial: Editorial Universitaria
3. Artículo de revista: Autor: Laura Fernández, Año: 2022, Título: 'Estrategias de enseñanza', Revista: 'Educación y Ciencia', Volumen: 15, Número: 2, Páginas: 45-60"

📝 Actividad práctica

Realiza los siguientes pasos:

  • Paso 1: Abre ChatGPT u otra IA generativa.
  • Paso 2: Usa el siguiente prompt para generar una cita en el texto y una referencia APA a partir de una URL real o ficticia:
    • "Genera una cita en el texto y una referencia en formato APA 7ma edición para la URL: [coloca aquí tu URL]"
  • Paso 3: Usa el siguiente prompt para generar una cita y referencia a partir de un libro:
    • "Genera una cita en el texto y una referencia en formato APA 7ma edición para un libro con los siguientes datos: Autor: [tu autor], Año: [año], Título: '[título]', Editorial: [editorial]."
  • Paso 4: Verifica la precisión de las citas generadas utilizando una guía APA o una herramienta de verificación.
  • Paso 5: Guarda el resultado en un documento de Word.

💡 Tips clave para generar citas APA con IA:

• Prompt claro: Proporciona toda la información necesaria (autor, año, título, URL).

• Especifica el formato: Indica que deseas el formato APA 7ma edición.

• Verifica siempre: Revisa que la cita generada siga las reglas APA (cursivas, sangría, etc.).

• Usa herramientas complementarias: Combina la IA con herramientas como APA Citation Generator para verificar los resultados.

• No confíes ciegamente: La IA puede cometer errores; la responsabilidad final es tuya.
