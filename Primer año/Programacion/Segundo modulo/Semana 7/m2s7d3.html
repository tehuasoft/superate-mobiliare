🎯 Competencia General

Utiliza herramientas de organización y presentación en Excel para gestionar datos de manera eficiente y preparar documentos para impresión profesional, aplicando ordenamiento de tablas, inmovilización de paneles y configuración de página.

  • Comprende la función de inmovilizar paneles para mantener visible información importante.
  • Reconoce las opciones de configuración de página para impresión profesional.
  • Identifica los elementos de la vista previa de impresión.

🛠️ Procedimentales (Saber hacer)

  • Ordenar datos de forma ascendente y descendente.
  • Ordenar por múltiples columnas.
  • Inmovilizar filas y columnas en una hoja de cálculo.
  • Configurar márgenes, orientación y tamaño de página.
  • Agregar encabezados y pies de página para impresión.
  • Usar la vista previa de impresión.

❤️ Actitudinales (Saber ser)

Actividad: "Ordenar, inmovilizar y configurar página"

Metodología: Explicación guiada y práctica.

🔹 Ordenar datos

📊 Ordenar tablas

Permite organizar datos alfabética o numéricamente.

  • Orden ascendente: De menor a mayor (A-Z, 0-9).
  • Orden descendente: De mayor a menor (Z-A, 9-0).
  • Ordenar por múltiples columnas: Útil cuando hay valores repetidos.
📌 Uso: Organizar listas de estudiantes, productos, ventas, etc.

🔹 Inmovilizar paneles

🔒 Inmovilizar paneles

Mantiene visibles filas o columnas mientras se desplaza la hoja.

  • Inmovilizar fila superior: Mantiene visible la primera fila.
  • Inmovilizar primera columna: Mantiene visible la primera columna.
  • Inmovilizar paneles: Permite seleccionar una fila y columna específicas.
📌 Uso: Mantener encabezados visibles en tablas largas.

🔹 Configurar página para impresión

🖨️ Configurar página

Prepara la hoja para una impresión profesional.

  • Márgenes: Normal, estrecho, personalizado.
  • Orientación: Vertical u horizontal.
  • Tamaño: Carta, oficio, A4, etc.
  • Área de impresión: Seleccionar qué parte de la hoja imprimir.
  • Encabezados y pies de página: Agregar título, fecha, número de página.
📌 Uso: Preparar informes, listados y documentos para presentación.

🔹 Pasos para aplicar cada herramienta

📌 Ordenar en Excel
  1. Seleccionar los datos.
  2. Ir a Datos → Ordenar.
  3. Elegir columna y tipo de orden.
📌 Inmovilizar paneles
  1. Ir a Ver → Inmovilizar paneles.
  2. Elegir opción: fila superior, primera columna o paneles.
📌 Configurar página
  1. Ir a Diseño de página → Configurar página.
  2. Configurar márgenes, orientación y tamaño.
  3. Agregar encabezado/pie de página.
  4. Usar Vista previa para ver el resultado.
📌 Área de impresión
  1. Seleccionar el rango a imprimir.
  2. Diseño de página → Área de impresión → Establecer.

📝 Actividad práctica

Crea una hoja de cálculo en Excel y realiza lo siguiente:

  • Datos: Crea una tabla con las siguientes columnas: Nombre, Edad, Ciudad, Calificación.
  • Ingresa al menos 10 registros (puedes inventar los datos).
  • Ordenar: Ordena la tabla por Edad de forma descendente.
  • Ordenar múltiple: Ordena por Ciudad y luego por Calificación.
  • Inmovilizar: Inmoviliza la primera fila para que los encabezados siempre estén visibles.
  • Configurar página: Cambia la orientación a Horizontal y los márgenes a Estrechos.
  • Encabezado: Agrega un encabezado con el título "Lista de Estudiantes".
  • Pie de página: Agrega el número de página.
  • Área de impresión: Establece que solo se imprima la tabla.
  • Vista previa: Revisa cómo quedaría al imprimir.
  • Guarda el archivo como "organizacion_impresion.xlsx".
