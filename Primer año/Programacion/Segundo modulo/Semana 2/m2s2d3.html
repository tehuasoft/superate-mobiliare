🔹 Estilos como base para la tabla de contenido

La tabla de contenido automática de Word se basa en los estilos de título aplicados al documento.

  • Título 1: Nivel principal (capítulos o secciones principales).
  • Título 2: Subsecciones dentro de un capítulo.
  • Título 3: Subsecciones de nivel inferior.
📋 Tabla de contenido (ejemplo)
1. Introducción1
1.1. Objetivos2
1.2. Metodología3
2. Desarrollo4
2.1. Análisis de datos5
3. Conclusiones8

🔹 Pasos para crear una tabla de contenido automática

  1. Aplicar estilos: Seleccionar los títulos y aplicar Título 1, Título 2, etc.
  2. Posicionar el cursor: Colocar el cursor donde se desea insertar la tabla de contenido (generalmente al inicio del documento).
  3. Insertar tabla de contenido: "Referencias" → "Tabla de contenido" → Elegir un estilo automático.
  4. Actualizar: Después de hacer cambios, hacer clic derecho sobre la tabla y seleccionar "Actualizar campo".

🔹 Estructura de un reporte formal

Un reporte formal debe incluir los siguientes elementos:

📄 Portada
  • Título del reporte.
  • Nombre del autor/institución.
  • Fecha.
📋 Índice (TOC)
  • Lista de capítulos y subsecciones.
  • Números de página.
📝 Introducción
  • Contexto del tema.
  • Objetivos del reporte.
  • Metodología breve.
📊 Desarrollo
  • Capítulos con el contenido principal.
  • Datos, análisis y discusión.
📌 Conclusiones
  • Resumen de hallazgos.
  • Recomendaciones.
📚 Bibliografía
  • Fuentes consultadas.
  • Formato APA, MLA u otro.

📝 Actividad práctica

Crea un reporte en Word sobre un tema de tu elección siguiendo estos pasos:

  • Portada: Crea una portada con título, tu nombre y fecha.
  • Índice: Inserta una tabla de contenido automática.
  • Introducción: Escribe un párrafo sobre el tema (aplica Título 1 a "Introducción").
  • Desarrollo: Escribe 3 secciones principales (Título 1) con 1-2 subsecciones cada una (Título 2).
  • Conclusiones: Escribe un párrafo de cierre.
  • Bibliografía: Lista 3 fuentes de información.
  • Actualiza la tabla de contenido después de escribir todo el contenido.
  • Guarda el documento como "reporte_ejercicio.docx".

💡 Tips clave:

• Estilos: Usa Título 1, Título 2 y Título 3 para estructurar tu documento.

• Tabla de contenido: Se genera automáticamente a partir de los estilos.

• Actualización: Siempre actualiza la tabla de contenido antes de exportar o imprimir.

• Portada: Word tiene plantillas de portada prediseñadas en "Insertar → Portada".

• Numeración: Usa numeración automática para los títulos si lo deseas.
