🔹 Formas en Word

Las formas son elementos gráficos que se pueden insertar en el documento para ilustrar ideas, crear diagramas o resaltar información.

  • Dónde encontrarlas: "Insertar" → "Formas".
  • Tipos: Rectángulos, círculos, flechas, líneas, diagramas de flujo, etc.
  • Formato: Color de relleno, borde, efectos de sombra, 3D.

🔹 Imágenes en Word

Las imágenes pueden ser insertadas desde el equipo o desde la web.

  • Insertar desde archivo: "Insertar" → "Imágenes" → "Este dispositivo".
  • Insertar en línea: "Insertar" → "Imágenes" → "Imágenes de stock".
  • Formato: Cambiar tamaño, recortar, ajustar brillo/contraste, aplicar efectos artísticos.
  • Posición: Ajustar el texto alrededor de la imagen (cuadrado, ajustado, detrás del texto, etc.).
📌 Recomendaciones para imágenes:
✔ Usa imágenes de alta calidad y que estén relacionadas con el contenido.
✔ No abuses de las imágenes para no saturar el documento.
✔ Ajusta el tamaño y la posición para que no interfieran con el texto.

🔹 Estilos en Word

Los estilos son conjuntos de formatos predefinidos que se pueden aplicar a títulos, subtítulos y texto normal para mantener una apariencia consistente.

  • Dónde encontrarlos: Pestaña "Inicio" → grupo "Estilos".
  • Ventajas: Ahorran tiempo, mantienen coherencia, permiten actualizar todo el documento al cambiar un estilo.
  • Estilos comunes: Título 1, Título 2, Título 3, Normal, Énfasis, etc.

📝 Actividad práctica

Crea un documento en Word y realiza lo siguiente:

  • Escribe un título principal y aplica el estilo "Título 1".
  • Escribe tres subtítulos y aplica el estilo "Título 2".
  • Inserta una forma (puede ser un rectángulo o círculo) y agrega texto dentro.
  • Inserta una imagen desde tu computadora o desde la web.
  • Ajusta la imagen para que el texto fluya a su alrededor (opción "Cuadrado").
  • Cambia el color de la forma y aplica un efecto de sombra.
  • Guarda el documento como "visuales_ejercicio.docx".

💡 Tips clave:

• Formas: Úsalas para diagramas, resaltar información o decorar.

• Imágenes: Ajusta la calidad y el tamaño para no ralentizar el documento.

• Estilos: Ahorran tiempo y dan un aspecto profesional al documento.

• Alineación: Usa las herramientas de alineación para ordenar formas e imágenes.

• Agrupar objetos: Selecciona varias formas, haz clic derecho y elige "Agrupar" para moverlas juntas.
