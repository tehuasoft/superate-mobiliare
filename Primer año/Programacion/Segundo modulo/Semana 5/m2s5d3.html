🔹 Formato de tablas en Excel

El formato de tabla permite dar un aspecto profesional a los datos, facilitando su lectura y análisis.

✅ Opciones de formato
  • Fuente: Tipo, tamaño, color, negrita, cursiva.
  • Alineación: Izquierda, centrado, derecha, justificado.
  • Bordes: Líneas que separan celdas.
  • Relleno: Color de fondo de las celdas.
  • Número: Formato de moneda, porcentaje, fecha, etc.
📌 Estilos de tabla
  • Excel ofrece estilos predefinidos que combinan colores, bordes y formato.
  • Se aplican desde la pestaña "Inicio" → "Dar formato como tabla".
  • También se puede usar la pestaña "Diseño de tabla" para personalizar.

🔹 Secuencias en Excel

Las secuencias permiten llenar rápidamente celdas con datos consecutivos (números, fechas, meses, etc.) usando el controlador de relleno.

  • Autollenado: Arrastrar el controlador de relleno (cuadro negro en la esquina inferior derecha) para completar una secuencia.
  • Secuencias numéricas: 1, 2, 3, 4... o 10, 20, 30... (escribe los primeros dos números y arrastra).
  • Secuencias de fechas: 01/01/2025, 02/01/2025... o meses (Enero, Febrero, etc.).
  • Secuencias personalizadas: Usar la opción "Relleno → Series" para configurar incrementos y límites.

📝 Actividad práctica

Crea una hoja de cálculo en Excel y realiza lo siguiente:

  • Secuencias: En la columna A, crea una secuencia de meses (Enero a Diciembre) usando autollenado.
  • Formato: En la columna B, escribe números aleatorios y aplícales formato de moneda ($).
  • Formato de tabla: Selecciona todos los datos y aplica un estilo de tabla desde "Inicio → Dar formato como tabla".
  • Alineación y bordes: Centra los encabezados y agrega bordes a toda la tabla.
  • Secuencia personalizada: En la columna C, crea una secuencia de números impares (1, 3, 5, 7...) usando el controlador de relleno.
  • Guarda el archivo como "formato_secuencias.xlsx".

💡 Tips clave:

• Autollenado: Arrastra el controlador de relleno para copiar o completar secuencias.

• Secuencias numéricas: Escribe 1 y 2, selecciona ambos y arrastra para continuar la secuencia.

• Secuencias de texto: Escribe "Enero" y arrastra para obtener los meses siguientes.

• Formato de tabla: Usa los estilos predefinidos para dar un aspecto profesional.

• Bordes y rellenos: Mejoran la legibilidad y organización de los datos.

• Formato de números: Usa el formato de moneda, porcentaje o fecha según el tipo de dato.
