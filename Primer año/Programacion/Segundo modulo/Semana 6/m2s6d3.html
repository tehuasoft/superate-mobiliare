🔹 Función OR

La función OR evalúa múltiples condiciones y devuelve TRUE si al menos una es verdadera.

Condición 1 Condición 2 OR
TRUE TRUE TRUE
TRUE FALSE TRUE
FALSE TRUE TRUE
FALSE FALSE FALSE
📌 Ejemplo con OR:
Si un estudiante aprueba si tiene nota >= 70 O asistencia >= 80%:
=IF(OR(A1 >= 70, B1 >= 80), "Aprobado", "Reprobado")

🔹 Combinación de IF, AND y OR

Se pueden combinar AND y OR dentro de IF para evaluar condiciones complejas.

Función Descripción Ejemplo
IF + OR Al menos una condición debe ser verdadera =IF(OR(cond1, cond2), "Sí", "No")
IF + AND + OR Combina AND y OR para condiciones complejas =IF(AND(cond1, OR(cond2, cond3)), "Sí", "No")
IF + OR + AND OR con condiciones compuestas =IF(OR(AND(cond1, cond2), cond3), "Sí", "No")
📌 Ejemplo combinado:
Un empleado recibe bono si (ventas > 10000 Y antigüedad > 2 años) O (es gerente):
=IF(OR(AND(A1 > 10000, B1 > 2), C1 = "Gerente"), "Bono", "Sin bono")

💡 Tips clave:

• OR: =OR(cond1, cond2, ...) devuelve TRUE si al menos una es verdadera.

• IF + OR: =IF(OR(cond1, cond2), "Verdadero", "Falso")

• AND + OR: =IF(AND(cond1, OR(cond2, cond3)), "Sí", "No")

• OR + AND: =IF(OR(AND(cond1, cond2), cond3), "Sí", "No")

• Precaución: Usa paréntesis para controlar el orden de evaluación.
