Actividad: "Funciones IF y AND en Excel"

Metodología: Explicación guiada y práctica.

🔹 Función IF

La función IF evalúa una condición y devuelve un valor si es verdadera y otro si es falsa.

=IF(condición, valor_si_verdadero, valor_si_falso)
📌 Ejemplo:
Si en la celda A1 tienes una calificación, la siguiente fórmula clasifica si es aprobado o reprobado:
=IF(A1 >= 70, "Aprobado", "Reprobado")

🔹 Función AND

La función AND evalúa múltiples condiciones y devuelve TRUE solo si todas son verdaderas.

Condición 1 Condición 2 AND
TRUE TRUE TRUE
TRUE FALSE FALSE
FALSE TRUE FALSE
FALSE FALSE FALSE
📌 Ejemplo con AND:
Si una persona debe tener edad >= 18 y nacionalidad = "Mexicana" para votar:
=IF(AND(A1 >= 18, B1 = "Mexicana"), "Puede votar", "No puede votar")

🔹 IF anidados

Es posible colocar un IF dentro de otro IF para evaluar múltiples condiciones de manera secuencial.

📌 Ejemplo:
Para clasificar calificaciones:
=IF(A1 >= 90, "Excelente", IF(A1 >= 70, "Aprobado", "Reprobado"))

📝 Actividad práctica

Crea una hoja de cálculo en Excel y realiza lo siguiente:

  • Ejercicio 1 (IF simple): En la columna A, escribe 5 calificaciones (0-100). En la columna B, usa =IF(A1 >= 70, "Aprobado", "Reprobado").
  • Ejercicio 2 (IF con AND): Crea una tabla con Edad (columna A) y Nacionalidad (columna B). En la columna C, usa =IF(AND(A1 >= 18, B1 = "Mexicana"), "Puede votar", "No puede votar").
  • Ejercicio 3 (IF anidado): Usa calificaciones y clasifica como: "Excelente" (>=90), "Bueno" (80-89), "Aprobado" (70-79), "Reprobado" (<70).
  • Ejercicio 4 (IF con AND anidado): Evalúa si un empleado recibe bono: si ventas > 10000 y antigüedad > 2 años, "Bono", si no, "Sin bono".
  • Guarda el archivo como "funciones_IF_AND.xlsx".

💡 Tips clave:

• IF: =IF(condición, "Verdadero", "Falso")

• AND: =AND(cond1, cond2, ...) devuelve TRUE si todas son verdaderas.

• IF con AND: =IF(AND(cond1, cond2), "Sí", "No")

• IF anidado: =IF(cond1, "Resultado1", IF(cond2, "Resultado2", "Resultado3"))

• Precaución: Demasiados IF anidados pueden ser difíciles de leer. Usa otras funciones como IFS para simplificar.
