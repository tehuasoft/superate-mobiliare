🔗 PLANIFICACIÓN DE CLASE

Integración SharePoint + Power Apps + Power Automate · Sistema de "Registro de Incidentes"

🎯 Competencia General

El estudiante construye paso a paso un sistema integrado de "Registro de Incidentes" utilizando SharePoint (lista de datos), Power Apps (interfaz de usuario) y Power Automate (notificación automática), comprendiendo cómo las tres herramientas se conectan para resolver un caso de negocio real.

📖 Conceptuales (Saber)

  • Comprende la arquitectura de integración entre SharePoint, Power Apps y Power Automate.
  • Reconoce el rol de cada herramienta en el sistema.
  • Identifica el flujo de datos entre las tres plataformas.
  • Entiende la importancia de la integración para resolver problemas reales.

🛠️ Procedimentales (Saber hacer)

  • Crear una lista de SharePoint para incidentes.
  • Diseñar una app de Power Apps con formularios y galerías.
  • Crear un flujo de Power Automate que notifique al crear un incidente.
  • Conectar las tres herramientas en un sistema funcional.
  • Probar el sistema completo de registro y notificación.

❤️ Actitudinales (Saber ser)

  • Muestra interés por la integración de herramientas.
  • Valora la importancia de resolver problemas con tecnología.
  • Participa activamente en la construcción del sistema.
  • Desarrolla visión de arquitectura de soluciones.

🔹 Parte 1: Crear la lista de SharePoint

1
Crear la lista "Incidentes"

Ir al sitio de SharePoint y crear una lista en blanco llamada "Incidentes".

📋 SharePoint → + Nuevo → Lista → Lista en blanco → Nombre: "Incidentes"
2
Agregar las columnas necesarias

Agregar las siguientes columnas:

  • Título (Texto) — Ya existe por defecto.
  • Descripción (Texto — varias líneas) — Detalle del incidente.
  • Reportado por (Persona o Grupo) — Quién reporta.
  • Responsable (Persona o Grupo) — A quién se asigna.
  • Prioridad (Elección: Alta, Media, Baja).
  • Estatus (Elección: Abierto, En progreso, Resuelto).
  • Fecha de reporte (Fecha).

🔹 Parte 2: Crear la app en Power Apps

3
Crear la app desde SharePoint

En la lista "Incidentes", ir a "Integrar" → "Power Apps" → "Crear una aplicación".

📱 SharePoint → Integrar → Power Apps → Crear una aplicación

Se generará automáticamente una app con pantallas Browse, Detail y Edit.

4
Personalizar la pantalla Browse

Renombrar la pantalla a "BrowseScreen" y configurar la galería para mostrar:

  • Título: ThisItem.Título
  • Prioridad: ThisItem.Prioridad.Value
  • Estatus: ThisItem.Estatus.Value
🖼️ Galería → Título | Prioridad | Estatus
5
Configurar la pantalla Edit

Renombrar la pantalla a "EditScreen" y configurar el EditForm con los campos:

  • Título, Descripción, Reportado por, Responsable, Prioridad, Estatus, Fecha de reporte.

Agregar los botones "Guardar" (SubmitForm(EditForm1); Back()) y "Cancelar" (ResetForm(EditForm1); Back()).

✏️ EditForm → Campos + Botón Guardar + Botón Cancelar

🔹 Parte 3: Crear el flujo de notificación en Power Automate

6
Crear flujo automatizado

Ir a make.powerautomate.com → "Crear" → "Flujo automatizado".

Nombre: "Notificación de nuevo incidente".

Trigger: "Cuando se crea un elemento" → SharePoint → Lista "Incidentes".

⚡ Crear → Flujo automatizado
🎯 Trigger: "Cuando se crea un elemento" → Incidentes
7
Agregar acción: Enviar correo al responsable

Agregar la acción "Enviar un correo electrónico" (Office 365 Outlook).

  • Para: Campo dinámico Responsable Email.
  • Asunto: "Nuevo incidente asignado: " + Título.
  • Cuerpo: Detalles del incidente.

🔹 Parte 4: Probar el sistema completo

9
Registrar un incidente desde Power Apps

Abrir la app en Power Apps, hacer clic en "+ Nuevo", completar el formulario y guardar.

📱 Power Apps → + Nuevo → Completar formulario → Guardar
10
Verificar el flujo y la notificación

Ir a Power Automate → "Mis flujos" → revisar el historial de ejecuciones. Verificar que el correo llegó al responsable.

✅ Mis flujos → Notificación de nuevo incidente → Historial: Exitoso
11
Verificar la lista de SharePoint

Ir a la lista "Incidentes" en SharePoint y confirmar que el nuevo incidente aparece con los datos correctos.

📋 SharePoint → Lista "Incidentes" → Nuevo incidente registrado

🔹 Integración completa del sistema

📋
SharePoint

Lista "Incidentes"

Almacena los datos de cada incidente.

Columnas: Título, Descripción, Reportado por, Responsable, Prioridad, Estatus.

📱
Power Apps

Interfaz de usuario

Permite registrar, ver y editar incidentes.

Pantallas: Browse, Detail, Edit.

⚡
Power Automate

Notificación automática

Envía correo al responsable al crear un incidente.

Trigger: Cuando se crea un elemento.

📌 Flujo de datos del sistema:
  1. Usuario registra un incidente en Power Apps.
  2. Los datos se guardan en la lista de SharePoint.
  3. Power Automate detecta el nuevo elemento (trigger) y envía un correo al responsable.
  4. El responsable recibe la notificación y actualiza el estatus en Power Apps o SharePoint.

📝 Actividad práctica

Instrucciones:

  • 1. Crea la lista "Incidentes" en SharePoint con las columnas indicadas.
  • 2. Crea una app en Power Apps desde la lista "Incidentes" y personaliza la galería y el formulario.
  • 3. Crea un flujo en Power Automate que envíe un correo al responsable cuando se cree un incidente.
  • 4. Prueba el sistema completo: registra un incidente desde Power Apps.
  • 5. Verifica que el incidente aparece en SharePoint y que el correo llega al responsable.
  • 6. Actualiza el estatus del incidente en Power Apps y verifica que se refleja en SharePoint.
  • 7. Si no tienes acceso, dibuja la arquitectura del sistema y describe el flujo de datos.

💡 Tips clave para la integración SharePoint + Power Apps + Power Automate:

• SharePoint: Base de datos donde se almacenan los incidentes.

• Power Apps: Interfaz de usuario para registrar, ver y editar incidentes.

• Power Automate: Automatización que notifica al responsable.

• Trigger del flujo: "Cuando se crea un elemento" en la lista "Incidentes".

• Acción del flujo: "Enviar un correo electrónico" al responsable.

• Campos dinámicos: Usar los datos del incidente en el correo.

• Probar: Registrar un incidente desde Power Apps y verificar el correo.

• Historial: Revisar ejecuciones en Power Automate para confirmar el éxito.

• Integración: Las tres herramientas se conectan a través de la lista de SharePoint.
