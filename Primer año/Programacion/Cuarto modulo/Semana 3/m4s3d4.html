📌 ¿Qué son las alertas en SharePoint?

Las alertas son notificaciones automáticas por correo electrónico que se envían cuando ocurren cambios en listas, bibliotecas o elementos específicos. Permiten a los usuarios mantenerse informados sin tener que revisar manualmente.

  • Tipos de alertas: A nivel de lista, biblioteca o elemento individual.
  • Frecuencia: Inmediata, diaria o semanal.
  • Eventos: Creación, modificación, eliminación o cambios de metadatos.

🔹 Tipos de alertas y casos de uso

📌 Alerta de lista / biblioteca

Descripción: Notifica sobre cualquier cambio en la lista o biblioteca completa.

Cuándo usarla: Cuando necesitas estar al tanto de todas las actividades en un repositorio compartido.

📂 Configurar alerta → Seleccionar "Lista completa"
📌 Alerta de elemento específico

Descripción: Notifica solo cuando se modifica un elemento en particular.

Cuándo usarla: Para seguimiento de tareas críticas, proyectos específicos o documentos clave.

📄 Seleccionar elemento → "Alert me" → Configurar alerta

🔹 Configurar una alerta en una lista

1
Acceder a la lista o biblioteca

Navegar hasta la lista o biblioteca donde se desea configurar la alerta.

2
Crear la alerta

En la cinta de opciones, seleccionar "Alertar" → "Alertar" (o "Alert me" en versiones antiguas) .

🔔 Alertar → Configurar alerta
3
Personalizar la alerta

Opciones de configuración:

  • Frecuencia: Inmediata, Resumen diario, Resumen semanal.
  • Eventos: Cambios en el elemento, cambios en metadatos, eliminación.
  • Destinatarios: Usuario actual o lista de correo (puede agregar otros).
  • Filtro: Solo cuando se cumplan ciertas condiciones (ej. solo proyectos "Activos").
📧 Frecuencia: Inmediata | Evento: Cambios en el elemento | Destinatario: usuario@empresa.com
4
Guardar la alerta

Hacer clic en "Aceptar" para crear la alerta. El usuario comenzará a recibir notificaciones según la configuración.

🔹 Ejemplo de notificación por correo

📧 Ejemplo de correo recibido:

De: SharePoint Alert <sharepoint@empresa.com>

Asunto: Alerta de SharePoint: "Proyecto Alpha" fue modificado

El elemento "Proyecto Alpha" en la lista "Proyectos" ha sido modificado.

Cambios realizados:

  • Estatus: Activo → Cerrado
  • Fecha de Fin: (vacío) → 15/06/2025

Para ver el elemento, haga clic aquí: [Enlace al elemento]

🔹 Gestión de alertas existentes

📌 Ver, editar o eliminar alertas

En Configuración → Configuración de alertas (o "My Alerts" en versiones clásicas) .

Desde allí se pueden:

  • Ver todas las alertas activas.
  • Editar la frecuencia o filtros.
  • Eliminar alertas que ya no sean necesarias.
⚙️ Configuración → Configuración de alertas → Gestionar alertas

🔹 Limitaciones y buenas prácticas

⚠️ Limitaciones a tener en cuenta
  • Volumen: Muchas alertas pueden saturar el correo.
  • Permisos: Solo se reciben alertas de elementos a los que se tiene acceso.
  • Personalización: No es posible modificar el cuerpo del correo.
  • Frecuencia: La opción "Inmediata" puede generar muchos correos en listas activas.
✅ Buenas prácticas
  • Usar filtros: Configurar alertas solo para cambios relevantes (ej. solo proyectos activos) .
  • Elegir frecuencia adecuada: Usar resumen diario/semanal para listas con muchos cambios.
  • Limitar alertas: No activar alertas para todo, solo para elementos críticos.
  • Revisar periódicamente: Limpiar alertas que ya no sean necesarias.
  • Comunicar: Informar al equipo sobre las alertas configuradas.

💡 Tips clave sobre alertas en SharePoint:

• Alertas de lista: Notifican sobre cualquier cambio en la lista completa.

• Alertas de elemento: Notifican solo sobre cambios en un elemento específico.

• Frecuencia: Inmediata, diaria o semanal. Elige según la actividad de la lista.

• Eventos: Creación, modificación, eliminación o cambios en metadatos.

• Filtros: Usa filtros para reducir el ruido (ej. solo proyectos activos).

• Gestión: Revisa periódicamente tus alertas para eliminar las innecesarias.

• Permisos: Solo recibes alertas de elementos a los que tienes acceso.
