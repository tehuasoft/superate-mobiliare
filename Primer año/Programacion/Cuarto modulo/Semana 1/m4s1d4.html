📄 PLANIFICACIÓN DE CLASE

Diseño de Páginas en SharePoint · Web Parts · Personalización visual

🎯 Competencia General

El estudiante aprende a diseñar páginas en SharePoint Online agregando y configurando web parts (bibliotecas de documentos, texto, imágenes, enlaces rápidos), y aplica personalización visual básica para mejorar la apariencia y usabilidad del sitio.

📖 Conceptuales (Saber)

  • Comprende la estructura de una página en SharePoint.
  • Reconoce los web parts más comunes: documentos, texto, imágenes, enlaces rápidos.
  • Identifica opciones de personalización visual (colores, diseño).

🛠️ Procedimentales (Saber hacer)

  • Crear y editar páginas en SharePoint.
  • Agregar y configurar web parts de biblioteca de documentos, texto, imágenes y enlaces rápidos.
  • Aplicar personalización visual básica (cambiar colores, ajustar diseño).
  • Organizar el contenido de una página de manera efectiva.

❤️ Actitudinales (Saber ser)

  • Muestra interés por el diseño de interfaces colaborativas.
  • Valora la importancia de una buena presentación visual.
  • Participa activamente en la práctica guiada.
  • Desarrolla habilidades de diseño y organización.

🔹 Crear una nueva página

📌 Pasos para crear una página
  1. Ir al sitio de equipo.
  2. Hacer clic en "+ Nuevo" → "Página".
  3. Elegir una plantilla (en blanco o con secciones predefinidas).
  4. Asignar un nombre a la página (ej. "Bienvenida", "Documentos del Proyecto").
  5. Hacer clic en "Crear".

🔹 Agregar Web Parts

📂 Web Part: Biblioteca de documentos

Muestra archivos almacenados en una biblioteca específica. Permite a los usuarios ver y acceder a documentos directamente desde la página.

Configuración:

  • Seleccionar la biblioteca de documentos que se desea mostrar.
  • Elegir vista (ej. "Todos los documentos", "Documentos recientes").
  • Definir tamaño y diseño (lista, mosaicos, etc.).

📝 Web Part: Texto

Permite agregar contenido escrito, instrucciones, descripciones o encabezados. Se puede formatear con negrita, listas, enlaces, etc.

Configuración:

  • Escribir el texto deseado.
  • Aplicar formato usando la barra de herramientas (negrita, viñetas, alineación).
  • Insertar enlaces a otros sitios o documentos.

🖼️ Web Part: Imagen

Inserta imágenes para hacer la página más visual. Puede ser un logotipo, una foto del equipo o un gráfico.

Configuración:

  • Seleccionar "Agregar imagen" y subir una imagen o elegir una existente.
  • Ajustar tamaño y alineación.
  • Agregar texto alternativo (accesibilidad).

🔗 Web Part: Enlaces rápidos

Proporciona acceso directo a otras páginas, sitios o recursos importantes. Mejora la navegación.

Configuración:

  • Agregar enlaces con nombre y URL.
  • Elegir diseño (lista, mosaicos, iconos).

🔹 Personalización visual básica

🎨 Cambiar colores y diseño

SharePoint permite ajustar la apariencia de la página para alinearla con la marca o preferencias del equipo.

Opciones disponibles:

  • Tema: Cambiar el color principal y los acentos.
  • Fondo: Seleccionar un color de fondo o imagen.
  • Diseño de secciones: Elegir entre una, dos o tres columnas.
  • Espaciado: Ajustar márgenes y padding.

📝 Actividad práctica

Instrucciones:

  • 1. Si tienes acceso a SharePoint, crea una nueva página en tu Sitio de Equipo.
  • 2. Agrega al menos los siguientes web parts:
    • Texto (con un mensaje de bienvenida).
    • Imagen (sube una imagen de prueba o usa un enlace).
    • Biblioteca de documentos (muestra la biblioteca predeterminada).
    • Enlaces rápidos (agrega 3 enlaces a sitios útiles).
  • 3. Personaliza la página: cambia el tema o colores, ajusta el diseño de secciones (usa 2 columnas).
  • 4. Publica la página y comparte el enlace con la clase (o describe tu diseño si no tienes acceso).

Preguntas de reflexión:

  • ¿Qué web part consideras más importante para una página de inicio?
  • ¿Cómo afecta la personalización visual a la percepción del sitio?
  • ¿Por qué es útil usar enlaces rápidos en una página?

💡 Tips clave para diseñar páginas en SharePoint:

• Web part de documentos: Muestra archivos relevantes para el equipo.

• Web part de texto: Explica el propósito de la página o da instrucciones.

• Web part de imagen: Aporta contexto visual y hace la página más atractiva.

• Enlaces rápidos: Mejora la navegación y acceso a recursos.

• Personalización: Usa colores y diseño para alinear la página con la identidad del equipo.

• Organización: Distribuye el contenido en secciones y columnas para facilitar la lectura.
