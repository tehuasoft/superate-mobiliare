📌 ¿Qué es Microsoft Power Automate?

Power Automate es un servicio en la nube que permite crear flujos de trabajo automatizados entre aplicaciones y servicios, sin necesidad de programar código complejo. Conecta cientos de aplicaciones como SharePoint, Outlook, Teams, Excel, y más.

  • Objetivo: Automatizar tareas repetitivas y conectar servicios.
  • Beneficio: Ahorra tiempo, reduce errores y aumenta la productividad.
  • Acceso: Desde make.powerautomate.com.

🔹 Tipos de flujos en Power Automate

🤖 Flujo Automatizado

Disparador: Un evento automático (ej. se crea un elemento, llega un correo, se modifica un archivo).

Cuándo usar: Cuando quieres que algo ocurra sin intervención manual.

Ejemplo: Cuando se agrega un elemento a la lista "Proyectos", enviar un correo al propietario.

⚡ Flujo Instantáneo

Disparador: Una acción manual del usuario (ej. presionar un botón en la app móvil, en Teams, o en SharePoint).

Cuándo usar: Cuando el usuario decide cuándo ejecutar el flujo.

Ejemplo: Botón "Solicitar aprobación" que el usuario presiona manualmente.

📅 Flujo Programado

Disparador: Una programación de fecha/hora (ej. todos los lunes a las 9 AM, cada día a medianoche).

Cuándo usar: Cuando quieres que algo ocurra en un horario específico.

Ejemplo: Enviar un resumen semanal de proyectos cada lunes.

📌 ¿Cómo elegir el tipo de flujo?
  • ¿El flujo debe ejecutarse solo cuando ocurre un evento? → Automatizado.
  • ¿El usuario debe presionar un botón para ejecutarlo? → Instantáneo.
  • ¿Debe ejecutarse en un horario específico? → Programado.
  • ¿Debe ejecutarse desde una app de Power Apps? → Instantáneo (Power Apps trigger).
  • ¿Debe ejecutarse desde una app de escritorio o móvil? → Instantáneo (botón).

🔹 Estructura de un flujo: Trigger + Actions

Todo flujo en Power Automate tiene dos partes fundamentales:

🎯 TRIGGER
Disparador
¿Cuándo se ejecuta?
→
⚙️ ACTION 1
Acción
¿Qué hace?
→
⚙️ ACTION 2
Acción
¿Qué más hace?
🎯 Trigger (Disparador)

Es el evento que inicia el flujo. Sin un trigger, el flujo nunca se ejecuta. Define el "cuándo" y el "cómo" comienza la automatización.

Ejemplos de triggers:

  • Cuando se crea un elemento en una lista de SharePoint.
  • Cuando llega un nuevo correo electrónico.
  • Cuando se presiona un botón en Power Apps.
  • Todos los días a las 9:00 AM.
⚙️ Actions (Acciones)

Son las tareas que ejecuta el flujo después de que se dispara. Puede haber una o muchas acciones, ejecutadas en orden.

Ejemplos de acciones:

  • Enviar un correo electrónico.
  • Crear un elemento en una lista.
  • Actualizar un campo.
  • Publicar un mensaje en Teams.
  • Crear un archivo en OneDrive.
  • Iniciar una aprobación.
📌 Ejemplo completo de flujo:
🎯 Trigger: Cuando se agrega un elemento a la lista "Proyectos"
⚙️ Action 1: Enviar un correo al propietario del proyecto
⚙️ Action 2: Publicar un mensaje en el canal de Teams
⚙️ Action 3: Crear una tarea en Planner

🔹 Explorar el entorno de Power Automate

1
Acceder al portal

Ingresar a make.powerautomate.com con la cuenta organizativa de Microsoft 365.

🌐 https://make.powerautomate.com
2
Explorar el menú principal

En el menú izquierdo, identificar las secciones:

  • Inicio: Resumen y flujos recientes.
  • Crear: Iniciar un nuevo flujo.
  • Mis flujos: Ver y gestionar flujos existentes.
  • Plantillas: Flujos predefinidos listos para usar.
  • Conectores: Servicios disponibles para conectar.
📂 Menú: Inicio | Crear | Mis flujos | Plantillas | Conectores | Aprobaciones
3
Explorar opciones de creación

Hacer clic en "Crear" y observar las opciones disponibles:

  • Flujo automatizado: Se inicia con un evento.
  • Flujo instantáneo: Se inicia manualmente.
  • Flujo programado: Se inicia según horario.
  • Flujo de botón: Se inicia desde un botón.
  • Flujo desde plantilla: Usar plantilla predefinida.
🚀 Crear → Flujo automatizado | Flujo instantáneo | Flujo programado | Flujo de botón
4
Explorar un flujo de ejemplo

Seleccionar "Flujo automatizado" y buscar el trigger "Cuando se crea un elemento" (SharePoint). Observar cómo se estructura el flujo con Trigger y Actions.

🔍 Trigger: "Cuando se crea un elemento" → SharePoint

💡 Tips clave sobre Power Automate:

• Power Automate: Servicio para automatizar flujos de trabajo.

• Flujo Automatizado: Se inicia con un evento (ej. nuevo elemento).

• Flujo Instantáneo: Se inicia manualmente (ej. botón).

• Flujo Programado: Se inicia en un horario específico.

• Trigger: Evento que inicia el flujo (¿cuándo?).

• Actions: Tareas que ejecuta el flujo (¿qué hace?).

• Conectores: Servicios que se conectan (SharePoint, Outlook, Teams, etc.).

• make.powerautomate.com: Portal de creación de flujos.

🔥 Esta clase es clave porque:

• Introduce la automatización de procesos, fundamental en entornos laborales.

• Conecta aplicaciones y servicios de Microsoft.

• Prepara a los estudiantes para crear soluciones que ahorren tiempo y reduzcan errores.

• Sienta las bases para flujos más complejos en clases futuras.
