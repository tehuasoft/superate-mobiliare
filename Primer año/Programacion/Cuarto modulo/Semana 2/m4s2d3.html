El docente pregunta: "Si tuvieras que crear una lista para registrar los libros de una biblioteca, ¿qué información necesitarías guardar? ¿Qué tipos de datos serían?" Se introduce el concepto de columnas como los "campos" de la lista.

📌 ¿Qué es una columna en SharePoint?

Una columna es un campo de datos que define un tipo específico de información dentro de una lista. Cada columna tiene un tipo que determina qué tipo de datos puede almacenar (texto, números, fechas, etc.).

Tipos de columnas que veremos:

  • Texto — Texto simple o varias líneas.
  • Número — Valores numéricos (enteros o decimales).
  • Fecha — Fechas y horas.
  • Elección — Selección de una o más opciones.
  • Persona o Grupo — Usuarios o grupos de la organización.
  • Sí/No — Valor booleano (verdadero/falso).

🔹 Crear una lista desde cero

📌 Pasos para crear una lista desde cero:
  1. Ir al sitio de SharePoint.
  2. Hacer clic en "+ Nuevo" → "Lista".
  3. Seleccionar "Lista en blanco".
  4. Asignar un nombre a la lista (ej. "Inventario de Productos").
  5. Hacer clic en "Crear".

🔹 Tipos de columnas en detalle

📝 Texto

Permite almacenar texto simple o varias líneas. Es el tipo más común.

Configuración:

  • Línea de texto (hasta 255 caracteres).
  • Varias líneas (texto largo, con formato).
  • Opcional: longitud máxima, validación.

Ejemplo de uso: "Nombre del producto", "Descripción", "Comentarios".

🔢 Número

Almacena valores numéricos (enteros o decimales).

Configuración:

  • Número entero o decimal.
  • Rango mínimo y máximo.
  • Formato (moneda, porcentaje, etc.).

Ejemplo de uso: "Cantidad", "Precio", "Porcentaje de avance".

📅 Fecha

Almacena fechas y opcionalmente horas.

Configuración:

  • Fecha y hora (opcional).
  • Formato de fecha (localizado).
  • Valor predeterminado (fecha actual).

Ejemplo de uso: "Fecha de vencimiento", "Fecha de creación", "Fecha de entrega".

☑️ Elección

Permite seleccionar una o varias opciones de una lista predefinida.

Configuración:

  • Opciones (separadas por punto y coma).
  • Selección única o múltiple.
  • Posibilidad de permitir valores personalizados.

Ejemplo de uso: "Estado" (Pendiente, En progreso, Completado), "Categoría".

👤 Persona o Grupo

Permite seleccionar usuarios o grupos de la organización.

Configuración:

  • Selección de una persona o grupo.
  • Mostrar nombre, correo, etc.
  • Posibilidad de selección múltiple.

Ejemplo de uso: "Asignado a", "Responsable", "Aprobador".

🔘 Sí/No

Almacena un valor booleano (verdadero/falso).

Configuración:

  • Valor predeterminado (Sí o No).
  • Se muestra como checkbox.

Ejemplo de uso: "Activo", "Completado", "Aprobado", "En oferta".

📝 Actividad práctica

Instrucciones:

  • 1. Si tienes acceso a SharePoint, crea una lista desde cero con el nombre "Proyectos".
  • 2. Agrega las siguientes columnas:
    • Nombre del proyecto (Texto — línea de texto)
    • Descripción (Texto — varias líneas)
    • Presupuesto (Número — decimal)
    • Fecha de inicio (Fecha)
    • Fecha de fin (Fecha)
    • Estado (Elección — Planeado, En curso, Finalizado, Cancelado)
    • Líder del proyecto (Persona o Grupo)
    • Prioritario (Sí/No)
  • 3. Agrega al menos 3 proyectos de ejemplo.
  • 4. Si no tienes acceso, diseña en papel la estructura de la lista con las columnas y 3 registros.

💡 Tips clave sobre tipos de columnas en SharePoint:

• Texto: Para nombres, descripciones, comentarios.

• Número: Para cantidades, precios, porcentajes.

• Fecha: Para fechas de inicio, vencimiento, entrega.

• Elección: Para categorías, estados, prioridades.

• Persona o Grupo: Para asignaciones, responsables.

• Sí/No: Para indicadores binarios (activo, completado).

• Elige el tipo correcto según el dato que quieras guardar.
