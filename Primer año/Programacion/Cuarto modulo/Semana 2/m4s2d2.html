📌 ¿Qué es una lista de SharePoint (PowerList)?

Es una base de datos estructurada dentro de SharePoint que permite almacenar, organizar y compartir información de manera colaborativa. Cada elemento de la lista es como una "fila" con columnas que definen los datos.

Usos comunes:

  • Seguimiento de tareas y proyectos.
  • Gestión de solicitudes y aprobaciones.
  • Inventario de recursos.
  • Registro de contactos y clientes.

🔹 Comparativa: Lista de SharePoint vs Excel

📊 Excel

Ventajas:

  • ✅ Fácil de usar para análisis y cálculos.
  • ✅ Herramienta conocida por casi todos.
  • ✅ Funciones avanzadas (gráficos, fórmulas).

Desventajas:

  • ❌ No es colaborativo en tiempo real (requiere guardar y compartir archivos).
  • ❌ Puede haber conflictos de versiones.
  • ❌ Sin historial de cambios ni permisos granulares.
📋 Lista de SharePoint

Ventajas:

  • ✅ Colaboración en tiempo real (varios usuarios editando).
  • ✅ Permisos por fila o columna.
  • ✅ Historial de cambios y versiones.
  • ✅ Integración con Power Automate, Power Apps, Teams.
  • ✅ Alertas y notificaciones automáticas.

Desventajas:

  • ❌ Menos funcionalidades de análisis que Excel.
  • ❌ Curva de aprendizaje inicial.

🔹 Plantillas de listas en SharePoint

📌 Plantillas predefinidas

SharePoint ofrece varias plantillas para crear listas rápidamente. Algunas de las más comunes:

  • Seguimiento de tareas: Gestiona asignaciones, fechas y estados.
  • Calendario: Eventos y fechas importantes.
  • Contactos: Gestión de personas y organizaciones.
  • Inventario: Seguimiento de productos o recursos.
  • Problemas: Registro y seguimiento de incidencias.

🔹 Creación de lista desde la plantilla "Seguimiento de tareas"

📌 Plantilla: Seguimiento de tareas

Columnas predefinidas:

📝 Título 👤 Asignado a 📊 Estado 📅 Fecha de vencimiento 📝 Descripción ⏱️ % completado

Incluye columnas clave para gestionar tareas de forma colaborativa.

Pasos para crear la lista:

  1. Ir al sitio de SharePoint donde se creará la lista.
  2. Hacer clic en "+ Nuevo" → "Lista".
  3. En el panel, seleccionar "Desde una plantilla".
  4. Elegir la plantilla "Seguimiento de tareas".
  5. Asignar un nombre a la lista (ej. "Tareas del Proyecto Alpha").
  6. Hacer clic en "Crear".

📝 Actividad práctica

Instrucciones:

  • 1. Si tienes acceso a SharePoint, crea una lista usando la plantilla "Seguimiento de tareas".
  • 2. Asígnale un nombre relacionado con un proyecto ficticio (ej. "Tareas del Proyecto Innovación").
  • 3. Agrega al menos 5 tareas con diferentes asignados, estados y fechas de vencimiento.
  • 4. Comparte la lista con un compañero (simula colaboración) y edita una tarea.
  • 5. Si no tienes acceso, dibuja en papel la estructura de la lista con 5 tareas ficticias.

💡 Tips clave sobre listas de SharePoint:

• Una lista es una base de datos colaborativa en SharePoint.

• A diferencia de Excel, permite edición simultánea y permisos granulares.

• Las plantillas ahorran tiempo al crear listas comunes.

• La plantilla "Seguimiento de tareas" es ideal para gestión de proyectos.

• Columnas clave: Título, Asignado a, Estado, Fecha de vencimiento.

• Las listas se integran con Teams, Power Automate y Power Apps.
