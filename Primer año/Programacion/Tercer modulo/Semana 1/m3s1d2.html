🟢 INICIO 15 minutos

Actividad: "¿Qué es flashear y por qué copiar no es suficiente?"

Metodología: Cuestionamiento y explicación conceptual.

Descripción: El docente plantea preguntas:

  • ¿Alguna vez has copiado un archivo a un USB? ¿Crees que eso es suficiente para hacerlo booteable?
  • ¿Qué diferencia hay entre "copiar" un archivo y "flashear" una imagen?
  • ¿Qué significa que un USB sea "booteable"?

Se introduce el concepto de flasheo como el proceso de escribir una imagen ISO directamente en los sectores del USB, incluyendo el sector de arranque, para que la computadora pueda reconocerlo como un dispositivo desde el cual iniciar.

📄 Copiar archivos
  • Solo copia el contenido visible.
  • No escribe el sector de arranque.
  • El USB no es booteable.
  • Ejemplo: Arrastrar archivos .iso al USB.
⚡ Flashear (Escribir imagen)
  • Escribe la ISO completa bit a bit.
  • Incluye el sector de arranque.
  • El USB se vuelve booteable.
  • Ejemplo: Usar Rufus, Etcher, Fedora Media Writer.
💡 Analogía:
Copiar un archivo .iso a un USB es como poner un libro dentro de una caja. Flashear es como grabar el libro directamente en el disco para que el reproductor pueda leerlo correctamente.

Aprendizaje esperado

El estudiante comprende la diferencia entre copiar y flashear, y por qué el flasheo es necesario para crear un USB booteable.

Criterios de evaluación

  • Participa en la discusión inicial.

🟡 DESARROLLO 35 minutos

Actividad: "Flasheando la USB con Rufus e intentando el Live de Fedora"

Metodología: Demostración guiada paso a paso + práctica.

🔹 Preparación

Cada estudiante debe tener:

  • La ISO de Fedora copiada en su computadora (de la clase anterior).
  • Una USB (mínimo 8 GB) que el maestro proporcionará.
  • Rufus instalado en Windows (instalado en clase anterior).

🔹 Rufus - La herramienta para flashear

Rufus es una herramienta gratuita y muy popular para crear USB booteables en Windows. Escribe la ISO directamente en el USB.

🔹 Paso a paso para flashear con Rufus

  1. Conectar la USB a la computadora.
  2. Abrir Rufus (se puede descargar desde https://rufus.ie).
  3. Seleccionar el dispositivo (Device): Asegurarse de que la USB esté seleccionada. ¡Cuidado de no seleccionar el disco duro!
  4. Seleccionar la ISO (Boot selection): Hacer clic en "SELECCIONAR" y elegir la ISO de Fedora que copiaste en tu computadora.
  5. Esquema de partición (Partition scheme):
    • MBR para sistemas BIOS/Legacy (computadoras más antiguas).
    • GPT para sistemas UEFI (la mayoría de las computadoras modernas).
  6. Hacer clic en "EMPEZAR" (Start): Rufus mostrará un diálogo con opciones:
    • "Escribir en modo ISO" (Write in ISO mode): Recomendado para la mayoría de los casos.
    • "Escribir en modo DD" (Write in DD mode): Útil si el modo ISO falla, pero menos común.
  7. Confirmar que se borrarán todos los datos de la USB.
  8. Esperar a que termine el proceso: Puede tomar varios minutos. La barra de progreso mostrará el avance.
  9. Verificar que el proceso fue exitoso: Al finalizar, Rufus mostrará un mensaje de "LISTO" (READY).

⚠️ ¡Cuidado con la selección del dispositivo!

Rufus muestra todos los discos conectados. Asegúrate de que el "Device" sea tu USB (por su tamaño y nombre) y no el disco duro interno. ¡Seleccionar el disco equivocado puede borrar todo tu sistema operativo!

🔹 Intentar arrancar Fedora Live desde la USB

Ahora que la USB está flasheada, intentamos arrancar el entorno Live.

  1. Reiniciar la computadora con la USB conectada.
  2. Presionar la tecla de Boot Menu (F12, F10, ESC, F2, DEL, depende de la marca) inmediatamente después de encender.
  3. Seleccionar la USB en el menú de dispositivos de arranque.
  4. Si todo funciona: Aparecerá el menú de arranque de Fedora. Seleccionar "Start Fedora Workstation Live".
  5. Si no funciona o es complicado: La computadora puede tener Secure Boot activado, Boot Lock habilitado, o el orden de arranque no prioriza el USB. En ese caso, no forzarlo; lo resolveremos en la siguiente clase.
📌 ¿Qué es el Boot Lock?
El Boot Lock es una función de seguridad que evita que la computadora arranque desde dispositivos externos (como USB) sin autorización. Esto es común en computadoras de empresas o con configuraciones de seguridad avanzadas. Si la computadora tiene Boot Lock activado, solo se puede arrancar desde el disco duro interno.

⚠️ ¡Importante!

Algunas computadoras tienen Secure Boot habilitado, lo que impide que Fedora Live arranque desde USB. También puede ser que el orden de arranque en la BIOS/UEFI no incluya el USB como prioridad.

Si no puedes arrancar el Live, no te preocupes. En la próxima clase configuraremos la BIOS/UEFI para solucionarlo e instalaremos Fedora.

📝 Actividad práctica

Realiza los siguientes pasos en tu computadora:

  • Conecta la USB que te proporcionó el maestro.
  • Abre Rufus y selecciona la USB como dispositivo.
  • Selecciona la ISO de Fedora que copiaste en la clase anterior.
  • Elige el esquema de partición (MBR o GPT según tu computadora).
  • Haz clic en "EMPEZAR" y espera a que termine el flasheo.
  • Una vez terminado, reinicia la computadora.
  • Presiona la tecla de Boot Menu e intenta arrancar desde la USB.
  • Si arranca correctamente, explora el entorno Live por unos minutos.
  • Si no arranca, anota qué mensaje aparece o qué ocurre.

Preguntas de reflexión:

  • ¿Qué opciones seleccionaste en Rufus (ISO mode o DD mode)?
  • ¿Qué tecla usaste para entrar al Boot Menu?
  • ¿Pudiste arrancar Fedora Live? ¿Qué pasó?
  • ¿Crees que tu computadora tiene Boot Lock o Secure Boot activado?

💡 Tips clave:

• Flashear ≠ Copiar: Flashear es escribir la ISO directamente en el USB, incluyendo el sector de arranque.

• Rufus es la herramienta más popular en Windows para flashear ISOs.

• Teclas de Boot Menu comunes: F12, F10, ESC, F2, DEL (varía según la marca).

• Secure Boot y Boot Lock pueden bloquear el arranque de Fedora Live. Se desactivan en la BIOS/UEFI.

• Si no arrancó: No te preocupes, en la siguiente clase configuraremos la BIOS/UEFI.

• Siempre verifica el dispositivo en Rufus para no borrar el disco duro por accidente.
