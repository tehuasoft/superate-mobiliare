🟡 DESARROLLO 60 minutos

🔹 Parte 1: Instalar Ventoy en la USB

1
Verificar que ya tiene Ventoy en su carpeta de Documentos

Ir a Documents y verificar que tenga el archivo necesario para poder instalar Ventoy.

Documents → Doble click en el programa o descomprimir el archivo ventoy-x.x.x-windows.zip
2
Instalar Ventoy en la USB

Conectar una USB (mínimo 16 GB) y ejecutar Ventoy2Disk.exe. Seleccionar la USB y hacer clic en "Install".

💾 Ventoy2Disk.exe → Seleccionar USB → Install

⚠️ Advertencia: Esto formateará la USB. Asegurarse de que no tenga datos importantes.

3
Copiar la ISO de Windows

Copiar el archivo ISO de Windows a la partición "Ventoy" de la USB.

💿 Copiar: Windows.iso → USB (partición Ventoy)
4
Copiar la ISO de Fedora

Copiar el archivo ISO de Fedora a la misma partición de Ventoy.

🐧 Copiar: Fedora.iso → USB (partición Ventoy)
💾 USB - Ventoy 📁
📁 ventoy —
💿 Windows.iso 5.2 GB
🐧 Fedora.iso 2.1 GB

↑ USB con Ventoy y las ISOs copiadas.

🔹 Parte 2: Configurar el BIOS/UEFI para arrancar desde USB

🔧 Acceder al BIOS/UEFI

Al encender la computadora, presionar la tecla correspondiente según el fabricante:

  • HP: F10 o Esc
  • Dell: F2 o F12
  • Lenovo: F1 o F2
  • Asus: F2 o Del
  • Acer: F2 o Del
⚙️ Configurar opciones de arranque

Buscar las siguientes opciones en el BIOS:

  • Boot Mode: UEFI (recomendado) o Legacy.
  • Secure Boot: Desactivar (Disable) para permitir arrancar desde USB.
  • Boot Order: Poner la USB en primer lugar.
  • Fast Boot: Desactivar si no detecta la USB.
📌 ¿Qué es Secure Boot?

Secure Boot es una característica de UEFI que impide que se carguen sistemas operativos no firmados. Para instalar Linux o arrancar desde USB, a veces es necesario desactivarlo.

Pasos: Ir a Security → Secure Boot → Disabled.

🔹 Parte 3: Desactivar BitLocker (evitar que pida clave)

5
Abrir la terminal como administrador

Una vez iniciado el instalador de Windows (o antes de instalar), abrir la terminal con Shift + F10.

⌨️ Shift + F10 → Símbolo del sistema
6
Ejecutar el comando para desactivar BitLocker

En la terminal, escribir el siguiente comando y presionar Enter:

Rojo: escribir en la terminal
Verde: respuesta esperada si todo sale bien
X:\Sources> reg add "HKLM\SYSTEM\CurrentControlSet\Control\BitLocker" /v PreventDeviceEncryption /t REG_DWORD /d 1 /f The operation completed successfully.
📌 ¿Qué hace este comando?

Modifica el registro de Windows para prevenir la encriptación automática del disco con BitLocker. Esto evita que al iniciar Windows nos pida una clave de recuperación.

🔹 Parte 4: Crear las particiones con DiskPart

7
Iniciar DiskPart

En la misma terminal, escribir diskpart y presionar Enter.

X:\Sources> diskpart Microsoft DiskPart version 10.0.xxxxx Copyright (C) Microsoft Corporation. On computer: MININT-XXXXX DISKPART>
8
Listar los discos

Escribir list disk para ver los discos disponibles.

DISKPART> list disk Disk ### Status Size Free Dyn Gpt -------- ------------- ------- ------- --- --- Disk 0 Online 476 GB 0 B *
9
Seleccionar el disco 0

Escribir select disk 0 para seleccionar el disco principal.

DISKPART> select disk 0 Disk 0 is now the selected disk.
10
Limpiar el disco

Escribir clean para borrar todas las particiones existentes.

DISKPART> clean DiskPart succeeded in cleaning the disk.
11
Convertir a GPT

Escribir convert gpt para convertir el disco al formato GPT (necesario para UEFI).

DISKPART> convert gpt DiskPart successfully converted the selected disk to GPT format.
12
Crear partición EFI (500 MB)

Escribir create partition efi size=500.

DISKPART> create partition efi size=500 DiskPart succeeded in creating the specified partition.
13
Formatear la partición EFI

Escribir format quick fs=fat32 label="EFI".

DISKPART> format quick fs=fat32 label="EFI" 100 percent completed DiskPart successfully formatted the volume.
14
Asignar letra S a la partición EFI

Escribir assign letter=S.

DISKPART> assign letter=S DiskPart successfully assigned the drive letter or mount point.
15
Crear partición MSR (16 MB)

Escribir create partition msr size=16.

DISKPART> create partition msr size=16 DiskPart succeeded in creating the specified partition.
16
Crear partición primaria para Windows (200 GB)

Escribir create partition primary size=200000 (200 GB en MB).

DISKPART> create partition primary size=200000 DiskPart succeeded in creating the specified partition.
17
Formatear la partición de Windows

Escribir format quick fs=ntfs label="Windows".

DISKPART> format quick fs=ntfs label="Windows" 100 percent completed DiskPart successfully formatted the volume.
18
Asignar letra C a la partición de Windows

Escribir assign letter=C.

DISKPART> assign letter=C DiskPart successfully assigned the drive letter or mount point.
19
Salir de DiskPart

Escribir exit para salir de DiskPart.

DISKPART> exit Leaving DiskPart...

🔹 Estructura de particiones creada

📌 Particiones creadas:
  • EFI (500 MB): Para el arranque UEFI (letra S).
  • MSR (16 MB): Reservada por Microsoft.
  • Windows (200 GB): Para el sistema operativo Windows (letra C).
  • Espacio libre: El resto del disco quedará sin asignar para instalar Fedora.

⚠️ Importante: No se debe crear partición para el espacio restante, debe quedar libre para Fedora.

🔹 Parte 5: Instalar Windows

20
Continuar con la instalación de Windows

Cerrar la terminal (si es necesario) y continuar con el asistente de instalación de Windows. Seleccionar la partición "Windows" (200 GB) como destino.

💿 Instalador de Windows → Seleccionar partición → Instalar
21
Verificar que BitLocker no se active

Después de instalar, verificar en Configuración → Privacidad y seguridad → Cifrado de dispositivo que BitLocker esté desactivado.

⚙️ Configuración → Cifrado de dispositivo → Desactivado

📝 Actividad práctica: Instalación guiada

Instrucciones:

  • 1. Instalar Ventoy en la USB y copiar las ISOs de Windows y Fedora.
  • 2. Reiniciar la computadora y acceder al BIOS/UEFI.
  • 3. Configurar el BIOS: desactivar Secure Boot, poner USB como primer dispositivo de arranque.
  • 4. Iniciar desde la USB y seleccionar la ISO de Windows en Ventoy.
  • 5. Abrir la terminal con Shift + F10 y ejecutar el comando de registro para desactivar BitLocker.
  • 6. Ejecutar DiskPart y crear las particiones: EFI (500 MB), MSR (16 MB), Windows (200 GB).
  • 7. Continuar con la instalación de Windows en la partición creada.
  • 8. Verificar que el espacio libre restante quede sin asignar para Fedora.
  • 9. Si no tienes acceso a una computadora para practicar, documenta los pasos y comandos utilizados.

💡 Tips clave para la instalación de Windows y preparación del dual boot:

• Ventoy: Instalar en USB y copiar las ISOs de Windows y Fedora.

• BIOS/UEFI: Desactivar Secure Boot y poner USB como primer dispositivo de arranque.

• BitLocker: Ejecutar el comando de registro para prevenir la encriptación.

• DiskPart: clean → convert gpt → crear particiones EFI, MSR y Windows.

• EFI: 500 MB, FAT32, letra S.

• MSR: 16 MB (reservada por Microsoft).

• Windows: 200 GB, NTFS, letra C.

• Espacio libre: No asignar, dejar para Fedora.

• Instalar Windows: Seleccionar la partición de 200 GB.

• Verificar: BitLocker desactivado y espacio libre disponible.

• Próxima clase: Instalación de Fedora en el espacio libre.
