📘 PLANIFICACIÓN DE CLASE

Tema: Instalación de Fedora - Configuración de BIOS/UEFI e instalación como sistema operativo principal

🎯 Competencia General

Configura la BIOS/UEFI de la computadora para permitir el arranque desde USB, comprende las diferencias entre BIOS Legacy y UEFI, e instala Fedora como sistema operativo principal en el disco duro, siguiendo el proceso guiado del instalador Anaconda.

📖 Conceptuales (Saber)

  • Comprende la diferencia entre BIOS Legacy y UEFI.
  • Reconoce que la interfaz de la BIOS/UEFI varía según el fabricante.
  • Identifica las opciones clave: Secure Boot, orden de arranque, modo de arranque (UEFI/Legacy).
  • Entiende la estructura del instalador Anaconda de Fedora.

🛠️ Procedimentales (Saber hacer)

  • Acceder a la BIOS/UEFI usando la tecla correcta según la marca (F2, DEL, F10, ESC).
  • Deshabilitar Secure Boot para permitir el arranque desde USB.
  • Configurar el orden de arranque para priorizar el USB.
  • Seleccionar el modo de arranque adecuado (UEFI o Legacy).
  • Iniciar el instalador de Fedora desde el USB.
  • Realizar la instalación guiada de Fedora en el disco duro.

❤️ Actitudinales (Saber ser)

  • Muestra paciencia al explorar la interfaz de la BIOS/UEFI.
  • Sigue las instrucciones con atención y precisión.
  • Comparte experiencias y ayuda a compañeros con diferentes modelos.
  • Valora la importancia de la configuración correcta para la instalación.
🟢 INICIO 15 minutos

Actividad: "¿Qué es la BIOS/UEFI y por qué debemos configurarla?"

Metodología: Cuestionamiento y explicación conceptual.

Descripción: El docente explica la importancia de la BIOS/UEFI:

  • BIOS (Basic Input/Output System): Firmware tradicional que inicializa el hardware y arranca el sistema operativo.
  • UEFI (Unified Extensible Firmware Interface): Reemplazo moderno de la BIOS, con interfaz gráfica, soporte para discos GPT y arranque más rápido.
  • Secure Boot: Funcionalidad UEFI que previene la ejecución de software no autorizado durante el arranque. Puede bloquear el arranque desde USB.

Se enfatiza que la interfaz de la BIOS/UEFI varía según el fabricante (Dell, HP, Lenovo, ASUS, Acer, etc.), por lo que no hay una sola forma de configurarla.

💡 Teclas comunes para acceder a la BIOS/UEFI:
Dell: F2 o DEL  |  HP: F10 o ESC  |  Lenovo: F2 o Fn+F2  |  ASUS: F2 o DEL  |  Acer: F2  |  Mac: Option (⌥) al encender.

🟡 DESARROLLO 35 minutos

Actividad: "Configurando BIOS/UEFI e instalando Fedora"

Metodología: Demostración guiada paso a paso + práctica individual.

🔹 Paso 1: Acceder a la BIOS/UEFI

  1. Conectar la USB con Fedora a la computadora.
  2. Reiniciar la computadora.
  3. Presionar repetidamente la tecla de acceso a la BIOS/UEFI inmediatamente después de encender. Las teclas más comunes son F2, DEL, F10, ESC. En Mac, presionar Option (⌥).
  4. Identificar el menú principal de la BIOS/UEFI. La interfaz puede ser gráfica (UEFI) o de texto (BIOS Legacy).

⚠️ Nota: Si no puedes acceder a la BIOS/UEFI en el primer intento, reinicia y prueba otra tecla. El tiempo para presionar la tecla es muy corto; a veces hay que presionarla inmediatamente después del primer sonido o logo.

🔹 Paso 2: Configuración en la BIOS/UEFI

Una vez dentro, hay que ajustar varias opciones para permitir la instalación de Fedora.

🟢 Deshabilitar Secure Boot

Secure Boot puede impedir que Fedora arranque desde el USB.

  • Buscar "Secure Boot" en el menú.
  • Cambiar a "Disabled".
  • En algunos equipos está dentro de "Boot" o "Security".
🟡 Cambiar orden de arranque (Boot Order)

La computadora debe arrancar desde el USB antes que el disco duro.

  • Buscar "Boot Order" o "Boot Priority".
  • Mover el USB al primer lugar de la lista.
  • En algunos equipos, el USB aparece como "Removable Device" o por el nombre de la marca (ej: "Kingston").
🔵 Seleccionar modo de arranque (UEFI vs Legacy)

Fedora puede instalarse en ambos modos, pero no se puede cambiar después de la instalación.

  • Buscar "Boot Mode" o "UEFI/Legacy".
  • Seleccionar "UEFI" para sistemas modernos (recomendado).
  • Seleccionar "Legacy" solo si la computadora es muy antigua.
🟣 Configuración de SATA (opcional)

Algunos equipos requieren cambiar el modo SATA para que Linux reconozca el disco.

  • Buscar "SATA Mode" o "SATA Configuration".
  • Cambiar de "RAID" o "Intel RST" a "AHCI".

🔹 Paso 3: Guardar cambios y reiniciar

  1. Guardar los cambios (presionar F10 o seleccionar "Save and Exit").
  2. Reiniciar la computadora con la USB conectada.
  3. Si el orden de arranque está configurado correctamente, la computadora arrancará desde el USB.
  4. Alternativa: Si no quieres cambiar el orden de arranque permanente, usa el Boot Menu (F12, F8, ESC) para seleccionar el USB solo esta vez.

🔹 Paso 4: Iniciar el instalador de Fedora

Al arrancar desde el USB, aparecerá el menú de arranque de Fedora.

  1. Seleccionar "Start Fedora Workstation Live" o "Test this media & install Fedora" (recomendado para verificar el USB).
  2. Esperar a que cargue el entorno Live de Fedora en la memoria RAM.
  3. Una vez en el escritorio Live, hacer clic en el icono "Instalar en disco duro" (Install to Hard Drive).

🔹 Paso 5: Instalación guiada con Anaconda

  1. Seleccionar el idioma para la instalación y el sistema.
  2. Configurar la zona horaria (ej: Ciudad de México, Santiago, Madrid).
  3. Configurar el teclado (ej: Latinoamericano, Español).
  4. Seleccionar el disco de destino (¡cuidado de no seleccionar la USB!).
  5. Elegir el esquema de particionado:
    • Automático: Fedora particiona el disco automáticamente (recomendado para principiantes).
    • Personalizado: Para usuarios avanzados que quieren control total.
  6. Configurar el nombre de la computadora (hostname).
  7. Crear un usuario y contraseña (el usuario administrador que usaremos en el curso).
  8. Hacer clic en "Iniciar instalación" (Begin Installation) y esperar a que termine.
  9. Al finalizar, hacer clic en "Reiniciar" (Reboot) y retirar la USB cuando aparezca el mensaje.
📌 ¡Atención con el particionado!
Si el disco ya tiene otro sistema operativo (Windows), el instalador de Fedora ofrece la opción de instalar junto a otros sistemas (dual boot) o borrar el disco e instalar Fedora como único sistema. Asegúrate de elegir la opción correcta según lo que quieras hacer.

📝 Actividad práctica

Realiza los siguientes pasos en tu computadora:

  • Accede a la BIOS/UEFI usando la tecla correspondiente a tu marca.
  • Deshabilita Secure Boot.
  • Configura el orden de arranque para que la USB sea la prioridad.
  • Reinicia y arranca desde la USB.
  • Inicia el instalador de Fedora desde el entorno Live.
  • Configura el idioma, zona horaria y teclado.
  • Selecciona el disco de destino y elige particionado automático.
  • Crea un usuario administrador.
  • Inicia la instalación y espera a que termine.
  • Reinicia, retira la USB y arranca desde Fedora.

  • ¿Tuviste algún problema durante la instalación?
