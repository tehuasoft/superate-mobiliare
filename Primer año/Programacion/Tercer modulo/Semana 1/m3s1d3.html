🐧 PLANIFICACIÓN DE CLASE

Instalación de Fedora · Dual Boot con Windows · Creación del usuario administrador

🎯 Competencia General

El estudiante instala Fedora Linux en el espacio libre del disco (previamente preparado con Windows), completa la configuración del dual boot, y crea el usuario administrador que se utilizará para gestionar el sistema y crear usuarios adicionales en clases futuras.

📖 Conceptuales (Saber)

  • Comprende el proceso de instalación de Fedora desde Ventoy.
  • Reconoce la opción de usar el espacio libre para instalar Linux.
  • Entiende la importancia del usuario administrador (root/sudo).
  • Identifica cómo se configura el dual boot con Windows.

🛠️ Procedimentales (Saber hacer)

  • Reiniciar desde la USB con Ventoy y seleccionar la ISO de Fedora.
  • Usar el espacio libre del disco para la instalación.
  • Configurar las opciones de instalación de Fedora.
  • Crear el usuario administrador durante la instalación.
  • Verificar que el dual boot funcione correctamente.

❤️ Actitudinales (Saber ser)

  • Muestra interés por la instalación de Linux.
  • Valora la importancia de seguir los pasos con precisión.
  • Participa activamente en la instalación.
  • Desarrolla paciencia y atención al detalle.

🔹 Parte 1: Reiniciar y arrancar desde la USB

1
Reiniciar la computadora

Con Windows ya instalado, reiniciar la computadora. Durante el arranque, presionar la tecla de acceso al menú de arranque (F12, Esc, F10 según el fabricante) para seleccionar la USB.

⌨️ F12 → Seleccionar USB → Arrancar desde USB
2
Seleccionar Fedora en Ventoy

Aparecerá el menú de Ventoy con las ISOs disponibles. Seleccionar Fedora.iso y presionar Enter.

💾 Ventoy - Menú de arranque 📁
💿 Windows.iso 5.2 GB
🐧 Fedora.iso 2.1 GB

Seleccionar Fedora y esperar a que cargue el instalador.

🔹 Parte 2: Instalar Fedora usando el espacio libre

3
Iniciar el instalador de Fedora

Una vez cargado el entorno de Fedora, hacer clic en "Instalar en el disco duro" (Install to Hard Drive).

🐧 Fedora Live → Instalar en el disco duro
4
Seleccionar idioma y configuración

Elegir el idioma (Español), la distribución del teclado (Latinoamericano) y la zona horaria.

🌎 Idioma: Español | ⌨️ Teclado: Latinoamericano | 🕒 Zona horaria: Guatemala
5
Seleccionar el destino de instalación

En la sección "Destino de instalación", seleccionar el disco donde está Windows. Luego elegir la opción "Usar espacio libre" (Use free space).

🐧 Instalación de Fedora ⚙️
✅ Usar espacio libre
Instala Fedora en el espacio no asignado del disco.
❌ Reemplazar una partición existente
Eliminaría Windows. ¡No seleccionar!
❌ Borrar el disco
Eliminaría todo. ¡No seleccionar!

⚠️ Importante: Seleccionar "Usar espacio libre" para no afectar Windows.

6
Confirmar el particionado automático

Fedora creará automáticamente las particiones necesarias (/, /boot, /home, swap) en el espacio libre. Hacer clic en "Comenzar instalación".

✅ Comenzar instalación → Fedora creará: /boot (1 GB), / (resto), swap (2 GB)

🔹 Parte 3: Crear el usuario administrador

7
Configurar el usuario administrador

Mientras la instalación avanza, configurar el usuario:

  • Nombre completo: Superate Mobiliare
  • Nombre de usuario: admin
  • Contraseña: Superate2026.
👤 Nombre completo: Superate Mobiliare
🔑 Nombre de usuario: admin
🔒 Contraseña: Superate2026.
8
Marcar como administrador

Importante: marcar la casilla "Hacer que este usuario sea administrador". Esto permite usar sudo para tareas administrativas y crear otros usuarios después.

✅ Hacer que este usuario sea administrador
📌 ¿Por qué crear un usuario administrador?

El usuario administrador es esencial para:

  • Instalar y actualizar software.
  • Crear y gestionar otros usuarios.
  • Configurar el sistema.
  • Realizar tareas de mantenimiento.

En la próxima clase usaremos este usuario para crear más usuarios.

🔹 Parte 4: Finalizar la instalación

9
Esperar a que termine la instalación

La instalación puede tardar entre 10 y 20 minutos. Al finalizar, hacer clic en "Reiniciar ahora" (Reboot Now).

⏳ Instalación completada → Reiniciar ahora
10
Retirar la USB y reiniciar

Retirar la USB cuando el sistema se reinicie. Aparecerá el menú de arranque GRUB con las opciones: Fedora y Windows.

🐧 GRUB: Fedora | Windows Boot Manager

🔹 Parte 5: Verificar el dual boot

11
Iniciar Fedora

Seleccionar Fedora en el menú GRUB e iniciar sesión con el usuario administrador creado.

🔑 Usuario: admin | Contraseña: ********
12
Verificar Windows en el menú GRUB

Reiniciar y verificar que Windows aparece en el menú GRUB. Seleccionarlo para confirmar que sigue funcionando.

🪟 GRUB → Windows Boot Manager → Windows inicia correctamente

🔹 Comandos útiles para verificar la instalación

# Ver las particiones del disco [admin@fedora ~]$ lsblk NAME MAJ:MIN RM SIZE RO TYPE MOUNTPOINT sda 8:0 0 476.9G 0 disk ├─sda1 8:1 0 500M 0 part /boot/efi ├─sda2 8:2 0 16M 0 part ├─sda3 8:3 0 200G 0 part ├─sda4 8:4 0 1G 0 part /boot └─sda5 8:5 0 275.4G 0 part /
# Verificar la versión de Fedora [admin@fedora ~]$ cat /etc/fedora-release Fedora release 40 (Forty)
# Verificar que el usuario es administrador (sudo) [admin@fedora ~]$ sudo whoami root

Instrucciones:

  • 1. Reiniciar la computadora y arrancar desde la USB con Ventoy.

💡 Tips clave para la instalación de Fedora y creación del usuario administrador:

• Arranque: Reiniciar y seleccionar la USB con Ventoy.

• Selección de ISO: Elegir Fedora.iso en el menú de Ventoy.

• Particionado: Fedora crea automáticamente /boot, /, /home y swap.

• Usuario administrador: Crear con nombre, usuario y contraseña.

• Marcar casilla: "Hacer que este usuario sea administrador".

• GRUB: Menú de arranque que permite elegir Fedora o Windows.

• Verificar: lsblk, cat /etc/fedora-release, sudo whoami.
