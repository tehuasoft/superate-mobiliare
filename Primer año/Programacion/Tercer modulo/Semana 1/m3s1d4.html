📘 PLANIFICACIÓN DE CLASE

Tema: Creación de usuarios en Fedora (admin y personal) desde interfaz gráfica y verificación de actualizaciones

🎯 Competencia General

Crea un usuario administrador y un usuario personal desde la interfaz gráfica de Fedora, siguiendo las indicaciones del maestro para el usuario admin y eligiendo sus propios datos para el usuario personal, para luego verificar las actualizaciones del sistema con sudo dnf check-update sin aplicarlas aún, comprendiendo la importancia de la administración de usuarios y la gestión de paquetes en Linux.

📖 Conceptuales (Saber)

  • Comprende la jerarquía de usuarios en Linux: root, administradores (sudo) y usuarios estándar.
  • Reconoce que al iniciar Fedora por primera vez se usa el usuario admin creado durante la instalación.
  • Identifica el propósito del comando sudo dnf check-update.
  • Entiende la diferencia entre verificar actualizaciones y aplicarlas.

🛠️ Procedimentales (Saber hacer)

  • Iniciar sesión con el usuario administrador creado durante la instalación.
  • Navegar en la interfaz gráfica: Configuración → Sistema → Usuarios.
  • Desbloquear la configuración de usuarios con la contraseña de administrador.
  • Crear un nuevo usuario administrador siguiendo las indicaciones del maestro.
  • Crear un usuario personal con nombre completo, nombre de usuario y contraseña elegidos por el alumno.
  • Verificar actualizaciones del sistema con sudo dnf check-update.

❤️ Actitudinales (Saber ser)

  • Muestra responsabilidad al elegir y recordar contraseñas.
  • Valora la importancia de tener un usuario administrador y uno personal.
  • Participa activamente en la creación de usuarios.
  • Comprende la importancia de mantener el sistema actualizado.
🟢 INICIO 15 minutos

Actividad: "Usuarios en Linux y administración del sistema"

Metodología: Cuestionamiento y explicación conceptual.

Descripción: El docente explica la jerarquía de usuarios en Linux:

  • Usuario root: El superusuario con todos los permisos (no se usa directamente).
  • Administradores (sudo): Pueden ejecutar comandos con privilegios de root usando sudo .
  • Usuarios estándar: Tienen permisos limitados para seguridad.

🔑 Al iniciar Fedora por primera vez:

Durante la instalación de Fedora, se creó un usuario administrador con su contraseña. Ese es el usuario que usaremos primero para iniciar sesión y luego crear los nuevos usuarios.

  • Usuario admin de instalación: El que configuraste durante la instalación (nombre, usuario y contraseña).
  • Contraseña: La que estableciste en el instalador de Fedora.

El docente indica que primero crearán un usuario admin siguiendo las instrucciones que él proporcione (nombre, nombre de usuario y contraseña). Luego cada estudiante creará su propio usuario desde la interfaz gráfica.

Finalmente, se explica que sudo dnf check-update permite verificar paquetes disponibles para actualizar, pero que no los instalaremos aún .

Aprendizaje esperado

Criterios de evaluación

  • Participa en la discusión inicial.

🟡 DESARROLLO 35 minutos

Actividad: "Creación de usuarios desde interfaz gráfica y verificación de actualizaciones"

Metodología: Demostración guiada paso a paso + práctica individual.

🔹 Paso 1: Iniciar sesión con el usuario administrador

Al encender la computadora, aparece la pantalla de inicio de sesión de Fedora. Usar el usuario y contraseña que se configuraron durante la instalación de Fedora.

🔹 Paso 2: Abrir Configuración de Usuarios

  1. Abrir Configuración (Settings): Hacer clic en el ícono de engranaje en el panel superior o buscarlo en el menú de aplicaciones.
  2. Ir a Sistema → Usuarios: En el panel izquierdo, seleccionar "Sistema" (System) y luego "Usuarios" (Users).
  3. Desbloquear (Unlock): Hacer clic en el botón "Desbloquear" (Unlock) en la esquina superior derecha (botón azul). Aparecerá una ventana para autenticación.
  4. Ingresar contraseña de administrador: Escribir la contraseña del usuario administrador actual (el de la instalación) y presionar "Autenticar" (Authenticate).

🔹 Paso 3: Crear el usuario administrador (admin)

El maestro indicará nombre completo, nombre de usuario y contraseña para el usuario admin.

  1. Agregar usuario (Add User): Hacer clic en el botón "Agregar usuario" (Add User) que ahora estará habilitado.
  2. Completar datos del usuario admin:
    • Nombre completo: El que indique el maestro.
    • Nombre de usuario: El que indique el maestro (ej: admin).
  3. Permisos de administrador: Activar el toggle (interruptor) que dice "Administrador" (Administrator) .
  4. Establecer contraseña ahora: Seleccionar "Establecer contraseña ahora" (Set password now) y crear la contraseña que indique el maestro.
  5. Agregar (Add): Hacer clic en "Agregar" (Add) para finalizar la creación del usuario admin.

🔹 Paso 4: Crear usuario personal

Cada estudiante creará su propio usuario con sus datos.

  1. Agregar usuario (Add User): Hacer clic nuevamente en "Agregar usuario" (Add User).
  2. Completar datos del usuario personal:
    • Nombre completo: Tu nombre completo (ej: Juan Pérez).
    • Nombre de usuario: Elegir un nombre de usuario (ej: juanp, jperez, el que desees).
  3. Permisos de administrador: Activar el toggle (interruptor) que dice "Administrador" (Administrator) para darle permisos de sudo .
  4. Establecer contraseña ahora: Seleccionar "Establecer contraseña ahora" (Set password now) y crear una contraseña para tu usuario.
  5. Agregar (Add): Hacer clic en "Agregar" (Add) para finalizar la creación de tu usuario personal.
💡 Ejemplo de usuario personal:
Nombre completo: María González
Nombre de usuario: mariag
Contraseña: (elegir una contraseña segura y recordarla)

🔹 Paso 5: Cerrar sesión y entrar con el usuario personal

Es importante que las siguientes acciones se realicen desde la sesión del propio usuario.

  1. Hacer clic en el menú de usuario en la esquina superior derecha.
  2. Seleccionar "Cerrar sesión" (Log Out).
  3. En la pantalla de inicio de sesión, seleccionar el usuario personal recién creado.
  4. Ingresar la contraseña establecida.

🔹 Paso 6: Verificar actualizaciones con sudo dnf check-update

Desde la terminal (Ctrl+Alt+T), ejecutar:

# Verificar paquetes disponibles para actualizar
sudo dnf check-update

Este comando mostrará una lista de paquetes que tienen actualizaciones disponibles. Es importante no instalar las actualizaciones aún; solo verificaremos qué paquetes necesitan ser actualizados .

⚠️ Nota: dnf check-update solo verifica actualizaciones, no instala nada. La instalación se hará en una clase posterior con sudo dnf upgrade.

📝 Actividad práctica

Realiza los siguientes pasos en tu computadora:

  • Inicia sesión con el usuario admin de instalación.
  • Abre Configuración → Sistema → Usuarios.
  • Desbloquea con la contraseña del usuario de instalación.
  • Crea el usuario admin con los datos que indique el maestro.
  • Crea tu propio usuario desde Configuración → Usuarios.
  • Asigna permisos de administrador (toggle) y establece contraseña.
  • Cierra sesión y entra con tu usuario personal.
  • Abre la terminal (Ctrl+Alt+T).
  • Ejecuta sudo dnf check-update e ingresa tu contraseña.
  • Observa la lista de paquetes disponibles para actualizar.
  • Anota en tu cuaderno al menos 3 paquetes que aparezcan en la lista.
