🔹 ¿Qué es Linux?

Linux es el núcleo (kernel) de un sistema operativo. Es el software que se encarga de:

  • Gestionar el hardware (procesador, memoria, discos, periféricos).
  • Proveer servicios básicos para que otros programas puedan funcionar.
  • Actuar como intermediario entre el usuario y el hardware.
💡 Analogía:
Linux es como el "motor" de un carro. Las distribuciones son el "carro completo" (carrocería, asientos, dirección, etc.).

🔹 ¿Qué es una distribución de Linux?

Una distribución (distro) es un paquete completo que incluye:

  • El kernel de Linux.
  • Herramientas de sistema (gestor de paquetes, bibliotecas, drivers).
  • Entorno de escritorio (GNOME, KDE, XFCE, etc.).
  • Aplicaciones preinstaladas.
  • Sistema de configuración y administración.

💡 Conclusión: Todas las distribuciones usan el mismo kernel Linux, pero se diferencian en las herramientas, el entorno visual y el propósito para el que están diseñadas.

🔹 Principales distribuciones de Linux

🟠
Ubuntu

La más popular para usuarios nuevos. Fácil de usar, gran comunidad y soporte. Basada en Debian.

🖥️ Escritorio
🟢
Debian

Muy estable y segura. Base de muchas otras distros (Ubuntu, Linux Mint). Usada en servidores y escritorio.

⚙️ Estable
🔴
Arch Linux

Rolling release, altamente personalizable. Para usuarios avanzados que quieren control total.

🧠 Avanzada
🕵️
Tails

Enfocada en anonimato y privacidad. Se ejecuta desde USB y no deja rastros en el disco duro.

🔒 Privacidad
⚫
Kali Linux

Especializada en seguridad informática y pentesting (pruebas de penetración).

🛡️ Seguridad
🔵
Fedora

Moderno, con software actualizado. Respaldado por Red Hat. Es la que usaremos en este curso.

⭐ ¡Nuestra distro!

🔹 Rufus - Herramienta para crear USB booteable

Rufus es una herramienta gratuita y de código abierto que permite crear USB booteables a partir de archivos ISO. Es ampliamente compatible con:

  • Windows
  • Distribuciones de Linux (Ubuntu, Fedora, Debian, Arch, etc.)
  • BSD, DOS y otros sistemas operativos

En esta clase, Rufus se instaló desde la Microsoft Store, lo cual facilita su obtención y actualización.
