📌 ¿Qué es Linux?

Linux es un sistema operativo de código abierto (open source) basado en Unix. Fue creado por Linus Torvalds en 1991 y es mantenido por una comunidad global de desarrolladores.

  • Gratuito y libre: Cualquiera puede usarlo, modificarlo y distribuirlo.
  • Seguro y estable: Ideal para servidores y sistemas críticos.
  • Flexible: Existen distribuciones para todos los gustos y necesidades.
  • Base de Android: El sistema operativo móvil más usado del mundo.
  • Usado en servidores: Más del 90% de los servidores web usan Linux.

🔹 Distribuciones de Linux

Una distribución (o "distro") es una versión de Linux que incluye el kernel, herramientas y aplicaciones empaquetadas para un propósito específico.

🟠 Ubuntu — La más popular

Base: Debian

Propósito: Uso general, fácil de usar, ideal para principiantes.

Características: Interfaz amigable, gran comunidad, actualizaciones frecuentes, soporte comercial de Canonical.

Uso típico: Escritorio, servidores, desarrollo.

🔴 Debian — El pilar de Linux

Base: Es la base de muchas otras distros (Ubuntu, Kali, etc.)

Propósito: Estabilidad y confiabilidad.

Características: Muy estable, 100% software libre, actualizaciones más lentas pero seguras.

Uso típico: Servidores, sistemas embebidos, usuarios avanzados.

🔵 Arch Linux — Para expertos

Base: Independiente

Propósito: Control total y personalización.

Características: Instalación manual, rolling release (siempre actualizado), documentación excelente (Arch Wiki).

Uso típico: Usuarios avanzados que quieren control absoluto.

🟣 Tails — Privacidad y anonimato

Base: Debian

Propósito: Navegación anónima y segura.

Características: Se ejecuta desde USB, enruta todo el tráfico por Tor, no deja rastro en el equipo.

Uso típico: Periodistas, activistas, usuarios que necesitan privacidad.

🔷 Kali Linux — Seguridad y hacking ético

Base: Debian

Propósito: Pruebas de penetración y seguridad informática.

Características: Incluye cientos de herramientas de hacking ético, auditoría y forense.

Uso típico: Pentesters, auditores de seguridad, estudiantes de ciberseguridad.

🟢 Fedora — Innovación y desarrollo

Base: Independiente (patrocinada por Red Hat)

Propósito: Innovación y tecnologías emergentes.

Características: Actualizaciones frecuentes, tecnologías de vanguardia, entorno GNOME por defecto.

Uso típico: Desarrolladores, entusiastas de la tecnología.

⭐ Esta es la distribución que usaremos más adelante en el curso.

🔹 Preparación de herramientas: Ventoy + ISO de Windows + ISO de Fedora

💾
Ventoy

¿Qué es? Una herramienta que permite crear una USB de arranque multiboot.

¿Para qué sirve? Permite copiar múltiples archivos ISO a una USB y arrancar desde cualquiera de ellos sin necesidad de formatear la USB cada vez.

Ventaja: Puedes tener Windows, Fedora y otras herramientas en la misma USB.

💿
ISO de Windows

¿Qué es? Un archivo de imagen que contiene una copia exacta de un disco de instalación de Windows.

¿Para qué sirve? Permite instalar Windows en una computadora desde una USB.

Uso en el curso: Lo usaremos para hacer un dual boot (Windows + Fedora).

🐧
ISO de Fedora

¿Qué es? Un archivo de imagen que contiene el instalador de Fedora Linux.

¿Para qué sirve? Permite instalar Fedora en una computadora desde una USB.

Uso en el curso: Lo instalaremos después de Windows para completar el dual boot.

🔹 ¿Qué es un dual boot?

📌 Dual Boot (arranque dual):

Es la instalación de dos sistemas operativos en la misma computadora. Al encender, el usuario puede elegir cuál sistema operativo iniciar.

  • Ventaja: Puedes usar Windows para algunas cosas y Fedora para otras.
  • Preparación: Necesitamos redimensionar la partición de Windows para dejar espacio a Fedora.
  • Orden de instalación: Primero Windows (redimensionado) y luego Fedora.

⚠️ Importante: Hoy solo copiaremos los archivos. La instalación y el redimensionado los haremos en otra clase.

1
Descargar Ventoy

Ir a ventoy.net y descargar la versión para Windows. Descomprimir el archivo ZIP.

🌐 ventoy.net → Descargar → ventoy-x.x.x-windows.zip
2
Instalar Ventoy en la USB

Conectar una USB (mínimo 16 GB) y ejecutar Ventoy2Disk.exe. Seleccionar la USB y hacer clic en "Install".

💾 Ventoy2Disk.exe → Seleccionar USB → Install

⚠️ Advertencia: Esto formateará la USB. Asegurarse de que no tenga datos importantes.

3
Copiar la ISO de Windows

Una vez instalado Ventoy, la USB tendrá una partición llamada "Ventoy". Copiar el archivo ISO de Windows a esa partición.

💿 Copiar: Windows.iso → USB (partición Ventoy)
4
Copiar la ISO de Fedora

Copiar también el archivo ISO de Fedora a la misma partición de Ventoy.

🐧 Copiar: Fedora.iso → USB (partición Ventoy)
