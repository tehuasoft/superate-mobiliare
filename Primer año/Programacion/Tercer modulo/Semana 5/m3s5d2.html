  • Usar operadores lógicos dentro de condiciones.

🟡 DESARROLLO 35 minutos

Actividad: "Estructuras condicionales en Dart"

Metodología: Explicación guiada con ejemplos en código.

🔹 if simple

El if ejecuta un bloque de código solo si la condición es true.

void main() {
  int edad = 20;
  if (edad >= 18) {
    print("Eres mayor de edad");
  }
}

🔹 if-else

El if-else ejecuta un bloque si la condición es true y otro bloque si es false.

void main() {
  int edad = 16;
  if (edad >= 18) {
    print("Eres mayor de edad");
  } else {
    print("Eres menor de edad");
  }
}

🔹 else if

El else if permite evaluar múltiples condiciones en secuencia.

void main() {
  int nota = 85;
  if (nota >= 90) {
    print("Calificación: A");
  } else if (nota >= 80) {
    print("Calificación: B");
  } else if (nota >= 70) {
    print("Calificación: C");
  } else {
    print("Calificación: F");
  }
}

🔹 Múltiples condiciones con operadores lógicos

Se pueden combinar condiciones usando && (AND) y || (OR).

void main() {
  int edad = 22;
  bool tieneCarnet = true;

  if (edad >= 18 && tieneCarnet) {
    print("Puede conducir");
  } else if (edad >= 18 && !tieneCarnet) {
    print("Es mayor de edad pero no tiene carnet");
  } else {
    print("No puede conducir");
  }
}

🔹 Comparación: if-else vs operador ternario

✅ Usando if-else (más legible para múltiples líneas)
String mensaje;
if (edad >= 18) {
  mensaje = "Mayor";
} else {
  mensaje = "Menor";
}
🔹 Usando operador ternario (más conciso)
String mensaje = (edad >= 18) ? "Mayor" : "Menor";

🔹 Anidar estructuras condicionales

Es posible poner un if dentro de otro if (anidamiento).

void main() {
  int edad = 20;
  bool tieneCarnet = true;

  if (edad >= 18) {
    if (tieneCarnet) {
      print("Puede conducir");
    } else {
      print("No tiene carnet");
    }
  } else {
    print("Es menor de edad");
  }
}

💡 Tips clave:

• if: Ejecuta un bloque solo si la condición es true.

• if-else: Ejecuta un bloque si es true y otro si es false.

• if-else if-else: Evalúa múltiples condiciones en secuencia.

• Operadores lógicos: && (AND), || (OR), ! (NOT).

• Anidamiento: Puedes poner if dentro de if.

• Buenas prácticas: Usa llaves { } siempre, incluso si solo hay una línea.

• Legibilidad: Para lógica compleja, usa if-else; para asignaciones simples, usa el operador ternario.
