Actividad: "Operadores de comparación y lógicos"

Metodología: Explicación guiada con ejemplos en código.

🔹 Operadores de comparación

Los operadores de comparación evalúan la relación entre dos valores y devuelven un booleano.

✅ Operadores de comparación
  • == → igual a
  • != → diferente de
  • > → mayor que
  • < → menor que
  • >= → mayor o igual que
  • <= → menor o igual que
📌 Ejemplos en código
print(5 > 3); // true
print(5 < 3); // false
print(5 == 5); // true
print(5 != 5); // false

🔹 Operadores lógicos

Los operadores lógicos combinan dos o más condiciones y devuelven un booleano.

🔹 && (AND)

Devuelve true solo si ambas condiciones son true.

print(5 > 3 && 10 > 5); // true (ambas son true)
print(5 > 3 && 10 < 5); // false (una es false)
🔹 || (OR)

Devuelve true si al menos una condición es true.

print(5 > 3 || 10 < 5); // true (una es true)
print(5 < 3 || 10 < 5); // false (ambas son false)

🔹 Tablas de verdad

✅ AND (&&)
A B A && B
true true true
true false false
false true false
false false false
✅ OR (||)
A B A || B
true true true
true false true
false true true
false false false

🔹 Ejemplos completos

void main() {
  int a = 10;
  int b = 5;

  // Comparaciones
  print(a > b); // true
  print(a < b); // false
  print(a == b); // false
  print(a != b); // true

  // Condiciones combinadas con &&
  print(a > 5 && b > 0); // true (ambas true)
  print(a > 5 && b > 10); // false (b > 10 es false)

  // Condiciones combinadas con ||
  print(a > 5 || b > 10); // true (a > 5 es true)
  print(a > 20 || b > 10); // false (ambas false)
}

💡 Tips clave:

• bool: Tipo de dato que solo puede ser true o false.

• Comparaciones: == (igual), != (diferente), > (mayor), < (menor).

• AND (&&): true solo si ambas son true.

• OR (||): true si al menos una es true.

• Los booleanos son el resultado de preguntas que le hacemos al programa.
