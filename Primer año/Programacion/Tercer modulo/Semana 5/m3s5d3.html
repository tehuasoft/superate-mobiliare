🔹 ¿Qué son las condicionales anidadas?

Una condicional anidada ocurre cuando colocamos una estructura if, else if o else dentro de otra estructura if, else if o else.

if (condicion1) {
  // Código si condicion1 es true
  if (condicion2) {
    // Código si condicion1 y condicion2 son true
  } else {
    // Código si condicion1 es true pero condicion2 es false
  }
} else {
  // Código si condicion1 es false
}

🔹 ¿Cuándo usar condicionales anidadas?

Las condicionales anidadas son útiles cuando:

  • Una condición solo tiene sentido si otra se cumple primero.
  • Necesitas evaluar una jerarquía de condiciones.
  • Quieres evitar evaluar condiciones innecesarias (cortocircuito).
📌 Ejemplo de uso apropiado:
Verificar si una persona puede conducir: primero debe ser mayor de edad, y luego tener licencia.
if (edad >= 18) {
  if (tieneLicencia) {
    print("Puede conducir");
  } else {
    print("Es mayor de edad pero no tiene licencia");
  }
} else {
  print("Es menor de edad");
}

🔹 ¿Cuándo NO usar condicionales anidadas?

  • Cuando el anidamiento es excesivo (más de 2-3 niveles).
  • Cuando las condiciones son independientes y se pueden combinar con &&.
  • Cuando el código se vuelve difícil de leer y mantener.
📌 Ejemplo de mal uso (anidamiento excesivo):
if (a > 0) {
  if (b > 0) {
    if (c > 0) {
      if (d > 0) {
        // Demasiado anidado
      }
    }
  }
}

🔹 Alternativas: condiciones compuestas

En muchos casos, se puede usar && para combinar condiciones y evitar anidar.

✅ Usando && (recomendado)
if (edad >= 18 && tieneLicencia) {
  print("Puede conducir");
} else if (edad >= 18 && !tieneLicencia) {
  print("No tiene licencia");
} else {
  print("Es menor de edad");
}
⚠️ Anidado (menos legible)
if (edad >= 18) {
  if (tieneLicencia) {
    print("Puede conducir");
  } else {
    print("No tiene licencia");
  }
} else {
  print("Es menor de edad");
}

🔹 Mejores prácticas

  • Usa && o || cuando las condiciones son independientes.
  • Anida solo cuando una condición debe evaluarse solo si otra se cumple.
  • Mantén un máximo de 2-3 niveles de anidamiento.
  • Usa early returns para evitar anidamiento innecesario.
  • Comenta el código si el anidamiento es necesario.

💡 Tips clave:

• Anida cuando: Una condición solo debe evaluarse si otra se cumple.

• Evita anidar cuando: Las condiciones son independientes; usa && o ||.

• Máximo 2-3 niveles: El anidamiento excesivo hace el código difícil de leer.

• Alternativas: Usa operadores lógicos, switch o early returns.

• Legibilidad: Siempre prioriza que el código sea claro y fácil de entender.
