🔹 break - Salir del bucle

El comando break permite terminar el bucle inmediatamente, sin importar si la condición sigue siendo verdadera.

void main() {
  for (int i = 1; i <= 10; i++) {
    if (i == 5) {
      break; // Sale del bucle cuando i llega a 5
    }
    print(i);
  }
}
// Salida: 1, 2, 3, 4
📌 Uso típico:
Buscar un elemento en una lista y detenerse cuando se encuentra.

🔹 continue - Saltar a la siguiente iteración

El comando continue permite saltar a la siguiente iteración sin ejecutar el resto del código en la iteración actual.

void main() {
  for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
      continue; // Salta los números pares
    }
    print(i);
  }
}
// Salida: 1, 3, 5, 7, 9
📌 Uso típico:
Procesar solo elementos que cumplen cierta condición, saltando los que no.

🔹 Comparación: break vs continue

✅ break
  • Termina el bucle inmediatamente.
  • Sale completamente del bucle.
  • Útil cuando se encuentra lo que se busca.
🔹 continue
  • Salta a la siguiente iteración.
  • No ejecuta el resto del código en esa iteración.
  • Útil para filtrar elementos.

🔹 Ejemplo con while

void main() {
  int i = 0;
  while (i < 10) {
    i++;
    if (i == 5) {
      continue; // Salta el 5
    }
    if (i == 8) {
      break; // Termina en 8
    }
    print(i);
  }
}
// Salida: 1, 2, 3, 4, 6, 7

💡 Tips clave:

• break: "Sal del bucle ahora."

• continue: "Salta el resto de esta iteración y ve a la siguiente."

• break es útil para detener un bucle cuando se encuentra un resultado.

• continue es útil para filtrar elementos que no cumplen una condición.

• En bucles anidados: break solo afecta al bucle más interno.
