Tema: while y do-while en Dart

🎯 Competencia General

Comprende el funcionamiento de los bucles while y do-while en Dart, diferencia sus comportamientos, y los aplica en situaciones donde la cantidad de iteraciones no es conocida de antemano, desarrollando habilidades de control de flujo basado en condiciones.

📖 Conceptuales (Saber)

  • Define qué es un bucle while y cuándo usarlo.
  • Define qué es un bucle do-while y cuándo usarlo.
  • Comprende la diferencia clave: while evalúa primero, do-while ejecuta primero.
  • Reconoce que ambos son útiles cuando no sabemos cuántas veces se repetirá el bucle.

🛠️ Procedimentales (Saber hacer)

  • Escribir bucles while con condiciones de parada.
  • Escribir bucles do-while para garantizar al menos una ejecución.
  • Elegir entre while y do-while según la necesidad.
  • Evitar bucles infinitos con condiciones correctas.

❤️ Actitudinales (Saber ser)

  • Muestra confianza al escribir bucles condicionales.
  • Participa activamente en la resolución de ejercicios.
  • Valora la utilidad de los bucles para tareas repetitivas.
  • Desarrolla pensamiento lógico al diseñar condiciones de parada.
🟢 INICIO 15 minutos

Actividad: "Explicación super simple de while y do-while"

Metodología: Analogías y ejemplos cotidianos.

Descripción: El docente explica con analogías sencillas.

🧠 Analogía para entender while y do-while:
  • while: "Revisa si hay pizza. Si hay, come una rebanada. Sigue mientras haya pizza."
  • do-while: "Come una rebanada de pizza. Luego revisa si hay más. Repite mientras haya pizza."
📌 Diferencia clave:
  • while: Primero pregunta, luego actúa. Si la condición es falsa, no se ejecuta ni una vez.
  • do-while: Primero actúa, luego pregunta. Siempre se ejecuta al menos una vez, aunque la condición sea falsa.

🟡 DESARROLLO 35 minutos

Actividad: "While y do-while en Dart - Ejemplos y práctica"

Metodología: Explicación con ejemplos y ejercicios.

🔹 Bucle while

while (condición) {
  // Código que se repite MIENTRAS la condición sea verdadera
}

Ejemplo 1: Contar del 1 al 5 con while

void main() {
  int i = 1;
  while (i <= 5) {
    print(i);
    i++;
  }
}
// Salida: 1, 2, 3, 4, 5

Ejemplo 2: while con condición falsa (no se ejecuta)

void main() {
  int i = 10;
  while (i < 5) {
    print(i); // Esto nunca se ejecuta
  }
}

🔹 Bucle do-while

do {
  // Código que se ejecuta al menos una vez
} while (condición);

Ejemplo 1: Contar del 1 al 5 con do-while

void main() {
  int i = 1;
  do {
    print(i);
    i++;
  } while (i <= 5);
}
// Salida: 1, 2, 3, 4, 5

Ejemplo 2: do-while con condición falsa (se ejecuta al menos una vez)

void main() {
  int i = 10;
  do {
    print(i); // Se ejecuta una vez, aunque i no sea < 5
  } while (i < 5);
}
// Salida: 10 (se ejecuta una vez)

🔹 Comparación: while vs do-while

✅ while
  • Evalúa la condición primero.
  • Si es falsa, no se ejecuta.
  • Útil cuando no sabemos si se debe ejecutar.
while (condición) { ... }
🔹 do-while
  • Ejecuta el bloque primero.
  • Luego evalúa la condición.
  • Útil cuando debe ejecutarse al menos una vez.
do { ... } while (condición);

🔹 ¿Cuándo usar while y cuándo do-while?

  • Usa while cuando no estás seguro de que la condición se cumpla, y quieres asegurarte de que no se ejecute si la condición es falsa.
  • Usa do-while cuando el bloque debe ejecutarse al menos una vez, independientemente de la condición.
📌 Ejemplo práctico:
while: Pedir a un usuario que ingrese un número mayor a 0. Si ingresa -1, no se ejecuta.
do-while: Mostrar un menú al usuario. Siempre se muestra al menos una vez, luego se pregunta si quiere salir.

Metodología: Preguntas y respuestas.

  • ¿Cuándo usamos while? → Cuando no sabemos si la condición se cumplirá, y queremos verificar primero.
  • ¿Cuándo usamos do-while? → Cuando necesitamos que el bloque se ejecute al menos una vez.

💡 Tips clave para recordar:

• while: "Pregunta, luego actúa" → Puede que no se ejecute nunca.

• do-while: "Actúa, luego pregunta" → Siempre se ejecuta al menos una vez.

• Siempre modifica la variable de control dentro del bucle para evitar bucles infinitos.

• Usa while para validación de entrada (ej: pedir un número válido).

• Usa do-while para menús o juegos donde la opción se muestra al menos una vez.
