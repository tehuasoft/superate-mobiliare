📘 PLANIFICACIÓN DE CLASE

Tema: Proyecto en Dart - Terminal con opciones (sin funciones)

🎯 Competencia General

Aplica los conceptos de bucles (for, while, do-while), condicionales (if, else if, if anidados) y control de iteraciones (break, continue) para crear una terminal interactiva con opciones, sin utilizar funciones o métodos.

📖 Conceptuales (Saber)

  • Comprende el uso de bucles para menús interactivos.
  • Reconoce cómo estructurar opciones con condicionales.
  • Identifica cuándo usar break para salir de un bucle.
  • Entiende la lógica de un menú interactivo en terminal.

🛠️ Procedimentales (Saber hacer)

  • Crear un menú interactivo en la terminal.
  • Usar do-while para mostrar el menú al menos una vez.
  • Evaluar la opción del usuario con if-else anidados.
  • Implementar diferentes funcionalidades dentro del menú.
  • Controlar la salida del programa con break.

❤️ Actitudinales (Saber ser)

  • Muestra interés por crear programas interactivos.
  • Valora la importancia de la organización del código.
  • Participa activamente en la creación del proyecto.
  • Desarrolla confianza en el uso de estructuras de control.

Metodología: Presentación y organización.

Descripción: El docente explica el proyecto de la terminal interactiva.

🔹 Objetivo del proyecto:

Crear una terminal interactiva en Dart que:

  • Muestre un menú con varias opciones.
  • Permita al usuario elegir una opción.
  • Ejecute una acción según la opción seleccionada.
  • Use do-while para mostrar el menú repetidamente.
  • Use if-else if y if anidados para manejar las opciones.
  • No use funciones ni métodos (todo dentro de main()).

🔹 Paso 1: Importar la librería dart:io

import 'dart:io';

🔹 Paso 2: Estructura del menú con do-while

void main() {
  String? opcion;

  do {
    print("\n📋 MENÚ PRINCIPAL");
    print("1. Sumar dos números");
    print("2. Restar dos números");
    print("3. Multiplicar dos números");
    print("4. Dividir dos números");
    print("5. Mostrar tabla de multiplicar");
    print("6. Salir");
    print("Elige una opción:");
    opcion = stdin.readLineSync()!;

    if (opcion == "1") {
      // Sumar
    } else if (opcion == "2") {
      // Restar
    } else if (opcion == "3") {
      // Multiplicar
    } else if (opcion == "4") {
      // Dividir
    } else if (opcion == "5") {
      // Tabla de multiplicar
    } else if (opcion == "6") {
      print("¡Hasta luego!");
      break;
    } else {
      print("Opción no válida. Intenta de nuevo.");
    }
  } while (true);
}

Opción 4: Dividir

print("Ingresa el primer número:");
double num1 = double.parse(stdin.readLineSync()!);
print("Ingresa el segundo número:");
double num2 = double.parse(stdin.readLineSync()!);
if (num2 != 0) {
  print("Resultado: ${num1 / num2}");
} else {

}

Opción 5: Tabla de multiplicar

print("Ingresa un número:");
int numero = int.parse(stdin.readLineSync()!);
for (int i = 1; i <= 10; i++) {
  print("$numero x $i = ${numero * i}");
}

🔹 Código completo del proyecto

import 'dart:io';

void main() {
  String? opcion;

  do {
    print("\n📋 MENÚ PRINCIPAL");
    print("1. Sumar dos números");
    print("2. Restar dos números");
    print("3. Multiplicar dos números");
    print("4. Dividir dos números");
    print("5. Mostrar tabla de multiplicar");
    print("6. Salir");
    print("Elige una opción:");
    opcion = stdin.readLineSync()!;

    if (opcion == "1") {
      // Sumar
    } else if (opcion == "2") {
      // Restar
    } else if (opcion == "3") {
      // Multiplicar
    } else if (opcion == "4") {
      // Dividir
    } else if (opcion == "5") {
      // Tabla de multiplicar
    } else if (opcion == "6") {
      print("¡Hasta luego!");
      break;
    } else {
      print("Opción no válida. Intenta de nuevo.");
    }
  } while (true);
}

💡 Tips clave:

• do-while: Ideal para menús que deben mostrarse al menos una vez.

• break: Úsalo para salir del bucle cuando se selecciona "Salir".

• if-else if: Estructura clara para manejar opciones del menú.

• Bucles for/while: Para repetir acciones dentro de las opciones.

• Validación: Siempre verifica que el usuario ingrese valores válidos.
