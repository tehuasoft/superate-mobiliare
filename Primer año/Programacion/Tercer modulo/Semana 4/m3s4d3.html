🔹 Sintaxis de interpolación

Dart permite insertar valores dentro de Strings usando $ antes del nombre de la variable o ${} para expresiones.

void main() {
  String nombre = "Ana";
  int edad = 22;

  // Interpolación simple
  print("Hola, $nombre"); // Hola, Ana

  // Interpolación con expresión
  print("Edad: $edad años"); // Edad: 22 años
  print("El año que viene tendrás ${edad + 1} años"); // El año que viene tendrás 23 años
}

🔹 Interpolación con expresiones

Se pueden incluir expresiones completas dentro de ${}.

void main() {
  int a = 10;
  int b = 5;

  print("Result: ${a + b}"); // Result: 15
  print("Producto: ${a * b}"); // Producto: 50
  print("¿Es mayor? ${a > b}"); // ¿Es mayor? true
}

🔹 Interpolación vs Concatenación

✅ Interpolación (recomendada)
print("Hola, $nombre");
  • Más legible.
  • Más eficiente.
  • Menos propenso a errores.
⚠️ Concatenación (menos recomendada)
print("Hola, " + nombre);
  • Menos legible.
  • Más verbosa.
  • Puede ser más lenta.

🔹 Ejemplos avanzados

void main() {
  String nombre = "Carlos";
  int edad = 30;
  double altura = 1.75;

  print("Mi nombre es $nombre, tengo $edad años y mido ${altura}m.");

  // Expresiones múltiples
  int a = 8;
  int b = 3;
  print("${a} + ${b} = ${a + b}"); // 8 + 3 = 11
  print("${a} * ${b} = ${a * b}"); // 8 * 3 = 24
}

💡 Tips clave:

• Interpolación simple: "Hola $nombre" → inserta el valor de la variable.

• Interpolación con expresión: "Resultado: ${a + b}" → inserta el resultado de la operación.

• Ventajas: Más legible, eficiente y fácil de escribir que la concatenación.

• Usa ${} cuando necesites evaluar una expresión, no solo una variable.

• Práctica: Combina múltiples variables y expresiones en un solo mensaje.
