🔹 La librería dart:io

dart:io: Es una librería que permite acceder a funcionalidades del sistema, como entrada/salida estándar, archivos, redes, etc. Para usarla, debemos importarla con import 'dart:io';.

🔹 stdin.readLineSync()

stdin.readLineSync(): Lee una línea completa de la entrada estándar (teclado).
Devuelve: Un String? (anulable). Usamos ! para indicar que confiamos en que no es null.
Importante: Siempre devuelve texto, aunque el usuario escriba números.
// Ejemplo básico de lectura import 'dart:io'; void main() { print("¿Cuál es tu edad?"); String entrada = stdin.readLineSync()!; // entrada contiene el texto que el usuario escribió print("El usuario escribió: $entrada"); }

🔹 El método parse — Conversión de tipos

parse: Es un método que convierte un String en otro tipo de dato (int, double, etc.).
int.parse(): Convierte un String a entero.
double.parse(): Convierte un String a número decimal.
📌 Convertir String a int con int.parse()
String numeroStr = "25"; int numero = int.parse(numeroStr); print(numero + 10); // 35
📌 Convertir String a double con double.parse()
String alturaStr = "1.75"; double altura = double.parse(alturaStr); print(altura * 2); // 3.5

🔹 Combinando stdin.readLineSync() y parse

Flujo típico: Leer entrada → obtener String → parsear al tipo deseado.
import 'dart:io'; void main() { // Leer un número entero print("Escribe tu edad:"); String entradaEdad = stdin.readLineSync()!; int edad = int.parse(entradaEdad); // Leer un número decimal print("Escribe tu estatura (ej: 1.75):"); String entradaAltura = stdin.readLineSync()!; double altura = double.parse(entradaAltura); // Usar los datos convertidos print("El año que viene tendrás ${edad + 1} años"); print("Tu altura en metros es $altura"); }

🔹 Usar parse con datos que vienen de otras fuentes

parse no solo se usa con stdin: También se usa para convertir datos provenientes de archivos, bases de datos, API, etc. Cualquier dato que llegue como String y necesite ser convertido a otro tipo.
// Datos simulados de una base de datos o API String temperaturaStr = "36.5"; double temperatura = double.parse(temperaturaStr); String cantidadStr = "150"; int cantidad = int.parse(cantidadStr); print("Temperatura: $temperatura°C"); print("Cantidad: $cantidad unidades");

🔹 ¿Qué pasa si el usuario escribe algo que no es un número?

Error en tiempo de ejecución: Si el String no es convertible, Dart lanza una excepción (FormatException). En una clase introductoria, mencionamos que hay que tener cuidado con la entrada del usuario.
// Esto causaría un error si el usuario escribe "abc" String entrada = stdin.readLineSync()!; int numero = int.parse(entrada); // ¡FormatException!

🔹 Ejemplo completo: Calculadora básica

import 'dart:io'; void main() { // Pedir el primer número print("Ingresa el primer número:"); String entrada1 = stdin.readLineSync()!; double num1 = double.parse(entrada1); // Pedir el segundo número print("Ingresa el segundo número:"); String entrada2 = stdin.readLineSync()!; double num2 = double.parse(entrada2); // Mostrar resultados print("Suma: ${num1 + num2}"); print("Resta: ${num1 - num2}"); print("Multiplicación: ${num1 * num2}"); print("División: ${num1 / num2}"); }
