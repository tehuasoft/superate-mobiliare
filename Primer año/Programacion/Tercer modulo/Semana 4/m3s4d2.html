🔹 Operadores aritméticos básicos

Dart tiene los siguientes operadores aritméticos básicos:

Operador Descripción Ejemplo Resultado
+ Suma 10 + 3 13
- Resta 10 - 3 7
* Multiplicación 10 * 3 30
/ División real 7 / 2 3.5
~/ División entera 7 ~/ 2 3
% Módulo (residuo) 7 % 2 1
// Ejemplos en código
int a = 10;
int b = 3;

print(a + b); // 13
print(a - b); // 7
print(a * b); // 30
print(a / b); // 3.3333333333333335 (double)
print(a ~/ b); // 3 (int, división entera)
print(a % b); // 1 (residuo)

🔹 Operadores compuestos

Los operadores compuestos combinan una operación aritmética con la asignación.

int x = 10;
x += 5; // x = x + 5 → 15
x -= 3; // x = x - 3 → 12
x *= 2; // x = x * 2 → 24
x /= 4; // x = x / 4 → 6.0
x ~/= 2; // x = x ~/ 2 → 3

🔹 Precedencia de operadores

La precedencia determina el orden en que se evalúan los operadores en una expresión. Dart sigue el orden matemático estándar.

Prioridad Operador Descripción
1 (Más alta) ( ) Paréntesis
2 *, /, ~/, % Multiplicación, división, división entera, módulo
3 +, - Suma y resta
4 = Asignación (evalúa al final)
// Ejemplos de precedencia
print(10 + 3 * 2); // 16 (primero multiplicación)
print((10 + 3) * 2); // 26 (primero paréntesis)
print(10 / 2 + 3); // 8.0 (primero división, luego suma)
print(10 / (2 + 3)); // 2.0 (primero paréntesis)

💡 Tips clave:

• + - * / : Operadores básicos. / siempre devuelve double.

• ~/ → División entera. Devuelve la parte entera del cociente.

• % → Módulo (residuo). Útil para saber si un número es par/divisible.

• Operadores compuestos: +=, -=, *=, /=, ~/= → simplifican la escritura.

• Precedencia: 1. Paréntesis, 2. *, /, ~/, %, 3. +, -, 4. =

• Asociatividad: Izquierda a derecha para operadores del mismo nivel.

• Usa paréntesis para hacer tu código más claro y evitar errores.
