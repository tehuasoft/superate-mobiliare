Tema: Proyecto en Dart - Calculadora interactiva (sin funciones)

🎯 Competencia General

Aplica los conceptos de variables, entrada de datos con stdin.readLineSync(), operadores aritméticos e interpolación de Strings para crear una calculadora interactiva en Dart que recibe dos números del usuario y muestra los resultados de suma, resta, multiplicación y división.

📖 Conceptuales (Saber)

  • Comprende el uso de dart:io y stdin.readLineSync().
  • Reconoce los operadores aritméticos en Dart (+, -, *, /, ~/).
  • Entiende el concepto de parseo de Strings a números.
  • Comprende la interpolación de Strings para mostrar resultados.

🛠️ Procedimentales (Saber hacer)

  • Importar la librería dart:io.
  • Leer datos del usuario con stdin.readLineSync().
  • Convertir Strings a números con int.parse() o double.parse().
  • Realizar operaciones aritméticas con los números ingresados.
  • Mostrar resultados usando interpolación de Strings.

❤️ Actitudinales (Saber ser)

  • Muestra interés por crear programas interactivos.
  • Valora la importancia de la entrada de datos en la programación.
  • Participa activamente en la creación de la calculadora.
  • Desarrolla confianza en el manejo de entrada y salida de datos.

🟡 DESARROLLO 35 minutos

Actividad: "Creando la calculadora"

Metodología: Explicación guiada y práctica.

🔹 Paso 1: Importar la librería dart:io

import 'dart:io';

🔹 Paso 2: Leer los números del usuario

void main() {
  print("Ingresa el primer número:");
  String? input1 = stdin.readLineSync();
  double num1 = double.parse(input1!);

  print("Ingresa el segundo número:");
  String? input2 = stdin.readLineSync();
  double num2 = double.parse(input2!);
}

⚠️ Nota: Estamos usando double.parse() para permitir números decimales. Si solo quieres enteros, usa int.parse().

🔹 Paso 3: Calcular y mostrar resultados

double suma = num1 + num2;
double resta = num1 - num2;
double multiplicacion = num1 * num2;
double division = num1 / num2;
int divisionEntera = num1 ~/ num2; // División entera
double modulo = num1 % num2; // Módulo (residuo)

🔹 Paso 4: Mostrar resultados con interpolación

print("Suma: $num1 + $num2 = $suma");
print("Resta: $num1 - $num2 = $resta");
print("Multiplicación: $num1 * $num2 = $multiplicacion");
print("División: $num1 / $num2 = $division");
print("División entera: $num1 ~/ $num2 = $divisionEntera");
print("Módulo: $num1 % $num2 = $modulo");

🔹 Código completo de la calculadora

import 'dart:io';

void main() {
  print("Ingresa el primer número:");
  String? input1 = stdin.readLineSync();
  double num1 = double.parse(input1!);

  print("Ingresa el segundo número:");
  String? input2 = stdin.readLineSync();
  double num2 = double.parse(input2!);

  double suma = num1 + num2;
  double resta = num1 - num2;
  double multiplicacion = num1 * num2;
  double division = num1 / num2;
  int divisionEntera = num1 ~/ num2;
  double modulo = num1 % num2;

  print("Suma: $num1 + $num2 = $suma");
  print("Resta: $num1 - $num2 = $resta");
  print("Multiplicación: $num1 * $num2 = $multiplicacion");
  print("División: $num1 / $num2 = $division");
  print("División entera: $num1 ~/ $num2 = $divisionEntera");
  print("Módulo: $num1 % $num2 = $modulo");
}

💡 Tips clave:

• stdin.readLineSync(): Lee una línea de texto del usuario.

• double.parse(): Convierte un String a número decimal.

• int.parse(): Convierte un String a número entero.

• Operadores: + (suma), - (resta), * (multiplicación), / (división real), ~/ (división entera), % (módulo).

• Interpolación: Usa $variable y ${expresión}.

• Prueba: Prueba tu calculadora con diferentes números para verificar que funciona correctamente.
