📘 PLANIFICACIÓN DE CLASE

Tema: Instalación de herramientas de desarrollo en Fedora (Google Chrome, VS Code, Flutter, Java, Android Studio) + Actualización final del sistema

🎯 Competencia General

Instala y configura todas las herramientas esenciales para el desarrollo de software en Fedora: Google Chrome, Visual Studio Code, Flutter SDK, Java Correto, Android Studio y las dependencias faltantes, siguiendo instrucciones paso a paso, para luego finalizar con la actualización completa del sistema y el firmware.

📖 Conceptuales (Saber)

  • Comprende el propósito de cada herramienta: Chrome (navegador), VS Code (editor), Flutter (framework móvil), Java (lenguaje y runtime), Android Studio (IDE para Android).
  • Reconoce las dependencias necesarias para Flutter y Android Studio.
  • Entiende el concepto de PATH y cómo agregar directorios para ejecutar comandos globalmente.
  • Comprende la importancia de mantener el sistema actualizado (dnf upgrade y fwupd).

🛠️ Procedimentales (Saber hacer)

  • Instalar paquetes RPM con sudo dnf install <ruta>.
  • Configurar repositorios de VS Code y agregar la clave GPG de Microsoft.
  • Instalar dependencias de Flutter con sudo dnf install.
  • Extraer archivos comprimidos (tar -xf para .tar.xz, tar -zxvf para .tar.gz).
  • Agregar directorios al PATH en ~/.bashrc.
  • Usar update-alternatives para seleccionar versiones de Java.
  • Ejecutar flutter doctor y aceptar licencias de Android.
  • Ejecutar sudo dnf upgrade y fwupdmgr update para actualizar sistema y firmware.

❤️ Actitudinales (Saber ser)

  • Sigue las instrucciones del maestro con atención y precisión.
  • Muestra paciencia al instalar herramientas con múltiples pasos.
  • Comparte archivos y comandos con compañeros cuando sea necesario.
  • Desarrolla confianza al ejecutar comandos en la terminal.

🟡 DESARROLLO 35 minutos

Actividad: "Instalación guiada de herramientas de desarrollo"

Metodología: Demostración paso a paso + práctica individual.

🔹 1. Google Chrome (RPM)

Copiar el paquete RPM de Google Chrome desde el USB. Luego instalar con dnf install.

# Ejemplo: instalar Chrome desde el RPM
sudo dnf install ~/Descargas/google-chrome-stable_current_x86_64.rpm

🔹 2. Visual Studio Code

Configurar el repositorio de Microsoft para instalar VS Code.

# Importar clave GPG y crear repositorio
sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc
echo -e "[code]\nname=Visual Studio Code\nbaseurl=https://packages.microsoft.com/yumrepos/vscode\nenabled=1\nautorefresh=1\ntype=rpm-md\ngpgcheck=1\ngpgkey=https://packages.microsoft.com/keys/microsoft.asc" | sudo tee /etc/yum.repos.d/vscode.repo > /dev/null

# Actualizar repositorios e instalar
sudo dnf check-update
sudo dnf install code

Después de instalar VS Code, abrirlo e instalar las extensiones Dart, Flutter y Prettier. Luego ir a Configuración → buscar "AI features" y marcar Disable AI Features.

🔹 3. Dependencias para Flutter

sudo dnf install wget git unzip xz zip curl libstdc++.i686 mesa-libGLU

🔹 4. Crear carpeta ~/development

mkdir ~/development

🔹 5. Flutter SDK

Copiar el archivo flutter_linux_*.tar.xz desde el USB. Luego extraerlo en ~/development.

# Extraer Flutter SDK en development
tar -xf ~/Descargas/flutter_linux_3.24.0-stable.tar.xz -C ~/development

🔹 6. Agregar Flutter al PATH

echo 'export PATH="$PATH:$HOME/development/flutter/bin"' >> ~/.bashrc
source ~/.bashrc

🔹 7. Java Correto

Copiar el RPM de Java Correto desde el USB e instalarlo.

sudo dnf install ~/Descargas/java-correto-*.rpm

# Verificar versión de Java
java --version

# Si no aparece "Correto", configurar con update-alternatives
sudo update-alternatives --config java
sudo update-alternatives --config javac

🔹 8. Android Studio

Copiar el archivo android-studio-*.tar.gz desde el USB. Extraerlo en ~/development.

tar -zxvf ~/Descargas/android-studio-2024.1.1-linux.tar.gz -C ~/development

cd ~/development/android-studio/bin
./studio

Completar el asistente de instalación de Android Studio. Luego abrir SDK Manager e instalar Android SDK Command-line Tools (latest).

🔹 9. Aceptar licencias de Android

flutter doctor --android-licenses

🔹 10. Dependencias faltantes para Flutter

sudo dnf install glx-utils egl-utils
sudo dnf install clang
sudo dnf install cmake
sudo dnf install gtk3-devel
sudo dnf install ninja

🔹 11. Actualización final del sistema y firmware

⚠️ ADVERTENCIA IMPORTANTE

Realiza estas actualizaciones solo después de haber completado todos los pasos anteriores.

# Actualizar todos los paquetes
sudo dnf upgrade

# Forzar actualización con refresco de repositorios
sudo dnf upgrade --refresh

# Verificar disponibilidad del paquete de firmware
sudo dnf search fwupd-plugin-uefi-capsule-data

# Refrescar metadatos de firmware desde LVFS
fwupdmgr refresh

# Actualizar firmware del sistema (BIOS/UEFI)
fwupdmgr update

⚠️ Importante: La actualización de firmware (fwupdmgr update) puede reiniciar la computadora. Asegúrate de guardar todo tu trabajo antes de ejecutarlo.

📝 Actividad práctica

Realiza los siguientes pasos en tu computadora:

  • Copia los archivos desde el USB a tu carpeta Descargas.
  • Instala Google Chrome desde el RPM.
  • Configura el repositorio de VS Code e instálalo.
  • Instala las dependencias de Flutter con sudo dnf install.
  • Crea la carpeta ~/development.
  • Extrae el SDK de Flutter en ~/development.
  • Agrega Flutter al PATH en ~/.bashrc.
  • Instala Java Correto y configúralo con update-alternatives.
  • Extrae Android Studio en ~/development y ejecuta ./studio.
  • Acepta las licencias de Android con flutter doctor --android-licenses.
  • Instala las dependencias faltantes (clang, cmake, gtk3-devel, ninja).
  • Ejecuta flutter doctor y verifica que todas las verificaciones estén en verde.
  • Ejecuta sudo dnf upgrade y luego fwupdmgr update (si hay actualizaciones de firmware).

💡 Tips clave:

• Instalación de RPM: sudo dnf install /ruta/al/archivo.rpm.

• Extraer tar.xz: tar -xf archivo.tar.xz -C /destino.

• Extraer tar.gz: tar -zxvf archivo.tar.gz -C /destino.

• Agregar al PATH: echo 'export PATH="$PATH:$HOME/development/flutter/bin"' >> ~/.bashrc y luego source ~/.bashrc.

• Configurar Java: usar sudo update-alternatives --config java para elegir la versión correcta.

• flutter doctor: es la herramienta de diagnóstico de Flutter. Todo debe estar en verde (✔).

• Dependencias clave: clang, cmake, gtk3-devel, ninja son necesarias para Flutter en Linux.

• Actualización final: sudo dnf upgrade y fwupdmgr update mantienen el sistema y firmware actualizados.
