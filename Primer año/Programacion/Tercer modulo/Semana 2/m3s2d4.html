📘 PLANIFICACIÓN DE CLASE

Tema: Comandos de gestión de archivos en Linux (cp, mv, rm, rm -r, rm -rf)

🎯 Competencia General

Domina los comandos básicos para la gestión de archivos y directorios en Linux: copia con cp, mueve y renombra con mv, y elimina archivos y carpetas con rm, entendiendo las opciones -r y -rf para eliminaciones recursivas y forzadas, y aplica estos comandos en ejercicios prácticos de creación y borrado de carpetas.

📖 Conceptuales (Saber)

  • Comprende la función de cada comando: cp, mv, rm, rm -r, rm -rf.
  • Diferencia entre copiar y mover/renombrar archivos.
  • Reconoce el peligro del comando rm -rf y su uso responsable.
  • Entiende la opción -r (recursivo) para trabajar con directorios.

🛠️ Procedimentales (Saber hacer)

  • Copiar archivos y directorios con cp.
  • Mover y renombrar archivos y carpetas con mv.
  • Eliminar archivos con rm.
  • Eliminar directorios con contenido usando rm -r y rm -rf.
  • Crear carpetas y archivos para practicar los comandos.
  • Tomar capturas de pantalla para evidenciar el aprendizaje.

❤️ Actitudinales (Saber ser)

  • Muestra precaución al usar comandos destructivos como rm -rf.
  • Practica con orden y verificando la ubicación antes de ejecutar comandos.
  • Participa activamente en los ejercicios prácticos.
  • Desarrolla confianza en el uso de la terminal.
🟢 INICIO 15 minutos

Actividad: "Introducción a la gestión de archivos en la terminal"

Metodología: Explicación y demostración.

Descripción: El docente explica la importancia de gestionar archivos desde la terminal:

  • La terminal permite copiar, mover y eliminar archivos de manera rápida y eficiente.
  • Estos comandos son esenciales para la administración del sistema y el trabajo diario.
  • Se debe tener cuidado con los comandos que eliminan archivos, especialmente rm -rf.

Se presenta la tabla de comandos que se aprenderán en la clase.

Comando Descripción Ejemplo
cp origen destino Copia archivos o directorios. cp archivo.txt copia.txt
mv origen destino Mueve o renombra archivos/directorios. mv viejo.txt nuevo.txt
rm archivo Elimina archivos (permanentemente). rm archivo.txt
rm -r carpeta Elimina directorios y su contenido (recursivo). rm -r mi_carpeta/
rm -rf carpeta Elimina forzadamente directorios y contenido (¡peligroso!). rm -rf mi_carpeta/

⚠️ ¡PELIGRO! rm -rf

rm -rf elimina todo (archivos y carpetas) sin preguntar. Es irreversible. Nunca ejecutes rm -rf / (borraría todo el sistema). Siempre verifica la ruta antes de usarlo.

🟡 DESARROLLO 35 minutos

Actividad: "Práctica guiada de comandos cp, mv y rm"

Metodología: Demostración y práctica individual.

🔹 Paso 1: Preparar el entorno de práctica

# Crear carpeta de práctica
mkdir ~/practica_cmds
cd ~/practica_cmds
pwd
/home/tuusuario/practica_cmds

🔹 Paso 2: Crear archivos para practicar

# Crear archivos con touch
touch archivo1.txt archivo2.txt archivo3.txt
ls
archivo1.txt archivo2.txt archivo3.txt

🔹 Paso 3: Comando cp - Copiar archivos

# Copiar archivo1.txt a copia_archivo1.txt
cp archivo1.txt copia_archivo1.txt
ls
archivo1.txt archivo2.txt archivo3.txt copia_archivo1.txt

🔹 Paso 4: Comando mv - Renombrar y mover

# Renombrar archivo2.txt a archivo2_renombrado.txt
mv archivo2.txt archivo2_renombrado.txt
ls
archivo1.txt archivo2_renombrado.txt archivo3.txt copia_archivo1.txt

🔹 Paso 5: Comando mv - Mover archivo a otra carpeta

# Crear una subcarpeta
mkdir subcarpeta
# Mover archivo3.txt a subcarpeta
mv archivo3.txt subcarpeta/
ls
archivo1.txt archivo2_renombrado.txt copia_archivo1.txt subcarpeta
ls subcarpeta/
archivo3.txt

🔹 Paso 6: Comando rm - Eliminar archivos

# Eliminar copia_archivo1.txt
rm copia_archivo1.txt
ls
archivo1.txt archivo2_renombrado.txt subcarpeta

🔹 Paso 7: Comando rm -r - Eliminar directorios con contenido

# Eliminar la subcarpeta con su contenido
rm -r subcarpeta/
ls
archivo1.txt archivo2_renombrado.txt

🔹 Paso 8: Comando rm -rf - Eliminar forzadamente

# Crear una carpeta con archivos para probar rm -rf
mkdir carpeta_peligrosa
touch carpeta_peligrosa/archivo1.txt carpeta_peligrosa/archivo2.txt
ls carpeta_peligrosa/
archivo1.txt archivo2.txt

# Eliminar forzadamente (sin preguntar)
rm -rf carpeta_peligrosa/
ls
archivo1.txt archivo2_renombrado.txt

💡 Tips clave:

• cp origen destino: Copia archivos o directorios (usa cp -r para carpetas).

• mv origen destino: Mueve o renombra archivos y directorios.

• rm archivo: Elimina archivos. Es permanente.

• rm -r carpeta: Elimina carpetas con todo su contenido.

• rm -rf carpeta: Elimina forzadamente, sin preguntar. ¡MUY PELIGROSO!

• Siempre verifica la ruta antes de ejecutar rm -rf.

• Usa ls antes de borrar para confirmar que estás en el lugar correcto.
