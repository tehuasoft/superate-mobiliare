1 Rufus (Windows)
Rufus is a utility that helps format and create bootable USB drives. On Windows, download and run Rufus, select your USB stick, and choose the Fedora ISO to write it in bootable mode. Rufus es una utilidad que ayuda a formatear y crear unidades USB de arranque. En Windows, descarga y ejecuta Rufus, selecciona tu memoria USB y elige la ISO de Fedora para escribirla en modo arrancable.
2 Flash Fedora ISO
Use Rufus to write the Fedora ISO to the USB stick. Follow the on-screen setup; it will erase the USB and make it bootable. Usa Rufus para escribir la ISO de Fedora en la memoria USB. Sigue la configuración en pantalla; borrará la USB y la hará arrancable.
3 Boot & keyboard
Change the boot order in your BIOS/UEFI to boot from the USB stick. Once Fedora loads, open settings, then keyboard and select Spanish (Guatemala), the keyboard distribution would be Spanish (Latin American, dead tilde). Cambia el orden de arranque en tu BIOS/UEFI para iniciar desde la USB. Una vez que Fedora cargue, abre settings y en la seccion keyboard selecciona Spanish (Guatemala), la distribución del teclado será Spanish (Latin American, dead tilde).
4 sudo dnf check-update 

  sudo dnf check-update
Checks for available package updates without installing them. It refreshes the repository metadata and lists any updates. Verifica las actualizaciones disponibles sin instalarlas. Refresca los metadatos del repositorio y enumera las actualizaciones.
5 GNOME extensions
GNOME Shell extensions add extra features. You can install them via the Software store or use the commands below. Las extensiones de GNOME Shell añaden funciones extra. Puedes instalarlas desde la tienda de software o usar los comandos siguientes. 
            
  sudo dnf install gnome-extensions-app
Installs the GNOME Extensions application, a graphical manager for extensions. Instala la aplicación GNOME Extensions, un gestor gráfico para extensiones. 
            
  sudo dnf install gnome-tweaks
Installs GNOME Tweaks, a tool to customize fonts, themes, and advanced GNOME settings. Instala GNOME Tweaks, una herramienta para personalizar fuentes, temas y configuraciones avanzadas de GNOME.
Then open Firefox, go to addons.mozilla.org and install the GNOME Shell Integration add‑on. Allow it in private windows, then visit extensions.gnome.org and install Dash to Dock by Michele G. Luego abre Firefox, ve a addons.mozilla.org e instala el complemento GNOME Shell Integration. Permite que se ejecute en ventanas privadas, visita extensions.gnome.org e instala Dash to Dock de Michele G.
6 Google Chrome (RPM)
Download the Google Chrome RPM package from the official website. Then install it with dnf install. Descarga el paquete RPM de Google Chrome desde el sitio web oficial. Luego instálalo con dnf install. 
            
    sudo dnf install <path-to-rpm>
Replace <path-to-rpm> with the actual path to the downloaded .rpm file (e.g., sudo dnf install /home/your-user/Downloads/google-chrome-stable_current_x86_64.rpm). Reemplaza <path-to-rpm> con la ruta real del archivo .rpm descargado (ej: sudo dnf install /home/your-user/Downloads/google-chrome-stable_current_x86_64.rpm).
7 OnlyOffice & Visual Studio Code
Install OnlyOffice (from the website or Flathub) and then set up the VS Code repository as shown. Instala OnlyOffice (desde el sitio web o Flathub) y luego configura el repositorio de VS Code como se muestra. 
            
  sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc && echo -e "[code]\nname=Visual Studio Code\nbaseurl=https://packages.microsoft.com/yumrepos/vscode\nenabled=1\nautorefresh=1\ntype=rpm-md\ngpgcheck=1\ngpgkey=https://packages.microsoft.com/keys/microsoft.asc" | sudo tee /etc/yum.repos.d/vscode.repo > /dev/null
Imports Microsoft’s GPG key and creates the official VS Code repository file (/etc/yum.repos.d/vscode.repo). Importa la clave GPG de Microsoft y crea el archivo de repositorio oficial de VS Code (/etc/yum.repos.d/vscode.repo). 
            
  sudo dnf check-update
Refreshes the package list so the new VS Code repository is recognized. Refresca la lista de paquetes para que el nuevo repositorio de VS Code sea reconocido. 
            
  sudo dnf install code
Installs Visual Studio Code from the Microsoft repository. Instala Visual Studio Code desde el repositorio de Microsoft.
After opening VS Code, install the extensions: Dart, Flutter, and Prettier. Then go to Settings → type “AI features” and check Disable AI Features. Después de abrir VS Code, instala las extensiones: Dart, Flutter y Prettier. Luego ve a Configuración → escribe “AI features” y marca Disable AI Features.
8 Flutter – dependencies 
            
  sudo dnf install wget git unzip xz zip curl libstdc++.i686 mesa-libGLU
Installs essential tools: wget (download), git (version control), unzip/xz/zip (archive handling), curl (data transfer), and 32-bit libraries required by Flutter. Instala herramientas esenciales: wget (descarga), git (control de versiones), unzip/xz/zip (manejo de archivos), curl (transferencia de datos) y bibliotecas de 32 bits necesarias para Flutter.
9 Create ~/development 
            
  mkdir development
Creates a folder named development in your home directory to store the Flutter SDK and Android Studio. Crea una carpeta llamada development en tu directorio personal para almacenar el SDK de Flutter y Android Studio.
10 Flutter SDK – extract
Download the Flutter SDK (tar.xz) from the official site. Then extract it into the development folder. Descarga el SDK de Flutter (tar.xz) desde el sitio oficial. Luego extráelo en la carpeta development. 
            
  tar -xf <sdk_zip_path> -C <destination_directory_path>
Example: tar -xf /home/your-user/Downloads/flutter_linux_3.24.0-stable.tar.xz -C /home/your-user/development. This extracts the SDK into the target directory. Ejemplo: tar -xf /home/your-user/Downloads/flutter_linux_3.24.0-stable.tar.xz -C /home/your-user/development. Esto extrae el SDK en el directorio destino.
11 Add Flutter to PATH 
            
  echo 'export PATH="$PATH:$HOME/development/flutter/bin"' >> ~/.bashrc source ~/.bashrc
Appends the Flutter binary directory to the PATH variable in your .bashrc file, then source reloads the file so the change takes effect immediately. Añade el directorio bin de Flutter a la variable PATH en tu archivo .bashrc y luego recarga el archivo para que el cambio surta efecto de inmediato.
12 Java (Correto)
Download the Correto Java RPM from AWS documentation. Install it with dnf install. Then use update-alternatives to set Correto as the default. Descarga el RPM de Java Correto desde la documentación de AWS. Instálalo con dnf install. Luego usa update-alternatives para establecer Correto como predeterminado. 
            
  sudo dnf install <path-to-java-rpm>
Run the command java --version to see which version of Java you are running. Corre el comando java --version para ver que versión de Java tiene tu computadora. 
            
  java --version
If you see a version string that doesn't mention Corretto, run the following command to change the default java or javac providers. Si tras correr el commando no ve en el texto resultante la palabra Correto en ningún lado, entonces corra el siguiente comando: 
            
  sudo update-alternatives --config java
Shows a list of installed Java versions; select the number corresponding to Correto. Muestra una lista de versiones de Java instaladas; selecciona el número correspondiente a Correto. 
            
  sudo update-alternatives --config javac
Same as above, but for the Java compiler (javac). Choose the Correto option. Igual que arriba, pero para el compilador de Java (javac). Elige la opción Correto.
13 Android Studio
Download Android Studio from developer.android.com/studio. Extract it to the development folder. Descarga Android Studio desde developer.android.com/studio. Extráelo en la carpeta development. 
            
  tar -zxvf <android-studio-path> -C <destination_directory_path>
Example: tar -zxvf /home/your-user/Downloads/android-studio-2024.1.1-linux.tar.gz -C home/your-user/development. The -z flag handles gzip compression. Ejemplo: tar -zxvf /home/your-user/Downloads/android-studio-2024.1.1-linux.tar.gz -C home/your-user/development. La opción -z maneja la compresión gzip. 
            
  cd /home/your-user/development/android-studio/bin
  ./studio
Navigates to the Android Studio binary folder and launches the installer. Complete the wizard and create a desktop shortcut when prompted. Navega a la carpeta bin de Android Studio y ejecuta el instalador. Completa el asistente y crea un acceso directo en el escritorio cuando se indique.
After the wizard, open Android Studio → SDK Manager and install Android SDK Command-line Tools (latest). Click Apply & OK. Después del asistente, abre Android Studio → SDK Manager e instala Android SDK Command-line Tools (latest). Haz clic en Apply y OK.
14 flutter doctor --android-licenses 
            
  flutter doctor --android-licenses
Accepts all Android SDK licenses. You’ll be prompted to type y for each license. Acepta todas las licencias del SDK de Android. Se te pedirá que escribas y para cada licencia.
15 Missing dependencies 
            
  sudo dnf install glx-utils egl-utils
Installs Mesa utilities for OpenGL and EGL, often required for graphics and Flutter emulation. Instala utilidades Mesa para OpenGL y EGL, a menudo necesarias para gráficos y emulación de Flutter. 
            
  sudo dnf install clang
Installs the Clang compiler, which some Flutter dependencies expect. Instala el compilador Clang, que algunas dependencias de Flutter esperan. 
            
  sudo dnf install cmake
Installs CMake, a build system generator used by certain Flutter plugins. Instala CMake, un generador de sistemas de compilación usado por algunos plugins de Flutter. 
            
  sudo dnf install gtk3-devel
Installs GTK 3 development headers (libgtk-3-dev) needed for Flutter’s Linux desktop embedding. Instala los encabezados de desarrollo de GTK 3 (libgtk-3-dev) necesarios para la integración de Flutter en Linux. 
            
  sudo dnf install ninja
Installs a performance‑optimized build tool that helps compile native dependencies faster and more reliably when working with Flutter on Linux. Instala una herramienta optimizada en desempeño que ayuda a compilar dependencias nativas más rápido y de manera más confiable cuando se trabaja con Flutter en Linux.
⚠️ Final upgrades (only after all previous steps)
WARNING: Do these upgrades only after completing all the previous steps. ADVERTENCIA: Realiza estas actualizaciones solo después de completar todos los pasos anteriores. 
            
  sudo dnf upgrade
Upgrades all installed packages to the latest available versions from the repositories. Actualiza todos los paquetes instalados a las versiones más recientes disponibles en los repositorios. 
            
  sudo dnf upgrade --refresh
Forces a refresh of repository metadata before upgrading, ensuring you have the latest package lists. Fuerza un refresco de los metadatos del repositorio antes de actualizar, asegurando que tengas las listas de paquetes más recientes.
This synchronizes your system with the active Fedora mirrors and ensures the package manager sees the correct fwupd versions. Esto sincroniza tu sistema con los espejos activos de Fedora y garantiza que el gestor de paquetes vea las versiones correctas de fwupd. 
            
  sudo dnf search fwupd-plugin-uefi-capsule-data
Searches for the fwupd-plugin-uefi-capsule-data package to verify it is available for your release. Busca el paquete fwupd-plugin-uefi-capsule-data para verificar que esté disponible para tu versión. 
            
  fwupdmgr refresh
Refreshes the firmware metadata from the Linux Vendor Firmware Service (LVFS). Refresca los metadatos de firmware desde el Servicio de Firmware de Proveedores Linux (LVFS). 
            
  fwupdmgr update
Updates your system firmware (BIOS/UEFI) using the fwupd service, if updates are available. Actualiza el firmware de tu sistema (BIOS/UEFI) usando el servicio fwupd, si hay actualizaciones disponibles.
