📘 PLANIFICACIÓN DE CLASE

Tema: Comandos básicos de la terminal de Linux (pwd, cd, mkdir, ls, clear)

🎯 Competencia General

Comprende y aplica los comandos básicos de la terminal de Linux para navegar por el sistema de archivos, crear directorios, listar contenido y limpiar la pantalla, desarrollando habilidades fundamentales para la administración del sistema y el trabajo en entornos de línea de comandos.

📖 Conceptuales (Saber)

  • Comprende la estructura jerárquica del sistema de archivos en Linux (directorio raíz, home).
  • Reconoce la función de cada comando: pwd, cd, cd .., cd (sin argumentos), mkdir, ls, ls -la, clear.
  • Diferencia entre rutas absolutas y relativas.
  • Entiende el propósito de listar archivos ocultos con ls -la.

🛠️ Procedimentales (Saber hacer)

  • Mostrar la ruta del directorio actual con pwd.
  • Cambiar de directorio con cd y sus variantes.
  • Crear directorios con mkdir.
  • Listar archivos y directorios con ls y ls -la.
  • Limpiar la pantalla de la terminal con clear.
  • Tomar capturas de pantalla de la terminal para evidenciar el aprendizaje.

❤️ Actitudinales (Saber ser)

  • Muestra confianza al usar la terminal.
  • Practica con precisión y atención a los detalles.
  • Participa activamente en los ejercicios prácticos.
  • Valora la importancia de la terminal como herramienta fundamental en Linux.
🟢 INICIO 15 minutos

Actividad: "Introducción a la terminal de Linux"

Metodología: Explicación y demostración.

Descripción: El docente explica la importancia de la terminal en Linux:

  • La terminal es una interfaz de texto que permite interactuar con el sistema operativo.
  • Es una herramienta poderosa para administrar archivos, instalar software y configurar el sistema.
  • Muchas tareas se pueden hacer más rápido y con mayor control desde la terminal.

Se presenta la tabla de comandos que se aprenderán en la clase.

Comando Descripción Ejemplo
pwd Muestra la ruta del directorio actual (Print Working Directory). pwd → /home/usuario
cd /ruta Cambia al directorio especificado (Change Directory). cd /etc → va a /etc
cd .. Sube un nivel en la jerarquía de directorios. cd .. → sube al directorio padre
cd Sin argumentos, te lleva directamente al directorio home del usuario. cd → /home/usuario
mkdir carpeta Crea un nuevo directorio (Make Directory). mkdir proyectos → crea la carpeta "proyectos"
ls Lista archivos y carpetas del directorio actual (List). ls → muestra archivos y carpetas visibles
ls -la Lista todos los archivos (incluidos ocultos) con detalles (permisos, propietario, tamaño, fecha). ls -la → muestra información detallada
clear Limpia la pantalla de la terminal. clear → pantalla limpia

💡 Tips clave:

• pwd: Siempre útil para saber dónde estás.

• cd: Usa cd .. para subir un nivel y cd para ir al home.

• ls -la: El comando más completo para ver archivos y detalles.

• mkdir: Para crear carpetas. Puedes crear varias a la vez: mkdir carpeta1 carpeta2.

• clear: Mantiene la terminal ordenada.

• Rutas absolutas: Comienzan con / (ej: cd /etc).

• Rutas relativas: No comienzan con / y son relativas al directorio actual.
