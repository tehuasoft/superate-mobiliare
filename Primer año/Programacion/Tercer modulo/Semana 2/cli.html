🐧 Linux · comandos

cheat sheet · imprimir
pwd
Muestra dónde estás ahora en el ordenador.
pwd
📍 te dice la ruta completa donde estas
ls
Enseña los nombres de las cosas que hay aquí.
ls
📁 archivos y carpetas
ls -la
Muestra todo, incluso lo escondido, con muchos detalles.
ls -la
🔍 permisos, dueño, tamaño
cd /ruta-a-la-carpeta
Te mueves a otro lugar que elijas.
cd /home/user/Documents
🚶 entra en una carpeta
cd ..
Subes un paso atrás, a la carpeta de antes.
cd ..
⬆️ retrocede una carpeta
cd
Sin nada más, te lleva directo a tu casa (tu carpeta personal).
cd
🏠 vuelve a tu carpeta de inicio
mkdir
Crea una carpeta nueva con el nombre que pongas.
mkdir archivos
📂 hace una carpeta llamada "archivos"
cp
Copia un archivo y lo pone en otro sitio.
cp archivo.txt /ruta/donde/lo/quieres/copiar
📄 copiar y pegar
mv
Mueve o cambia el nombre de un archivo o carpeta.
mv archivo.txt /ruta/donde/lo/quieres/mover
🔀 mover o renombrar
rm
Borra un archivo para siempre. No vuelve. No borra carpetas
rm archivo.txt
🗑️ eliminar archivo.txt
rm -r
Borra una carpeta y todo lo de dentro.
rm -r /ruta/carpeta/que/quieres/borrar
📁🗑️ borrar carpeta y contenido
rm -rf
Borra sin preguntar y con más fuerza. ¡Cuidado!
rm -rf /ruta/carpeta/que/quieres/borrar
⚠️ fuerza bruta, no pregunta, nunca corras sudo rm -rf
clear
Limpia la pantalla para que no veas lo de antes.
clear
🧹 pantalla limpia
⏺️ cada comando hace una cosa simple · usa cd para moverte, ls para ver
