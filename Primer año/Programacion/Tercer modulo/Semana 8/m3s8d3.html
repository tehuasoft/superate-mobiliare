🔹 Jerarquía visual

📌 ¿Qué es la jerarquía?

Es el orden de importancia de los elementos en la pantalla. Guía la atención del usuario de lo más importante a lo menos importante.

Se logra con:

  • Color: Colores llamativos para elementos importantes, colores neutros para secundarios.
  • Tamaño: Elementos más grandes = más importancia.
  • Peso (bold): Texto en negrita destaca sobre texto regular.
  • Espaciado: Más espacio alrededor = más importancia.
🎯 Jerarquía con color y tamaño
Título principal (grande, color fuerte)
Subtítulo (mediano, color de acento)
Cuerpo del texto (tamaño normal, color neutro)
Texto secundario / pequeño (tamaño reducido, color tenue)
Botón principal (color fuerte) Botón secundario (color neutro)
📌 ¿Qué quiero destacar con el color?

El color atrae la atención. Úsalo para elementos clave: botones de acción, títulos importantes, llamados a la acción (CTA).

📌 ¿Qué quiero destacar con el tamaño?

El tamaño establece jerarquía. Los títulos deben ser grandes, el cuerpo más pequeño, la información secundaria aún más pequeña.

🔹 Layout — Distribución en la pantalla

📌 ¿Qué es el layout?

Es la forma en que se organizan los elementos en la interfaz. Un buen layout es equilibrado, ordenado y fácil de escanear.

Consejos:

  • No hacer la pantalla demasiado larga (el usuario se cansa de scroll).
  • No hacerla demasiado corta (se siente incompleta).
  • Usa grillas para organizar el contenido.
  • Distribuye el peso visual de manera equilibrada.

🔹 Alineación — Pocos puntos de alineación

📌 ¿Qué es la alineación?

Es la forma en que se alinean los elementos entre sí. Lo recomendable es usar pocos puntos de alineación (1 o 2) para mantener el orden y la limpieza.

Regla: Alinea todo a la izquierda, al centro o a la derecha. No mezcles muchas alineaciones en una misma pantalla.

⬅️ Alineación a la izquierda (la más común para texto)
⬆️ Alineación al centro (para títulos o elementos destacados)
➡️ Alineación a la derecha (menos común, para números o precios)

✅ Recomendación: usa 1 o 2 alineaciones como máximo.

🔹 White Space (Espacio blanco / espacio negativo)

📌 ¿Qué es el white space?

Es el espacio vacío entre los elementos. No es espacio desperdiciado, es espacio que mejora la legibilidad, la claridad y la estética.

Beneficios:

  • Hace que el diseño se vea más limpio.
  • Hace que el diseño se vea más caro y premium.
  • Ayuda a la comprensión del contenido.

🔹 Audiencia — ¿Para quién diseño?

📌 ¿Qué es la audiencia?

Es el público objetivo al que va dirigido el producto. El diseño debe adaptarse a sus necesidades, gustos y expectativas.

Preguntas clave:

  • ¿Quién es mi usuario? (edad, profesión, intereses)
  • ¿Qué espera de la interfaz?
  • ¿Qué colores, tipografías y estilos le atraen?
👶 Audiencia juvenil (15-25 años)

Colores vibrantes, tipografías modernas, layouts dinámicos, mucho espacio, elementos divertidos.

Ejemplo: TikTok, Instagram, marcas de moda joven.

🧑‍💼 Audiencia profesional (25-50 años)

Colores sobrios (azul, gris), tipografías serias, layouts limpios, información clara y directa.

Ejemplo: LinkedIn, bancos, software empresarial.

🌿 Audiencia ecológica / saludable

Colores verdes, tonos tierra, tipografías orgánicas, espacios amplios, sensación de calma.

Ejemplo: marcas de productos orgánicos, wellness.

💎 Audiencia de lujo

Colores oscuros (negro, dorado), tipografías serif elegantes, mucho white space, minimalismo.

Ejemplo: marcas de moda premium, joyería.

📌 Dependiendo de mi público, así será mi diseño:

Si diseño para adolescentes, usaré colores brillantes y tipografías modernas. Si diseño para ejecutivos, usaré colores sobrios y layouts formales. ¡El diseño debe hablar el idioma de tu audiencia!

📝 Actividad práctica

Instrucciones:

  • 1. Elige una audiencia (juvenil, profesional, ecológica, lujo).
  • 2. Diseña una interfaz (puede ser en papel o herramienta digital) para una aplicación de recordatorios.
  • 3. Aplica jerarquía: usa color y tamaño para destacar lo importante.
  • 4. Aplica layout: distribuye elementos de forma equilibrada.
  • 5. Usa pocos puntos de alineación (máximo 2).
  • 6. Incluye white space para que se vea limpio.
  • 7. Explica cómo tu diseño se adapta a la audiencia elegida.

Preguntas de reflexión:

  • ¿Cómo cambia el diseño si cambia la audiencia?
  • ¿Por qué el white space hace que un diseño se vea "más caro"?
  • ¿Cuántos puntos de alineación recomiendas usar?

💡 Tips clave para UI Design:

• Jerarquía: Usa color y tamaño para guiar la atención.

• Color: Destaca lo importante (botones, títulos).

• Tamaño: Más grande = más importante.

• Layout: Equilibrado, ni muy largo ni muy corto.

• Alineación: Máximo 2 puntos de alineación.

• White Space: Hace que el diseño se vea limpio y premium.

• Audiencia: Diseña para tu usuario, no para ti.

• Pregunta siempre: ¿A quién le estoy diseñando?
