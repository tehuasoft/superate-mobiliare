📘 PLANIFICACIÓN DE CLASE

Ejercicios con ciclos · Diagramas de flujo UML

🎯 Competencia General

El estudiante practica la representación de algoritmos con ciclos mediante diagramas de flujo UML para dos ejercicios: un contador personalizado (ascendente/descendente) y un generador de tablas de multiplicar con control de flujo (continuar/salir).

📖 Conceptuales (Saber)

  • Comprende la estructura de un diagrama de flujo UML con ciclos.
  • Reconoce los elementos: inicio, fin, proceso, decisión, bucle (while/for).
  • Identifica condiciones de control de ciclos y condiciones de salida.

🛠️ Procedimentales (Saber hacer)

  • Dibujar diagramas de flujo con ciclos while y for.
  • Representar contadores ascendentes y descendentes.
  • Representar validación de entrada del usuario para continuar o salir.
  • Interpretar y traducir diagramas a código Dart.

❤️ Actitudinales (Saber ser)

  • Muestra interés por resolver problemas con ciclos.
  • Valora la planificación antes de codificar.
  • Participa activamente en la creación de diagramas.
  • Desarrolla una actitud meticulosa en el diseño.

Actividad: "Repaso de ciclos en UML y presentación de ejercicios"

Metodología: Repaso y organización.

El docente repasa los elementos de UML para ciclos: cómo se representa un while (condición al inicio con rombo y flecha de retorno) y un for (inicialización, condición, incremento). Luego presenta los dos ejercicios.

📌 Ejercicios de la clase:
  1. Contador personalizado: El programa pide dos números (inicio y fin). Si inicio > fin, cuenta hacia atrás. Si inicio <= fin, cuenta hacia adelante.

🟡 DESARROLLO 50 minutos

Actividad: "Diseño de diagramas de flujo con ciclos"

Metodología: Explicación guiada + práctica individual/grupal en Draw.io.

📌 Ejercicio 1: Contador personalizado

Enunciado: El programa pide al usuario dos números: uno para iniciar y otro para terminar. Si el número inicial es mayor que el final, cuenta hacia atrás. En caso contrario, cuenta hacia adelante.

Entrada: inicio (int), fin (int)

Salida: Secuencia de números desde inicio hasta fin (ascendente o descendente)

📊 Diagrama de flujo UML:
Inicio → 📥 Leer inicio, fin → ❓ ¿inicio > fin?
❓ (No) → 🔹 i = inicio → ❓ ¿i <= fin?
❓ (Sí) → 📤 imprimir i → 🔹 i = i + 1 ↻
❓ (No) → Fin
❓ (Sí) → 🔹 i = inicio → ❓ ¿i >= fin?
❓ (Sí) → 📤 imprimir i → 🔹 i = i - 1 ↻
❓ (No) → Fin
📌 Si inicio > fin, se usa un ciclo con decremento (i = i - 1). Si no, se usa un ciclo con incremento (i = i + 1).
💻 Código equivalente en Dart:
void main() { int inicio = 5; int fin = 1; if (inicio > fin) { for (int i = inicio; i >= fin; i--) { print(i); } } else { for (int i = inicio; i <= fin; i++) { print(i); } } }
📌 Ejercicio 2: Tablas de multiplicar del 0 al 12 con control

Enunciado: Muestra las tablas de multiplicar del 0 al 12. Después de imprimir una tabla, pregunta al usuario si desea continuar a la siguiente. Si responde "sí" (o "si") sigue, si responde "no" termina, cualquier otra opción muestra "opción inválida, saliendo del programa" y termina.

Entrada: opción (String)

Salida: Tablas de multiplicar, mensajes de control

📊 Diagrama de flujo UML:
Inicio → 🔹 tabla = 0 → ❓ ¿tabla <= 12?
❓ (Sí) → 🔹 i = 0 → ❓ ¿i <= 12?
❓ (Sí) → 📤 tabla + "x" + i + "=" + (tabla*i) → 🔹 i = i + 1 ↻
❓ (No) → 📤 "¿Continuar? (si/no)" → 📥 Leer opcion
❓ ❓ ¿opcion == "si" o "sí"?
❓ (Sí) → 🔹 tabla = tabla + 1 ↻
❓ (No) → ❓ ¿opcion == "no"?
❓ (Sí) → Fin
❓ (No) → 📤 "opción inválida, saliendo del programa" → Fin
❓ (No, tabla > 12) → Fin
📌 Ciclo externo: tabla de 0 a 12. Ciclo interno: multiplicadores de 0 a 12. Después de cada tabla, pregunta al usuario.
💻 Código equivalente en Dart:
import 'dart:io'; void main() { for (int tabla = 0; tabla <= 12; tabla++) { for (int i = 0; i <= 12; i++) { print("$tabla x $i = ${tabla * i}"); } print("¿Continuar? (si/no)"); String opcion = stdin.readLineSync()!; if (opcion == "si" || opcion == "sí") { // continuar } else if (opcion == "no") { break; } else { print("opción inválida, saliendo del programa"); break; } } }

💡 Tips clave para diagramas de flujo con ciclos:

• Ciclo while: rombo con condición al inicio, flecha de retorno desde el proceso.

• Ciclo for: se representa con inicialización (proceso), condición (rombo) e incremento (proceso) con flecha de retorno.

• Contador ascendente: incremento (i = i + 1) y condición (i <= fin).

• Contador descendente: decremento (i = i - 1) y condición (i >= fin).

• Ciclo anidado: un ciclo dentro de otro (como el de las tablas).

• Validación de entrada: decisión con comparación de Strings (== "si", == "no").

• Salida anticipada: usar un rombo para decidir si salir del ciclo o terminar el programa.
