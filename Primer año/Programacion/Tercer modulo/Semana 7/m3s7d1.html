⬤ Inicio → 🔹 Variable → 🔶 Condición → 🔄 Ciclo → ⬤ Fin

🔹 Variables y asignaciones en UML

📌 Representación de variables en UML

Se usa un rectángulo (proceso) con la acción de asignación o declaración de variable.

Ejemplo: edad = 18 o nombre = "Ana"

Inicio → 📦 int edad = 18 → 📦 String nombre = "Ana" → Fin
📌 Las variables se representan en rectángulos de proceso con la acción de asignación

🔹 Condiciones (if, if-else) en UML

📌 Representación de condiciones en UML

Se usa un rombo (decisión) con una pregunta o condición. Las flechas de salida indican el camino Sí (verdadero) y No (falso).

Inicio → ❓ ¿edad >= 18? → (Sí) ✅ "Eres mayor" → Fin
❓ ¿edad >= 18? (No) → ❌ "Eres menor" → Fin
📌 El rombo representa la condición. Las flechas indican los caminos Sí (verdadero) y No (falso).
// Código equivalente en Dart if (edad >= 18) { print("Eres mayor"); } else { print("Eres menor"); }

🔹 Ciclos en UML: for, while, do-while

🔄 for

Uso: Cuando se conoce el número de iteraciones.

Estructura: Inicialización, condición, incremento.

Notación: Rectángulo con la condición de control.

🔄 while

Uso: Cuando la condición se evalúa al inicio.

Estructura: Condición de entrada.

Notación: Rombo que decide si entrar al ciclo.

🔄 do-while

Uso: Cuando el bloque debe ejecutarse al menos una vez.

Estructura: Ejecuta y luego evalúa condición.

Notación: Rombo al final del bloque.

🔹 Ciclo for en UML

Inicio → 🔹 i = 0 → ❓ ¿i < 5? → (Sí) 📦 Proceso → 🔹 i++ ↻
❓ ¿i < 5? (No) → Fin
📌 El for se representa con: inicialización → condición → proceso → incremento → vuelta a condición
// Código equivalente en Dart for (int i = 0; i < 5; i++) { print(i); }

🔹 Ciclo while en UML

Inicio → ❓ ¿condición? → (Sí) 📦 Proceso ↻
❓ ¿condición? (No) → Fin
📌 El while se representa con un rombo de condición al inicio. Si es verdadero, entra al proceso y vuelve a la condición.
// Código equivalente en Dart int i = 0; while (i < 5) { print(i); i++; }

🔹 Ciclo do-while en UML

Inicio → 📦 Proceso → ❓ ¿condición? → (Sí) ↻ ↻
❓ ¿condición? (No) → Fin
📌 El do-while se representa con el proceso primero y la condición al final. Se ejecuta al menos una vez.
// Código equivalente en Dart int i = 0; do { print(i); i++; } while (i < 5);

🔹 Práctica en Draw.io

Instrucciones para usar Draw.io:
  • 1. Abrir draw.io
  • 2. Seleccionar "Crear nuevo diagrama" → elegir "Diagrama en blanco"
  • 3. En la barra lateral, buscar "UML" o usar formas básicas:
    • Círculo: Inicio / Fin
    • Rectángulo: Proceso (asignación, operación)
    • Rombo: Decisión (condición)
    • Flechas: Conectar elementos
  • 4. Arrastrar y soltar formas, conectar con flechas.
  • 5. Hacer doble clic en las formas para escribir texto.

💡 Tips clave para UML básico en Draw.io:

• Variables: rectángulo con asignación (ej. edad = 18).

• Condiciones: rombo con pregunta (ej. ¿edad >= 18?).

• for: inicialización → condición → proceso → incremento → vuelta.

• while: condición al inicio → proceso → vuelta a condición.

• do-while: proceso → condición al final → vuelta si es verdadero.

• Sí (Verdadero) y No (Falso) son las dos salidas de un rombo.

• En Draw.io, usa las formas básicas y conecta con flechas.

• No se usan clases ni funciones en este nivel de UML.
