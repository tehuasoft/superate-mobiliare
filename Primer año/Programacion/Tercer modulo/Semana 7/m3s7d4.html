📌 Ejercicio 1: Adivinador de número

Enunciado: Hay una variable hardcoded al principio (ej. numeroSecreto = 42). El usuario tiene 7 intentos para adivinar. En cada intento, el programa indica si el número ingresado es más alto o más bajo que el número secreto. Si acierta, felicita y termina. Si se quedan sin intentos, muestra "Perdiste, el número era X".

Entrada: intento (int)

Salida: Pistas ("Más alto", "Más bajo"), mensaje de victoria o derrota

📊 Diagrama de flujo UML:
Inicio → 🔹 secreto = 42 → 🔹 intentos = 0 → ❓ ¿intentos < 7?
❓ (Sí) → 📥 Leer numero → ❓ ¿numero == secreto?
❓ (Sí) → 📤 "¡Felicidades!" → Fin
❓ (No) → ❓ ¿numero > secreto?
❓ (Sí) → 📤 "Más bajo" → 🔹 intentos++ ↻
❓ (No) → 📤 "Más alto" → 🔹 intentos++ ↻
❓ (No, intentos >= 7) → 📤 "Perdiste, era X" → Fin
📌 Ciclo while con contador de intentos. Condiciones anidadas para comparar y dar pistas.
💻 Código equivalente en Dart:
void main() { int secreto = 42; int intentos = 0; while (intentos < 7) { print("Adivina el número:"); int numero = int.parse(stdin.readLineSync()!); if (numero == secreto) { print("¡Felicidades!"); return; } else if (numero > secreto) { print("Más bajo"); } else { print("Más alto"); } intentos++; } print("Perdiste, el número era $secreto"); }
📌 Ejercicio 2: Menú de cajero automático

Enunciado: Menú con opciones: 1. Consultar saldo, 2. Retirar, 3. Depositar, 4. Salir. Reglas: No retirar más del disponible, no depositar cantidades negativas. Después de cada operación vuelve al menú. Opción inválida → "Opción inválida".

Entrada: opción (int), cantidad (double)

Salida: Saldo actual, mensajes de éxito/error

📊 Diagrama de flujo UML:
Inicio → 🔹 saldo = 1000.0 → 📤 Menú (1-4) → 📥 Leer opcion
❓ ¿opcion == 1? (Sí) → 📤 "Saldo: X" ↻
❓ (No) → ❓ ¿opcion == 2?
❓ (Sí) → 📥 Leer cantidad → ❓ ¿cantidad <= saldo y cantidad > 0?
❓ (Sí) → 🔹 saldo = saldo - cantidad → 📤 "Retiro exitoso" ↻
❓ (No) → 📤 "Fondos insuficientes o cantidad inválida" ↻
❓ (No) → ❓ ¿opcion == 3?
❓ (Sí) → 📥 Leer cantidad → ❓ ¿cantidad > 0?
❓ (Sí) → 🔹 saldo = saldo + cantidad → 📤 "Depósito exitoso" ↻
❓ (No) → 📤 "Cantidad inválida" ↻
❓ (No) → ❓ ¿opcion == 4?
❓ (Sí) → Fin
❓ (No) → 📤 "Opción inválida" ↻
📌 Ciclo infinito (while true) con condiciones para cada opción. Validaciones de saldo y cantidad negativa.
💻 Código equivalente en Dart:
import 'dart:io'; void main() { double saldo = 1000.0; while (true) { print("1. Consultar saldo"); print("2. Retirar"); print("3. Depositar"); print("4. Salir"); int opcion = int.parse(stdin.readLineSync()!); if (opcion == 1) { print("Saldo: $saldo"); } else if (opcion == 2) { print("Cantidad a retirar:"); double cantidad = double.parse(stdin.readLineSync()!); if (cantidad <= saldo && cantidad > 0) { saldo -= cantidad; print("Retiro exitoso"); } else { print("Fondos insuficientes o cantidad inválida"); } } else if (opcion == 3) { print("Cantidad a depositar:"); double cantidad = double.parse(stdin.readLineSync()!); if (cantidad > 0) { saldo += cantidad; print("Depósito exitoso"); } else { print("Cantidad inválida"); } } else if (opcion == 4) { break; } else { print("Opción inválida"); } } }

💡 Tips clave para diagramas de flujo con ciclos y validaciones:

• Límite de intentos: contador + condición de salida (intentos < max).

• Validación de saldo: comparar cantidad <= saldo en un rombo.

• Menú: ciclo infinito (while true) con opciones y break para salir.

• Opción inválida: usar else o default con mensaje de error.

• Depósito negativo: validar cantidad > 0.

• Ciclo de retorno: flecha desde el final de cada opción hacia el menú.
