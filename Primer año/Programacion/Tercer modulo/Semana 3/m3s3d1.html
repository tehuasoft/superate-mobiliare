📘 PLANIFICACIÓN DE CLASE

Tema: Primer proyecto en Dart - Creación, estructura y ejecución

🎯 Competencia General

Configura y crea su primer proyecto en Dart utilizando la línea de comandos, comprende la estructura de un proyecto Dart, identifica el código boilerplate, y ejecuta su primer programa usando dart run, sentando las bases para el desarrollo en Dart y Flutter.

📖 Conceptuales (Saber)

  • Comprende el propósito del comando dart --version para verificar la instalación.
  • Reconoce la estructura de un proyecto Dart (bin, lib, pubspec.yaml).
  • Define qué es código boilerplate y su utilidad para iniciar proyectos.
  • Entiende el flujo de trabajo: crear proyecto → editar código → ejecutar.

🛠️ Procedimentales (Saber hacer)

  • Verificar la instalación de Dart con dart --version.
  • Crear una carpeta contenedora para proyectos (mkdir dartpedia).
  • Navegar a la carpeta (cd dartpedia).
  • Crear un nuevo proyecto Dart con dart create <nombre-proyecto>.
  • Ejecutar el proyecto con dart run.
  • Abrir el archivo principal en VS Code desde la terminal con code bin/<archivo>.dart.
  • Modificar el código boilerplate y volver a ejecutar.

❤️ Actitudinales (Saber ser)

  • Muestra orden al organizar sus proyectos en carpetas.
  • Explora con curiosidad el código generado por Dart.
  • Participa activamente en la creación y ejecución de su primer programa.
  • Comparte dudas y soluciones con compañeros.

🟡 DESARROLLO 35 minutos

Actividad: "Creando y ejecutando el primer proyecto en Dart"

Metodología: Demostración paso a paso + práctica individual.

🔹 Paso 1: Crear carpeta para proyectos

# Crear carpeta dartpedia en el home
mkdir ~/dartpedia

# Navegar a la carpeta
cd ~/dartpedia

# Verificar ubicación actual
pwd
/home/usuario/dartpedia

Si el estudiante prefirió otro nombre para la carpeta, debe navegar a esa carpeta (cd <nombre-carpeta>).

🔹 Paso 2: Crear un proyecto en Dart

El comando dart create genera la estructura de archivos necesaria para un proyecto Dart.

# Crear proyecto llamado "mi_primer_proyecto"
dart create mi_primer_proyecto

# Navegar dentro del proyecto
cd mi_primer_proyecto
📁 Estructura del proyecto creada:
mi_primer_proyecto/
├── bin/
│ └── mi_primer_proyecto.dart ← Archivo principal
├── lib/
│ └── (código adicional)
├── test/
│ └── (pruebas unitarias)
└── pubspec.yaml ← Configuración del proyecto (dependencias, nombre, versión)

🔹 Paso 3: Ejecutar el proyecto

Dentro de la carpeta del proyecto, ejecutar dart run para correr el código.

# Ejecutar el código del proyecto
dart run
Hello world!
Hello, Dart!

🔹 Paso 4: Editar el archivo principal

El archivo principal se encuentra en bin/ y tiene el nombre del proyecto.

Opciones para abrir y editar:

  • Opción 1 (recomendada): Desde la terminal, navegar a la carpeta bin y ejecutar code <archivo>.dart.
  • Opción 2: Abrir VS Code, seleccionar "Abrir carpeta" y elegir la carpeta del proyecto.
  • Opción 3: Navegar al archivo en el explorador de archivos y abrirlo con VS Code (clic derecho → Abrir con...).
# Navegar a la carpeta bin y abrir el archivo
cd bin/
code mi_primer_proyecto.dart

🔹 Paso 5: ¿Qué es código boilerplate?

El código boilerplate es el código inicial que genera la herramienta (dart create) para que el proyecto funcione de inmediato. Incluye:

  • La función principal void main() { ... }.
  • Un print("Hello world!") básico.
  • La estructura de carpetas necesaria.

Este código sirve como punto de partida para comenzar a programar sin tener que configurar todo desde cero.

🔹 Paso 6: Modificar y ejecutar nuevamente

Editar el archivo .dart para cambiar el mensaje:

// Cambiar el print en el archivo .dart
void main() {
print("¡Hola, mundo desde Dart!");
}

Guardar el archivo y ejecutar nuevamente dart run desde la terminal (estando en la raíz del proyecto).

# Volver a ejecutar
dart run
¡Hola, mundo desde Dart!

💡 Tips clave:

• dart --version: siempre verifica que Dart esté instalado antes de crear un proyecto.

• mkdir dartpedia: organiza todos tus proyectos en una carpeta principal.

• dart create <nombre>: genera toda la estructura del proyecto automáticamente.

• dart run: ejecuta el código del proyecto. Siempre ejecútalo desde la raíz del proyecto.

• code bin/archivo.dart: abre el archivo principal en VS Code directamente desde la terminal.

• El código boilerplate ahorra tiempo y te permite concentrarte en la lógica de tu programa.

• Estructura: bin/ (código ejecutable), lib/ (bibliotecas), pubspec.yaml (configuración).
