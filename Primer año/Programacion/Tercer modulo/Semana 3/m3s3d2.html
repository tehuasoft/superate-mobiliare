🔹 Tipos de datos básicos en Dart

📌 int — Números enteros

Representa números enteros sin parte decimal.

int edad = 30; int temperatura = -5; int poblacion = 8000000;
📌 double — Números con punto decimal

Representa números con parte decimal (precisión doble).

double altura = 1.82; double pi = 3.1416; double peso = 68.5;
📌 String — Cadenas de texto

Representa texto entre comillas simples o dobles.

String nombre = "Carlos"; String mensaje = 'Hola mundo'; String saludo = "Bienvenido";
📌 bool — Booleano (verdadero/falso)

Representa valores lógicos: true o false.

bool esMayorEdad = true; bool tieneLicencia = false;

🔹 Concatenación de Strings con el operador +

Concatenación: Unir dos o más Strings en uno solo usando el operador +.
📌 Concatenación básica con +

Une dos o más Strings usando el operador +.

String nombre = "Carlos"; String apellido = "García"; String nombreCompleto = nombre + " " + apellido; // nombreCompleto = "Carlos García"
📌 Concatenar String con otros tipos usando .toString()

Para concatenar un String con un int o double, debemos convertir el número a String usando .toString().

String nombre = "Ana"; int edad = 25; double altura = 1.68; // Concatenación con números usando .toString() String mensaje = "Mi nombre es " + nombre + ", tengo " + edad.toString() + " años y mido " + altura.toString() + " m"; // mensaje = "Mi nombre es Ana, tengo 25 años y mido 1.68 m"
📌 Concatenar String con bool usando .toString()

Al igual que con los números, para concatenar un bool debemos usar .toString().

String nombre = "Luis"; bool esActivo = true; String mensaje = "Usuario: " + nombre + ", Activo: " + esActivo.toString(); // mensaje = "Usuario: Luis, Activo: true"
📌 Ejemplo completo de concatenación:
void main() { String nombre = "María"; String apellido = "López"; int edad = 28; double altura = 1.78; bool esEstudiante = true; // Concatenación paso a paso String nombreCompleto = nombre + " " + apellido; String mensaje = "Hola, soy " + nombreCompleto + ". Tengo " + edad.toString() + " años, mido " + altura.toString() + " m y soy estudiante: " + esEstudiante.toString(); print(mensaje); // Salida: "Hola, soy María López. Tengo 28 años, mido 1.78 m y soy estudiante: true" }

💡 Tips clave para Dart:

• int: números enteros (sin decimales).

• double: números con decimales.

• String: texto entre comillas simples o dobles.

• bool: true o false.

• Concatenación con +: une Strings, requiere .toString() para otros tipos.

• Usa .toString() para convertir int, double o bool a String antes de concatenar.
