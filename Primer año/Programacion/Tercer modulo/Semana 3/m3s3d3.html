🔹 Type Inference (Inferencia de tipos) con var

Type inference: Dart deduce automáticamente el tipo de la variable según el valor asignado. Esto permite escribir código más limpio sin especificar el tipo explícitamente.
// Inferencia de tipos con var var nombre = "Carlos"; // String var edad = 30; // int var altura = 1.75; // double var activo = true; // bool // Una vez inferido el tipo, no se puede cambiar // nombre = 42; // Error: no se puede asignar int a String // Pero SÍ se puede cambiar el valor, siempre que sea del mismo tipo nombre = "Ana"; // Válido: sigue siendo String edad = 31; // Válido: sigue siendo int

🔹 var — Variables mutables con inferencia

var: Declara una variable cuyo tipo es inferido por Dart. Puede cambiar su valor (reasignarse), pero NO puede cambiar su tipo.
// Ejemplos con var var ciudad = "Madrid"; // String ciudad = "Barcelona"; // ✅ Válido: cambia el valor // ciudad = 42; // ❌ Error: no se puede cambiar el tipo var temperatura = 22.5; // double temperatura = 23.0; // ✅ Válido // temperatura = "cálido"; // ❌ Error: no se puede cambiar el tipo

🔹 final — Variables que se asignan una sola vez

final: Una variable final solo puede ser asignada una vez. Se determina en tiempo de ejecución (runtime).
Importante: Una vez asignada, NO se puede reasignar.
final String nombre = "María"; // nombre = "Laura"; // ❌ Error: no se puede reasignar final edad = 28; // inferido como int // edad = 29; // ❌ Error: no se puede reasignar final altura = 1.78; // inferido como double // final se puede usar con tipos explícitos o con inferencia final String apellido = "García"; final pais = "Argentina"; // inferido como String

🔹 const — Constantes en tiempo de compilación

const: Una variable const es una constante que se define en tiempo de compilación (compile-time). Debe asignarse con un valor conocido en el momento de compilación.
Importante: NO se puede reasignar.
const double pi = 3.14159; const int diasSemana = 7; const String mensaje = "Bienvenido"; // const no se puede reasignar // PI = 3.14; // ❌ Error: no se puede reasignar una constante // Error: no se puede usar const con valores que no son constantes // const fecha = DateTime.now(); // ❌ Error: DateTime.now() no es constante // const también infiere el tipo const gravedad = 9.8; // inferido como double const nombreApp = "MiApp"; // inferido como String

🔹 Comparación entre var, final y const

var

Mutabilidad: Variable mutable.

¿Puede cambiar el valor? ✅ Sí

¿Puede cambiar el tipo? ❌ No (una vez inferido)

Asignación: Puede reasignarse.

Inferencia: Sí, infiere el tipo.

Tiempo de asignación: En tiempo de ejecución.

final

Mutabilidad: Inmutable (se asigna una vez).

¿Puede cambiar el valor? ❌ No

¿Puede cambiar el tipo? ❌ No

Asignación: Solo una vez.

Inferencia: Sí, infiere el tipo.

Tiempo de asignación: En tiempo de ejecución.

const

Mutabilidad: Constante (compile-time).

¿Puede cambiar el valor? ❌ No

¿Puede cambiar el tipo? ❌ No

Asignación: Valor conocido en compilación.

Inferencia: Sí, infiere el tipo.

Tiempo de asignación: En tiempo de compilación.

🔹 Mutabilidad e inferencia de tipos

Puntos clave:
• var: permite cambiar el valor, pero NO el tipo.
• final: NO permite cambiar el valor (inmutable en runtime).
• const: NO permite cambiar el valor (constante en compile-time).
• Los tres usan inferencia de tipos: Dart deduce el tipo automáticamente.
// var permite cambiar el valor, pero no el tipo var nombre = "Carlos"; // String nombre = "Ana"; // ✅ Válido: cambia el valor, sigue siendo String // nombre = 42; // ❌ Error: no se puede cambiar el tipo // final NO permite cambiar el valor final String apellido = "García"; // apellido = "López"; // ❌ Error: no se puede reasignar // const NO permite cambiar el valor const double pi = 3.14159; // PI = 3.14; // ❌ Error: no se puede reasignar // Todos usan inferencia de tipos var x = 10; // int final y = 20; // int const z = 30; // int

🔹 ¿Cuándo usar cada uno?

Usa var: Cuando necesitas una variable que va a cambiar su valor (pero mantiene el mismo tipo).
Usa final: Cuando necesitas una variable que se asigna una vez y no cambia (por ejemplo, valores calculados en runtime).
Usa const: Cuando necesitas un valor que es constante en tiempo de compilación (por ejemplo, pi, días de la semana, mensajes fijos).

🔹 Ejemplo completo con var, final y const

void main() { // var: inferencia y mutabilidad (cambia el valor, no el tipo) var nombre = "Carlos"; nombre = "Carlos Pérez"; // ✅ Se puede reasignar (mismo tipo) // nombre = 42; // ❌ Error: no se puede cambiar el tipo var edad = 28; edad = 29; // ✅ Se puede reasignar // final: inmutable en runtime (NO se puede reasignar) final String apellido = "García"; // apellido = "López"; // ❌ Error: no se puede reasignar final double altura = 1.78; // altura = 1.80; // ❌ Error: no se puede reasignar // const: constante en compile-time (NO se puede reasignar) const double pi = 3.14159; const String mensaje = "Hola mundo"; const int dias = 7; // pi = 3.14; // ❌ Error: no se puede reasignar // mensaje = "Hola"; // ❌ Error: no se puede reasignar // Inferencia de tipos con todos var ciudad = "Madrid"; // String final pais = "España"; // String const continente = "Europa"; // String print("Nombre: $nombre"); print("Apellido: $apellido"); print("Edad: $edad"); print("Altura: $altura"); print("pi: $pi"); print("Mensaje: $MENSAJE"); print("Días: $DIAS"); print("Ciudad: $ciudad, País: $pais, Continente: $CONTINENTE"); }

💡 Tips clave para Dart:

• var: variable mutable con inferencia de tipo. Puede cambiar el valor, pero NO el tipo.

• final: variable inmutable (se asigna una vez en runtime). NO se puede reasignar.

• const: constante en tiempo de compilación. NO se puede reasignar.

• Type inference: Dart deduce automáticamente el tipo de la variable.

• Usa var para variables que cambian, final para valores que se asignan una vez, y const para constantes de compilación.
