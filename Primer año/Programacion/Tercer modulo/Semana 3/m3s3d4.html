Tema: Proyecto personal - Variables con información personal y print()

🎯 Competencia General

Aplica los conceptos de variables en Dart para almacenar información personal (nombre, edad, altura, etc.) y utiliza la función print() para mostrar los datos de manera organizada, consolidando los conocimientos sobre tipos de datos y declaración de variables.

📖 Conceptuales (Saber)

  • Define qué es una variable y su propósito en programación.
  • Identifica los tipos de datos básicos: int, double, String, bool.
  • Reconoce la función print() y su utilidad para mostrar información.
  • Comprende la interpolación de Strings con $ y ${}.

🛠️ Procedimentales (Saber hacer)

  • Declarar variables con tipos explícitos e inferidos.
  • Asignar valores a variables de diferentes tipos.
  • Usar print() para mostrar información en consola.
  • Utilizar interpolación de Strings para mostrar datos.

❤️ Actitudinales (Saber ser)

  • Muestra interés por aplicar los conceptos aprendidos.
  • Valora la importancia de organizar la información en variables.
  • Participa activamente en la creación de su proyecto personal.
  • Desarrolla confianza en el uso de variables y print().

🔹 Objetivo del proyecto:

🟡 DESARROLLO 35 minutos

Actividad: "Creando el proyecto personal"

Metodología: Práctica guiada y trabajo individual.

🔹 Paso 1: Crear un proyecto en Dart

Crear un nuevo proyecto en Dart desde la terminal o desde VS Code.

# Crear proyecto
dart create proyecto_personal
cd proyecto_personal

🔹 Paso 2: Declarar variables personales

Dentro del archivo bin/proyecto_personal.dart, escribir el código.

void main() {
  // Información personal
  String nombre = "Ana María";
  String apellido = "Pérez";
  int edad = 22;
  double altura = 1.65;
  double peso = 58.5;
  String ciudad = "Madrid";
  String pais = "España";
  String hobby = "Leer y pintar";
  bool esEstudiante = true;
  bool tieneMascota = false;
  int añoNacimiento = 2003;
  int numHermanos = 2;

  // Mostrar información
  print("Nombre: $nombre $apellido");
  print("Edad: $edad años");
  print("Altura: $altura m");
  print("Peso: $peso kg");
  print("Ciudad: $ciudad");
  print("País: $pais");
  print("Hobby: $hobby");
  print("¿Es estudiante? $esEstudiante");
  print("¿Tiene mascota? $tieneMascota");
  print("Año de nacimiento: $añoNacimiento");
  print("Número de hermanos: $numHermanos");
}

🔹 Paso 3: Ejecutar el programa

dart run

🔹 Paso 4: Personalizar con tus datos

Cada estudiante debe modificar los valores de las variables con su propia información personal.

📝 Actividad práctica

Realiza los siguientes pasos:

  • Paso 1: Crea un proyecto en Dart llamado proyecto_personal.
  • Paso 2: Declara variables con tu información personal (nombre, edad, altura, etc.).
  • Paso 3: Usa print() para mostrar los datos de manera organizada.
  • Paso 4: Personaliza el formato de salida (ej: agregar separadores, líneas, etc.).
  • Paso 5: Ejecuta el programa y verifica la salida.

• Variables: Usa nombres descriptivos para tus variables (ej: nombre, edad).

• print(): Usa $variable para insertar valores en Strings.

• Formato: Organiza la salida para que sea clara y legible.

• Práctica: Experimenta agregando más variables o cambiando los valores.
