📘 PLANIFICACIÓN DE CLASE

Tema: Suma y Resta de Raíces - Radicales semejantes y simplificación

🎯 Competencia General

Comprende las reglas para sumar y restar radicales, identificando cuándo son semejantes (mismo índice y mismo radicando) y simplificando radicales para encontrar términos comunes, aplicando la propiedad de multiplicación de radicales cuando sea necesario.

📖 Conceptuales (Saber)

  • Define radicales semejantes.
  • Comprende que solo se pueden sumar o restar radicales semejantes.
  • Reconoce que los radicales diferentes pero simplificables pueden volverse semejantes.
  • Identifica el coeficiente de un radical.

🛠️ Procedimentales (Saber hacer)

  • Sumar y restar radicales con el mismo índice y radicando.
  • Simplificar radicales para encontrar términos semejantes.
  • Aplicar la propiedad de multiplicación de radicales para simplificar.
  • Operar coeficientes y mantener el radical común.

❤️ Actitudinales (Saber ser)

  • Muestra interés por simplificar expresiones con radicales.
  • Valora la importancia de la simplificación en matemáticas.
  • Participa activamente en la resolución de ejercicios.
  • Reconoce la utilidad de los radicales en contextos geométricos y algebraicos.
🟢 INICIO 15 minutos

Actividad: "¿Cómo sumar raíces?"

Metodología: Cuestionamiento y exploración.

Descripción: El docente plantea preguntas:

  • ¿Cómo sumas 2√3 + 3√3?
  • ¿Puedes sumar √2 + √3? ¿Por qué?
  • ¿Qué pasa con √4 + √8? ¿Se pueden sumar directamente?
  • ¿Cómo se llama la operación de simplificar √8?

Se introduce la idea de que solo se pueden sumar o restar radicales semejantes (mismo índice y mismo radicando).

📌 Ejemplo inicial:
2√3 + 3√3 = 5√3 (se suman los coeficientes)
√4 + √8 = 2 + 2√2 (se simplifican primero)

Aprendizaje esperado

El estudiante comprende que solo se pueden sumar radicales semejantes.

Criterios de evaluación

  • Define radicales semejantes.
  • Participa en la discusión inicial.

🟡 DESARROLLO 35 minutos

Actividad: "Suma y resta de radicales"

Metodología: Explicación guiada con ejemplos.

🔹 Radicales semejantes

Dos radicales son semejantes si tienen el mismo índice y el mismo radicando. Solo se pueden sumar o restar radicales semejantes.

✅ Semejantes
  • √3 y √3
  • 2√5 y 3√5
  • ³√2 y 5³√2
📌 Se pueden sumar o restar
❌ NO semejantes
  • √2 y √3
  • 2√5 y 3√7
  • √2 y ³√2
📌 NO se pueden sumar o restar directamente

🔹 Suma y resta de radicales semejantes

Para sumar o restar radicales semejantes, se suman o restan los coeficientes y se mantiene el radical.

📌 Ejemplos:
2√3 + 3√3 = 5√3
5√2 - 2√2 = 3√2
4³√5 + 2³√5 = 6³√5
7√3 - 3√3 = 4√3

🔹 Simplificación para encontrar radicales semejantes

Si los radicales no son semejantes, se puede simplificar el radicando para ver si se vuelven semejantes.

📌 Ejemplo: √4 + √8
√4 = 2 (raíz exacta)
√8 = √(4 × 2) = √4 × √2 = 2√2
√4 + √8 = 2 + 2√2 → No son semejantes, se dejan así.
📌 Ejemplo: √18 + √8
√18 = √(9 × 2) = 3√2
√8 = √(4 × 2) = 2√2
√18 + √8 = 3√2 + 2√2 = 5√2
📌 Ejemplo: √50 - √18
√50 = √(25 × 2) = 5√2
√18 = √(9 × 2) = 3√2
√50 - √18 = 5√2 - 3√2 = 2√2

🔹 Caso especial: mismo radicando pero diferente índice

Si tienen el mismo radicando pero diferente índice, no son semejantes y no se pueden sumar ni restar.

📌 Ejemplo: √2 + ³√2
√2 tiene índice 2
³√2 tiene índice 3
No son semejantes → se dejan como están.

🔹 Multiplicación de radicales

Cuando se multiplican radicales, se multiplican los coeficientes y se multiplican los radicandos (si tienen el mismo índice).

📌 Regla: (a√b) × (c√d) = (a × c) × √(b × d) 📌 (2√3) × (3√5) = 6√15 📌 (4√2) × (√3) = 4√6

📝 Actividad práctica

Resuelve las siguientes operaciones con radicales:

  • Suma y resta: 3√5 + 2√5, 7√2 - 3√2, 4√3 + 2√3 - 5√3
  • Simplificación y suma: √18 + √8, √50 - √32, √12 + √27
  • Simplificación y resta: √45 - √20, √72 - √50
  • Multiplicación: (2√3)(4√2), (3√5)(2√7), (√6)(√3)
  • Casos especiales: √2 + √8, √20 - √45, √12 + √18

Preguntas de reflexión:

  • ¿Qué condición deben cumplir dos radicales para poder sumarse?
  • ¿Cómo se simplifica un radical?
  • ¿Qué pasa si los radicales tienen el mismo radicando pero diferente índice?

Aprendizaje esperado

El estudiante suma y resta radicales, simplifica y reconoce radicales semejantes.

Criterios de evaluación

  • Suma y resta radicales semejantes correctamente.
  • Simplifica radicales para encontrar términos semejantes.
  • Multiplica radicales correctamente.
  • Explica por qué no se pueden sumar radicales no semejantes.

🔵 CIERRE 10 minutos

Actividad: "Repaso de suma y resta de radicales"

Metodología: Preguntas rápidas.

  • ¿Cuándo se pueden sumar dos radicales? → Cuando son semejantes (mismo índice y radicando).
  • ¿Cómo se suman 2√3 + 5√3? → 7√3 (se suman los coeficientes).
  • ¿Se puede sumar √2 + √3? → No, no son semejantes.
  • ¿Cómo se simplifica √8? → 2√2.
  • ¿Cuánto es √18 + √8? → 3√2 + 2√2 = 5√2.
  • ¿Cuánto es (2√3)(4√5)? → 8√15.

El estudiante consolida la suma y resta de radicales.

💡 Tips clave:

• Radicales semejantes: Mismo índice y mismo radicando.

• Suma/Resta: Suma o resta los coeficientes, mantén el radical.

• Simplificación: Factoriza el radicando para encontrar términos semejantes.

• Multiplicación: Multiplica coeficientes y radicandos.

• NO se pueden sumar radicales con diferente índice o diferente radicando.

🔥 Esta clase es clave porque:

• Enseña a operar con radicales, habilidad esencial en álgebra.

• Conecta con la simplificación de expresiones y ecuaciones.

• Prepara a los estudiantes para temas de geometría y cálculo.

• Desarrolla habilidades de factorización y razonamiento.
