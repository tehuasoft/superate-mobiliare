📘 PLANIFICACIÓN DE CLASE

Tema: División de Raíces - Regla, casos y simplificación

🎯 Competencia General

Comprende la regla de división de radicales con el mismo índice, aplica la propiedad de que el cociente de dos raíces es igual a la raíz del cociente de los radicandos, y maneja casos donde la raíz está solo en el numerador o solo en el denominador.

📖 Conceptuales (Saber)

  • Define la propiedad de división de radicales.
  • Comprende que ⁿ√a / ⁿ√b = ⁿ√(a/b).
  • Reconoce el caso donde la raíz está solo en el numerador o denominador.
  • Identifica la importancia de simplificar el resultado.

🛠️ Procedimentales (Saber hacer)

  • Dividir radicales con el mismo índice.
  • Simplificar el cociente de radicales.
  • Manejar raíces solo en el numerador o denominador.
  • Multiplicar por el conjugado cuando sea necesario (introducción).

❤️ Actitudinales (Saber ser)

  • Muestra interés por comprender la división de radicales.
  • Valora la utilidad de las propiedades de los radicales.
  • Participa activamente en la resolución de ejercicios.
  • Reconoce la importancia de la simplificación en divisiones.

🟡 DESARROLLO 35 minutos

Actividad: "División de radicales"

Metodología: Explicación guiada con ejemplos.

🔹 Propiedad de división de radicales

Para radicales con el mismo índice, el cociente es la raíz del cociente de los radicandos.

📌 Regla general
ⁿ√a / ⁿ√b = ⁿ√(a / b)
📌 √8 / √2 = √(8/2) = √4 = 2 📌 ³√27 / ³√3 = ³√(27/3) = ³√9

🔹 Caso 1: Raíz en numerador y denominador

Se aplica directamente la propiedad.

📌 Ejemplos:
√18 / √2 = √(18/2) = √9 = 3
√50 / √2 = √(50/2) = √25 = 5
³√24 / ³√3 = ³√(24/3) = ³√8 = 2

🔹 Caso 2: Raíz solo en el numerador

Si solo hay raíz en el numerador, se puede multiplicar por el denominador si es necesario, o simplemente dejar como fracción.

📌 Ejemplos:
√18 / 3 = (3√2) / 3 = √2 (simplificando el coeficiente)
√20 / 4 = (2√5) / 4 = √5 / 2

🔹 Caso 3: Raíz solo en el denominador

Si solo hay raíz en el denominador, se racionaliza multiplicando numerador y denominador por la raíz del denominador.

📌 Ejemplo: 5 / √2
5 / √2 = (5 × √2) / (√2 × √2) = 5√2 / 2
📌 Ejemplo: 3 / √5
3 / √5 = (3 × √5) / (√5 × √5) = 3√5 / 5

🔹 Racionalización de denominadores

Cuando el denominador tiene una raíz, se multiplica por la misma raíz para eliminarla.

📌 Regla: a / √b = (a × √b) / b 📌 2 / √3 = 2√3 / 3 📌 5 / √2 = 5√2 / 2

🔹 División con coeficientes

Cuando hay coeficientes, se dividen los coeficientes y los radicandos por separado.

📌 Regla:
(a√b) / (c√d) = (a/c) × √(b/d)

📌 Ejemplos:
(6√10) / (2√2) = (6/2) × √(10/2) = 3√5
(4√12) / (2√3) = (4/2) × √(12/3) = 2√4 = 2 × 2 = 4

📝 Actividad práctica

Resuelve las siguientes divisiones de radicales:

  • División básica: √12 / √3, √20 / √5, √27 / √3
  • Raíz solo en numerador: √18 / 3, √24 / 2, √32 / 4
  • Raíz solo en denominador (racionalizar): 3/√2, 5/√3, 7/√5
  • Con coeficientes: (6√8)/(2√2), (4√15)/(2√3), (9√6)/(3√2)
  • Simplificación: √50 / √2, √72 / √8, √45 / √5

💡 Tips clave:

• División: ⁿ√a / ⁿ√b = ⁿ√(a/b).

• Raíz en denominador: Racionaliza multiplicando por la raíz.

• Coeficientes: Divide coeficientes y radicandos por separado.

• Simplifica: Siempre simplifica el radical resultante.

• Diferentes índices: No se pueden dividir directamente.
